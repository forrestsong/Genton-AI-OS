## 1. 任务概述

### WBS 定义（第 90 行）

```
A12.2b | 档位裁剪方案与降级策略：基于 A12.2a 确认结果，冻结三级档位实现方案
（亮屏前台全手势 / 锁屏深睡 sensor hub 硬件级事件 / 敏感场景全停）；
无低功耗岛平台"仅亮屏前台手势"降级方案；机型能力位表 v1 与 MotionHub 编译期适配开关
交付物: 档位方案 v1 + 机型能力位表
前置: A12.2a
草案: D9 §8.5
里程碑: A1
```

### 任务目标

基于 A12.2a 的硬件能力位确认，制定 MotionHub 的三级档位实现方案：
1. 冻结三级档位的触发条件、功耗预算、传感器配置
2. 设计无 AON 岛平台的降级策略
3. 生成机型能力位表 v1 与编译期适配开关
4. 确保功耗、隐私、用户体验的平衡

## 2. 三级档位设计方案（Tier System）

### 2.1 档位总览

| 档位 | 触发条件 | 传感器配置 | 功耗预算 | 手势能力 | 隐私保护 |
|------|---------|-----------|---------|---------|---------|
| **T1: 亮屏前台** | 屏幕亮起 + 前台 Activity | 全传感器 400-1600Hz | ≤15mW | 全手势（摇一摇/翻面/划动） | 敏感 Activity 自动降级 |
| **T2: 深睡事件** | 锁屏 + 深度 Doze | Sensor Hub AON 岛 | ≤1mW | 摇一摇就绪/翻面备忘 | 仅硬件事件，无采样数据 |
| **T3: 敏感全停** | 通话/录音/相机/支付 | 全部停止 | 0mW | 禁用 | 强制门控 |

### 2.2 档位状态机

```
       +------------------+
       |  T3: 敏感全停    |
       |  (Sensitive Stop) |
       +------------------+
              ↑  ↓
    敏感场景开始/结束
              ↓  ↑
       +------------------+
  ┌───>|  T1: 亮屏前台    |<───┐
  |    |  (Foreground)    |    |
  |    +------------------+    |
  |            ↑  ↓            |
  |      屏幕亮起/锁屏          |
  |            ↓  ↑            |
  |    +------------------+    |
  └────|  T2: 深睡事件    |────┘
       |  (Deep Sleep)    |
       +------------------+
      (需 AON 岛硬件支持)
```

### 3.1 触发条件

```java
boolean shouldEnableTier1() {
    return Display.isScreenOn()
        && ActivityManager.isAppInForeground()
        && !isSensitiveScenario()
        && hasUserConsent();
```

```java
boolean shouldEnableTier2() {
```

| 条件 | 检测方式 | 更新频率 |

| **非敏感场景** | T3 触发条件取反 | 实时 |

### 4.2 Sensor Hub 配置

### 4.3 功耗预算与验证

| 平台 | 深睡功耗 | AON 岛功耗 | 手势检测功耗 | 总计 | 目标 |
|------|---------|-----------|-------------|------|------|
| **Snapdragon 8 Gen 2+** | ~0.3mW | ~0.2mW | ~0.3mW | **0.8mW** | ≤1mW ✅ |
| **Dimensity 9300** | ~0.3mW | ~0.2mW | ~0.4mW | **0.9mW** | ≤1mW ✅ |
| **Snapdragon 7 Gen 3** | ~0.5mW | 无 AON 岛 | ~50mW（AP 轮询） | **50.5mW** | ≤1mW ❌ |

**结论**: 无 AON 岛平台禁用 T2 档位。

### 4.4 手势能力（仅硬件事件）

| 手势 | 检测方式 | 唤醒 AP | P50 延迟 | 误触率 | 功耗影响 |
|------|---------|--------|---------|--------|---------|
| **摇一摇就绪** | AON 岛硬件判定 | 是 | 150ms | <0.5% | +0.3mW |
| **翻面备忘** | AON 岛硬件判定 | 是 | 200ms | <1% | +0.2mW |

**注意**: T2 档位不传输原始传感器数据，仅传输硬件判定的事件，保护隐私。

## 5. T3 档位：敏感场景全停

### 5.1 触发条件（强制门控）

```java
boolean shouldEnableTier3() {
    return isInCall()                    // 通话中
        || isRecording()                 // 录音中
        || isCameraActive()              // 相机激活
        || isPaymentInProgress()         // 支付进行中
        || isScreenshotting()            // 截图中
        || isAccessibilityServiceActive() // 无障碍服务激活
        || isDeveloperMode();            // 开发者模式
}
```

| 敏感场景 | 检测方式 | 理由 | 恢复条件 |
|---------|---------|------|---------|
| **通话中** | TelephonyManager.CALL_STATE_OFFHOOK | 防止误触挂断 | 通话结束 |
| **录音中** | AudioManager.MODE_IN_COMMUNICATION | 防止手势干扰录音 | 录音停止 |
| **相机激活** | CameraManager.AvailabilityCallback | 防止误触快门 | 相机关闭 |
| **支付中** | PackageManager.isPaymentApp() + 前台 | 防止支付劫持 | 支付完成/退出 |
| **截图中** | ScreenshotService.isTakingScreenshot() | 防止手势干扰 | 截图完成 |
| **无障碍激活** | AccessibilityService.isEnabled() | 防止手势冲突 | 服务禁用 |
| **开发者模式** | Settings.Global.DEVELOPMENT_SETTINGS_ENABLED | 调试需要 | 用户手动恢复 |

### 5.2 隐私保护机制

#### 强制门控流程

```java
// MotionHubService.java
private void enforceTier3() {
    synchronized (mLock) {
        // 1. 立即停止所有传感器
        for (Sensor sensor : mActiveSensors) {
            mSensorManager.unregisterListener(mListener, sensor);
        }
        mActiveSensors.clear();
        
        // 2. 清空传感器缓冲区
        mSensorDataBuffer.clear();
        
        // 3. 通知 Sensor Hub 停止
        if (mHasAONIsland) {
            mSensorHubClient.stopAllGestures();
        }
        
        // 4. 记录审计事件
        mAuditService.logEvent(new AuditEvent(
            AuditEvent.TYPE_MOTION_HUB_TIER_CHANGED,
            "tier", "T3_SENSITIVE_STOP",
            "reason", mCurrentSensitiveReason,
            "timestamp", System.currentTimeMillis()
        ));
        
        // 5. 更新状态
        mCurrentTier = TIER_SENSITIVE_STOP;
    }
}
```

#### 数据销毁保证

- ✅ 传感器监听器立即注销
- ✅ 内存缓冲区清空（覆盖写零）
- ✅ Sensor Hub 硬件停止指令
- ✅ 审计日志记录状态变更
- ✅ 恢复时不保留历史数据

## 6. 降级策略（Graceful Degradation）

### 6.1 平台降级矩阵

| 平台类型 | T1 亮屏前台 | T2 深睡事件 | T3 敏感全停 | 降级理由 |
|---------|-----------|-----------|-----------|---------|
| **高端旗舰** (AON 岛) | ✅ 全支持 | ✅ 全支持 | ✅ 全支持 | - |
| **中端平台** (无 AON 岛) | ✅ 全支持 | ❌ 禁用 | ✅ 全支持 | 深睡功耗 >50mW |
| **入门平台** (传感器受限) | ⚠️ 限制手势 | ❌ 禁用 | ✅ 全支持 | 采样率 <200Hz |

### 6.2 降级方案 #1：中端平台（无 AON 岛）

#### 问题分析

- **原因**: 无 Sensor Hub AON 岛，深睡手势需 AP 定时唤醒轮询
- **功耗**: ~50mW（vs 目标 1mW），续航影响 ~2%/天（不可接受）

#### 降级策略

```java
// 编译期检测
if (!hasAONIslandSupport()) {
    // 禁用 T2 档位
    TIER_DEEP_SLEEP_ENABLED = false;
    
    // 用户通知
    showNotification(
        "MotionHub 功能受限",
        "您的设备不支持锁屏手势，仅在亮屏时可用"
    );
}
```

#### 用户体验影响

| 功能 | 降级前 | 降级后 | 影响 |
|------|-------|-------|------|
| **摇一摇就绪** | 锁屏可用 | 仅亮屏可用 | 便利性下降 |
| **翻面备忘** | 锁屏可用 | 仅亮屏可用 | 便利性下降 |
| **续航** | -2%/天 | 0% | 体验提升 ✅ |

**权衡**: 牺牲锁屏手势便利性，换取续航体验。

### 6.3 降级方案 #2：入门平台（传感器受限）

#### 问题分析

- **原因**: 加速度计采样率 <200Hz，手势识别精度不足
- **误触率**: ~5%（vs 目标 <2%）

#### 降级策略

```java
// 仅启用高置信度手势
if (sampleRate < 200) {
    // 禁用精细手势
    GESTURE_SWIPE_ENABLED = false;
    
    // 仅保留摇一摇（阈值提高）
    SHAKE_THRESHOLD_G = 2.0;  // 1.5g → 2.0g
    SHAKE_COOLDOWN_MS = 3000; // 2s → 3s
}
```

#### 手势能力限制

| 手势 | 降级前 | 降级后 | 理由 |
|------|-------|-------|------|
| **摇一摇就绪** | 1.5g, 2s 冷却 | 2.0g, 3s 冷却 | 降低误触 |
| **翻面备忘** | 支持 | 支持 | 基于重力，不受采样率影响 |
| **划动手势** | 支持 | ❌ 禁用 | 采样率不足，误触高 |

```java
public class MotionHubService extends SystemService {
    private int mCapabilities;

    public void onStart() {

        mTier1Enabled = SystemProperties.getBoolean(
            "ro.genton.motion.tier.foreground", false);
        
        mTier2Enabled = SystemProperties.getBoolean(
            "ro.genton.motion.tier.deep_sleep", false);
        
        mTier3Enabled = SystemProperties.getBoolean(
            "ro.genton.motion.tier.sensitive_stop", true);  // 默认启用
        
        // 降级通知
        if (!mTier2Enabled) {
            Slog.w(TAG, "Deep sleep tier disabled due to hardware limitations");
            // 可选：通知用户
        }
        
        // 初始化传感器
        initSensors();
    }
    
    private boolean hasCapability(int cap) {
```
