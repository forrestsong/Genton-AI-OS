# C3.4 记忆抽取任务设计文档

## 任务概述

**任务编号**: C3.4  
**任务名称**: 记忆抽取：对话后事实抽取/偏好、PII 掩码与分级加密入库规则、来源标注防投毒  
**前置依赖**: A5.1 记忆服务端 ✅、C4.3 PII 掩码模型 ✅  
**里程碑**: A3（智能与端云）  
**配套文档**: D4 记忆服务与审计引擎接口草案

## 核心目标

实现对话后自动记忆抽取管线：

1. ✅ **事实抽取**：从对话中提取结构化事实（人物/地点/时间/事件）
2. ✅ **偏好抽取**：识别用户偏好（喜欢/不喜欢/习惯）
3. ✅ **PII 掩码**：集成 C4.3 PII 掩码服务，敏感内容拒绝入库
4. ✅ **分级加密**：根据敏感度分级加密（TEE 域密钥）
5. ✅ **来源标注**：provenance 追溯，防止长期记忆投毒
6. ✅ **后台调度**：低功耗窗口异步执行

### 三层记忆分类

| 记忆类型 | 来源 | 示例 | 处理策略 |
|---|---|---|---|
| **事实（Fact）** | 对话中陈述的客观信息 | "我的生日是 1990 年 1 月 1 日" | PII 检测 → 掩码/拒绝 |
| **偏好（Preference）** | 用户表达的喜好/习惯 | "我喜欢喝咖啡，不喜欢茶" | 分级加密，低敏感 |
| **系统记忆（System）** | 系统推断的元信息 | "用户常在早上 9 点查邮件" | 仅特权 Agent 可写 |

## 核心组件

### 1. MemoryExtractionTask - 后台抽取任务

**职责**: 在对话完成后，低功耗窗口触发记忆抽取

**触发时机**:
- 会话结束（用户明确退出或超时）
- 累计对话轮次 ≥5（防止短对话频繁触发）
- 设备空闲 + 电量充足（低功耗窗口）

**执行策略**:
```kotlin
class MemoryExtractionTask(
    private val sessionId: String,
    private val messages: List<Message>
) : Runnable {
    
    override fun run() {
        if (!shouldExtract()) {
            return  // 跳过：短对话/系统消息占比高
        }
        
        // 1. 事实抽取
        val facts = factExtractor.extract(messages)
        
        // 2. 偏好抽取
        val preferences = preferenceExtractor.extract(messages)
        
        // 3. 过滤 + 掩码 + 加密
        val candidateMemories = (facts + preferences)
            .filter { it.confidence >= 0.7 }  // 低置信度过滤
            .map { applyPiiMask(it) }
            .filter { it.status != STATUS_PII_REJECT }
            .map { applyEncryption(it) }
        
        // 4. 写入记忆服务
        candidateMemories.forEach { memory ->
            memoryService.write(memory.toDraft())
        }
    }
}
```

### 2. FactExtractor - 事实抽取器

**抽取目标**:
- **人物（Person）**: "我的朋友小明"、"王经理"
- **地点（Location）**: "北京海淀区"、"公司会议室"
- **时间（Time）**: "明天下午 3 点"、"每周一"
- **事件（Event）**: "我要出差"、"项目截止日期是 12 月 1 日"

**抽取方法**:
- 基于规则的 NER（命名实体识别）
- 简化版：正则表达式 + 关键词匹配
- 完整版：调用端侧 NER 模型（后续优化）

**示例**:
```kotlin
输入对话：
  用户："我明天下午 3 点要去北京开会，记得提醒我"
  
抽取结果：
  Fact(
    type = "EVENT",
    content = "明天下午 3 点 去北京开会",
    entities = [
      Entity(type="TIME", value="明天下午 3 点"),
      Entity(type="LOCATION", value="北京"),
      Entity(type="EVENT", value="开会")
    ],
    confidence = 0.92
  )
```

### 3. PreferenceExtractor - 偏好抽取器

**抽取目标**:
- **喜好（Like）**: "我喜欢 X"、"X 不错"
- **厌恶（Dislike）**: "我不喜欢 Y"、"Y 很烦"
- **习惯（Habit）**: "我每天都 Z"、"我通常 W"

**强度评分（1-5）**:
- 5 = 强烈喜欢/讨厌（"非常喜欢"、"特别讨厌"）
- 3 = 中等（"喜欢"、"不太喜欢"）
- 1 = 轻微（"还行"、"一般"）

**示例**:
```kotlin
输入对话：
  用户："我特别喜欢喝咖啡，但不太喜欢茶"
  
抽取结果：
  Preference(
    type = "LIKE",
    subject = "咖啡",
    strength = 5,
    confidence = 0.95
  ),
  Preference(
    type = "DISLIKE",
    subject = "茶",
    strength = 2,
    confidence = 0.88
  )
```

### 4. PII 掩码集成

**策略**:
```kotlin
fun applyPiiMask(memory: ExtractedMemory): MaskedMemory {
    val maskResult = piiMaskService.maskPii(
        memory.content,
        mode = MaskMode.AUTO,
        aggressiveMode = true
    )
    
    return when {
        // 命中强敏感 PII（密码/证件/金融）→ 拒绝入库
        maskResult.detectedPii.any { 
            it.category in listOf(
                PiiCategory.PASSWORD,
                PiiCategory.BANK_CARD,
                PiiCategory.ID_CARD
            )
        } -> MaskedMemory(
            status = STATUS_PII_REJECT,
            reason = "检测到强敏感 PII，拒绝入长期记忆"
        )
        
        // 中等敏感（手机号/邮箱）→ 掩码后入库
        maskResult.maskApplied -> MaskedMemory(
            status = STATUS_OK,
            content = maskResult.maskedText,
            piiMasked = true,
            detectedCategories = maskResult.detectedPii.map { it.category }
        )
        
        // 无 PII → 直接入库
        else -> MaskedMemory(
            status = STATUS_OK,
            content = memory.content,
            piiMasked = false
        )
    }
}
```

### 5. 分级加密

**加密级别**:

| 级别 | 触发条件 | 加密方式 | 密钥存储 |
|---|---|---|---|
| **高敏感** | 包含中等 PII（手机号/邮箱） | AES-256-GCM | TEE 密钥库 |
| **中敏感** | 用户隐私偏好 | AES-128-GCM | 应用密钥库 |
| **低敏感** | 一般事实（已掩码） | 明文存储 | - |

**实现**:
```kotlin
fun applyEncryption(memory: MaskedMemory): EncryptedMemory {
    val sensitivityLevel = assessSensitivity(memory)
    
    return when (sensitivityLevel) {
        SensitivityLevel.HIGH -> {
            val encrypted = teeEncryption.encrypt(
                memory.content,
                keyAlias = "memory_high_sens"
            )
            EncryptedMemory(
                content = encrypted.ciphertext,
                encryptionLevel = "TEE_AES256",
                keyRef = encrypted.keyRef
            )
        }
        
        SensitivityLevel.MEDIUM -> {
            val encrypted = appEncryption.encrypt(
                memory.content,
                keyAlias = "memory_med_sens"
            )
            EncryptedMemory(
                content = encrypted.ciphertext,
                encryptionLevel = "APP_AES128",
                keyRef = encrypted.keyRef
            )
        }
        
        SensitivityLevel.LOW -> {
            EncryptedMemory(
                content = memory.content,
                encryptionLevel = "NONE",
                keyRef = null
            )
        }
    }
}
```

### 6. Provenance 来源标注

**防投毒策略**:
```kotlin
data class ProvenanceInfo(
    val sourceKind: SourceKind,      // USER_STMT / MODEL_EXTRACT
    val sourceRef: String,            // 会话 ID
    val extractedAt: Long,
    val extractionModel: String,      // "fact_extractor_v1"
    val contentFingerprint: String,   // SHA256 哈希
    val trustLevel: TrustLevel        // USER_INPUT / APP_CONTENT 等
)

enum class SourceKind {
    USER_STMT,       // 用户直接陈述
    SCREEN,          // 屏幕捕获抽取
    NOTIFICATION,    // 通知内容抽取
    APP_DATA,        // 应用数据
    WEB_CONTENT,     // 网页内容
    MODEL_EXTRACT    // 模型推断
}

// 写入时标注
fun createMemoryDraft(memory: ExtractedMemory): MemoryEntryDraft {
    return MemoryEntryDraft(
        kind = KIND_LONG_TERM,
        content = memory.content,
        tags = memory.tags,
        trust = TrustLevel.USER_INPUT,  // 来自对话，高可信
        sourceSessionId = memory.sessionId,
        provenance = ProvenanceInfo(
            sourceKind = SourceKind.MODEL_EXTRACT,
            sourceRef = memory.sessionId,
            extractedAt = System.currentTimeMillis(),
            extractionModel = "fact_extractor_v1",
            contentFingerprint = sha256(memory.content),
            trustLevel = TrustLevel.USER_INPUT
        )
    )
}
```

## 验收标准

### 功能验收

- [ ] 事实抽取准确率 ≥80%（人工标注 100 条对话）
- [ ] 偏好抽取准确率 ≥75%
- [ ] PII 检测召回率 ≥90%（对齐 E3.1 基准）
- [ ] 强敏感 PII 拒绝率 100%（密码/证件/金融）
- [ ] 中等敏感 PII 掩码率 100%（手机号/邮箱）
- [ ] Provenance 完整性 100%（每条记忆可追溯）

### 性能验收

- [ ] 单次抽取延迟 ≤2s（100 轮对话）
- [ ] 后台任务不影响前台交互（低功耗窗口）
- [ ] 内存占用 ≤50MB（抽取过程）
- [ ] 每日抽取次数 ≤10（避免频繁触发）
