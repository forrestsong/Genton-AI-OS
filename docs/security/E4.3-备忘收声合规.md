## 0. 结论摘要

备忘收声与姿态传感器合规评审结论为 **有条件通过**。D9 §8 的「默认关闭（opt-in）、多传感器共识、3s 取消窗、活性指示、仅就绪不自动拍摄、粗位置本地命名」设计方向正确。存在 4 项强制落地项：

1. **F1（环境录音告知口径）**：备忘收声属**环境录音**，其告知对象是**用户本人**（区别于通话来电方）。告知形态 = **预告振动/屏幕提示「将录音」+ 3s 取消窗 + 录音期间活性指示常显**（R11.1/R11.3/R11.4）；**地区合规**承接 E4.1 §3.1：中国大陆「告知 + 默示同意 + 可拒绝」，若当地要求**可听提示音**（如部分司法辖区对持续录音要求 periodic beep），需地区配置（默认最严=开启可听提示音）。
2. **F2（取消窗与活性指示验收）**：3s 取消窗内用户可放弃（不留文件）；录音活性指示**必须在录音启动时立即显示（R8.8）且不可被 Agent/App 隐藏（R8.9）**；取消后无任何残留（文件/索引/审计摘要）。
3. **F3（「仅就绪不自动拍摄」边界）**：摇一摇就绪**不得自动按快门**（快门需第二意图：语音「拍照」/按键）——就绪 = 相机取景预热 + 提示「已就绪：可拍照或提问」，任何「就绪后定时/自动拍摄」均属违规（R12.10）。
4. **F4（粗位置命名不出端核验）**：备忘文件命名 `<coarsePlace>_<date>_<time>.m4a` 的 `coarsePlace`（家/公司/通勤中/未知）**仅本地语义解析、不出端**（R12.8）；位置授权缺失时退化为 `无地点_日期_时间.m4a`；`coarsePlace` 标签本身即敏感（D8 开放问题 3），**用户可改可关**。

**评审底线**：
- **录音能力不得提前开放**（对齐 WBS 长链⑥红线：备忘收声与 S6-b 共用 E4.1 合规定论，录音能力不得提前开放）；
- **姿态手势不削弱安全与可审计性**（D9 §8.3：任何加速都不削弱安全与可审计性）——就绪动作免确认仅限 low 级，录音属最高敏感级一律审计与可见。

## 2. 评审正文

### 2.1 环境录音告知口径（F1）

**评审结论：有条件通过**

- **告知对象区分**（本评审关键澄清）：
  - 备忘收声是**用户本人触发**的环境录音（翻面静置 → 自动录音），**告知对象 = 用户本人**（触发当下用户可能正把手机放下、人不在看屏）；
  - 因此告知**不能只靠屏幕文字**，必须是**多模态预告**：**振动 + 屏幕提示「将录音」+ 3s 取消窗**（D9 §8.1b），录音启动后**活性指示常显**（状态栏芯片 + 悬浮「录制中·可停止/丢弃」）。
- **地区合规口径（承接 E4.1 §3.1，F1 固化）**：
  - **中国**：告知（预告 + 活性指示）+ 默示同意（用户未在取消窗内放弃）+ 可随时停止——满足 PIPL 敏感个人信息处理的告知要求；录音文件本地加密（Keystore 密钥）；
  - **部分司法辖区要求持续可听提示音**（通话/录音合规差异）：地区配置 `memo_record_beep=true`（默认最严开启）；未配置地区默认开启可听提示音（fail-safe）；
  - **敏感场景强制禁用**：通话中/支付页/输入聚焦/安全窗口在屏 → 备忘收声禁用（D9 §8.3，R12.4）。
- **录音内容边界**：录音默认只落本地媒体库，**不入 Agent 长期记忆、不自动上传**（D9 §8.1b）；录音事件入审计（何时/时长/命名，**不采内容**）。

### 2.2 预告/3s 取消窗/活性指示验收（F2）

**评审结论：通过（需验收固化）**

- **预告**：判定达成 → 振动 + 屏幕提示 ≤300ms 内呈现（对齐 §0 收声启动 ≤300ms P95）；
- **3s 取消窗**：
  - 取消窗内录音**尚未开始**（预告态）或开始后可一键放弃；放弃 → **不留文件、不入索引、审计记「误触发已取消」**；
  - 取消窗 UI：悬浮「将录音 · 3s 内可取消」+ 明确「开始录音」/「取消」按钮（防误触：按钮间隔 + 上滑取消语义对齐 D3.1 确认面板防误触候选方案）；
  - **取消窗不可被手势绕过**（对齐 E5.4 用例「取消窗绕过」——任何新手势/重复手势不得加速越过 3s 窗）。
- **活性指示（R8.8/R8.9）**：
  - 录音态指示**必须在录音启动瞬间显示**（延迟 ≤ 100ms 验收，对齐 R8.8）；
  - 指示**不可被 Agent 关闭或隐藏**（系统级，R8.9）——MotionHub/SystemUI 独占呈现，Agent 无隐藏接口；
  - 指示形态：状态栏芯片「● 录制中」+ 可点击停止；锁屏场景走「提示先行 + 取消窗」补偿（D9 §8.5c 深睡档）。
- **验收方法**：自动化用例（触发→预告呈现→3s 取消→无残留文件；录音→指示显示延迟 <100ms；Agent 尝试隐藏指示→被系统拒绝）。

### 2.3 「仅就绪不自动拍摄」边界（F3）

**评审结论：有条件通过（边界明确）**

- **允许**：摇一摇 → 相机**就绪态**（取景预热 + 提示「已就绪：可拍照，或问'这个是什么'」）；
- **禁止**：
  - 就绪后**自动按快门**（任何延时/条件自动拍摄）；
  - 就绪空转超限（**15-30s 无操作自动退出**，D9 §8.5b 就绪空转上限）；
  - 后台静默取景（无就绪 UI 时相机不得预览）；
  - 遮挡状态下触发（相机被遮挡/隐私开关关闭时不得就绪，D9 §8.1a 前提）。
- **快门第二意图**：语音「拍照」/用户按键 → 才拍摄；拍摄帧走既有捕获/掩码/出端策略（S5-h + E3.2 出网中间件）。
- **边界裁决**：`sys.camera.prepare_qa`（low，就绪+拉起视觉问答入口，免确认但审计）——**免确认仅限「就绪」动作本身**；任何触发「拍摄/截图/上传」的动作回到策略/确认链。

### 2.4 粗位置命名不出端核验（F4）

**评审结论：有条件通过（需核验）**

- **设计**：备忘文件命名 `<coarsePlace>_<date>_<time>.m4a`，`coarsePlace ∈ {家/公司/通勤中/未知}`（D8 `LocationContext.coarsePlace`），本地语义解析。
- **核验要求**：
  - `coarsePlace` **只在设备本地解析**（本地小模型 + 用户可改可关，D8 开放问题 3）；
  - **不出端**：`coarsePlace` 不进入任何出网字段（E2.3 字段白名单无此字段）；**R12.8 红线**——通过 H3.4 网络抓包 + E5.4 渗透用例核验（「第三方经事件流/传感器上下文推断位置」）；
  - 位置授权缺失 → 退化 `无地点_日期_时间.m4a`（不采集位置）；
  - **隐私考量**：「家」标签本身即敏感——命名只是文件名元数据，录音内容索引不关联精确位置；文件分享（若有）前用户可见命名并可选重命名。
- **联动**：`coarsePlace` 的推导数据源（粗定位 GPS/Wi-Fi/蜂窝）走系统定位授权（D8 位置敏感级 S2：默认关闭，需用户显式开启）。

### 2.5 三级档位与敏感场景（评审确认）

**评审结论：通过**

- 亮屏/前台档（全手势，KPI 判定 ≤150ms/收声 ≤300ms P95）、锁屏/深睡档（硬件级事件 + 提示先行 + 取消窗补偿）、敏感场景档（全停）——D9 §8.5c 设计评审通过；
- 敏感场景强制全停（通话/支付/输入聚焦/安全窗口，R12.4）；「姿态交互」总开关一键全停（D9 §8.3）；
- MotionHub 为传感器唯一常驻消费方（R12.1）、第三方不可读（R12.2，签名 + SE 收紧）——联动 E5.4 渗透验收。

## 4. 验收口径

- [ ] 收声启动 ≤300ms（P95）；预告/取消窗 ≤300ms 呈现。
- [ ] 3s 取消窗内放弃 → 无文件/无索引/审计记「已取消」；重复手势不可绕过取消窗。
- [ ] 录音活性指示 ≤100ms 显示且不可被隐藏（Agent 尝试隐藏被拒）。
- [ ] 摇一摇就绪后无自动快门；就绪空转 15-30s 自动退出；遮挡/隐私关闭时不就绪。
- [ ] `coarsePlace` 不出端（抓包 + 渗透核验）；位置授权缺失退化 `无地点_*`。
- [ ] 敏感场景（通话/支付/输入聚焦/安全窗口）备忘收声与手势全停。
- [ ] 显著误触发 <1 次/周/用户（遥测，联动 H4.3 功耗差分）。

## 5. 遗留项

1. **可听提示音的地区矩阵**：各司法辖区对持续环境录音提示音要求的清单维护（法务 + 地区配置 OTA）。
2. **无遮挡传感器的机型弱判定**：D9 §8.5a 降级路径（弱判定 + 3s 取消窗兜底）的误触发实测。
3. **备忘文件的内容索引边界**：录音内容是否做本地 ASR 索引（供搜索）需单独评审（本意见默认**不索引内容**，仅文件名元数据）。
4. **就绪空转的功耗实测**：相机预览空转功耗（D9 §8.5b，数百 mW 级）的实验室验证与上限收紧。
