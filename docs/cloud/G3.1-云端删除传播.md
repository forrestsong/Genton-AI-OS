# G3.1 云端删除传播设计

> **任务编号**：G3.1
> **任务名称**：云端删除传播（设备 forget → 云级联删除与删除证明、保留窗口策略）
> **交付物**：删除传播服务
> **前置依赖**：G2.1（设备远程证明服务端）、E3.3（遗忘与删除传播评审）
> **草案来源**：D13（轨道A-端云调度与推理路由接口草案.md §5 删除传播）、D4（轨道A-记忆服务与审计引擎接口草案.md）
> **里程碑**：A3（智能与端云）
> **状态**：设计稿（待实现）

---

## 1. 摘要

云端删除传播把端侧"忘记 X"（`IAgentMemoryService.forget`）的语义延伸到云端：当用户忘记某实体/话题且请求包含 `confirmCloudDeletion` 删除凭证时，云端必须**级联删除**该实体在云端的全部副本——Broker 处理缓存、上下文快照、联邦微调样本（若在保留窗口内）——并回执**可审计的删除证明**（D13 §8 开放问题 6）。

核心约束：

- **SLA**：云端删除传播 ≤24 小时完成（红线 R7.10 / R11.13）。
- **级联语义**：与端侧"实体图级删除"（D4/R11.12）对应：删除实体 → 关联向量/图谱节点 → 云端缓存/样本。
- **删除证明**：Broker 回执签名删除证明（含被删条目哈希列表），端侧可验证（防"假删除"）。
- **保留窗口策略**：联邦微调样本有保留窗口（训练批次未冻结前可撤回）；窗口外已进入模型权重的样本无法删除，只能"去贡献"（G4.1 联合）。

---

## 2. 职责

| 职责 | 说明 |
|---|---|
| 删除凭证接收 | 接收端侧 `ForgetRequest.confirmCloudDeletion` 生成的删除凭证（`DeleteCredential`） |
| 级联删除 | 删除 Broker 缓存/上下文快照/转写样本/联邦微调样本（保留窗口内） |
| 删除证明 | 生成签名删除证明（deletionReceipt）：被删条目 ID 哈希列表 + 时间戳 + Broker 签名 |
| 保留窗口管理 | 联邦样本保留窗口（冻结前可删）；窗口外 → "去贡献"委托 G4.1 |
| 级联索引 | 维护"实体 → 云端副本引用"索引（供反向查找待删条目），删除后同步清索引 |
| 删除审计 | 删除请求/执行/证明全审计（G5.1 → A5.3）；撤销记录不可删（R11.14） |

## 3. 接口契约

### 3.1 删除凭证提交（设备 → 云）

端点：`POST /v1/deletion/request`（HTTPS + mTLS + 会话票据）

```json
{
  "deletionId": "del_01HZ...",
  "deviceKeyHash": "sha256:9f2c...b1e0",
  "credential": {
    "type": "forget_entity",             // forget_entity | forget_topic | forget_all
    "entity": "客户A",                    // 实体/话题描述（与端侧 ForgetRequest.topic 一致）
    "entityRefs": ["ent_graph:0x3F2A", "ent_vector:0x9C11"],  // 端侧实体引用（可对应到云缓存引用）
    "confirmCloudDeletion": true,        // 与 ForgetRequest.confirmCloudDeletion 一致
    "reason": "user_initiated",
    "issuedAtMs": 1737000000000,
    "deviceSignature": "<设备私钥签名>"
  },
  "scope": ["broker_cache", "context_snapshot", "finetune_samples"]
}
```

响应（受理）：

```json
{
  "deletionId": "del_01HZ...",
  "status": "ACCEPTED",
  "estimatedCompletionMs": 3600000,      // SLA ≤24h
  "receiptUrl": "/v1/deletion/receipt/del_01HZ..."
}
```

### 3.2 删除证明回执（云 → 设备）

端点：`GET /v1/deletion/receipt/{deletionId}`（设备轮询或推送）

```json
{
  "deletionId": "del_01HZ...",
  "status": "COMPLETED",                 // ACCEPTED | RUNNING | COMPLETED | PARTIAL | FAILED
  "completedAtMs": 1737003600000,
  "deleted": [
    { "refId": "cache:0x7F1A", "kind": "broker_cache", "deletedAtMs": 1737000300000 },
    { "refId": "ctx:0x2B88", "kind": "context_snapshot", "deletedAtMs": 1737000500000 },
    { "refId": "sample:0xD3C4", "kind": "finetune_sample", "deletedAtMs": 1737000800000 }
  ],
  "retained": [
    { "refId": "weight:0xA1B2", "kind": "finetune_weight", "reason": "beyond_retention_window", "mitigation": "unlearning_requested_g41" }
  ],
  "receiptSignature": "<Broker 签名>",
  "receiptHashChainRef": "audit:seq_88231"   // 汇入审计链的引用
}
```

### 3.3 状态查询

端点：`GET /v1/deletion/status/{deletionId}`

```json
{
  "deletionId": "del_01HZ...",
  "status": "RUNNING",
  "progress": { "total": 12, "done": 7, "failed": 0 },
  "etaMs": 1800000
}
```

## 4. 保留窗口策略

| 数据类型 | 保留窗口 | 窗口内删除 | 窗口外 |
|---|---|---|---|
| Broker 推理缓存 | 立即/短缓存（小时级） | 级联删除 | —（无长期缓存，处理即弃） |
| 上下文快照（contextDelta 引用） | 会话 + 24h | 级联删除 | 自动过期清除 |
| 转写样本（transcribe） | 处理即弃（不保留） | — | — |
| 联邦微调样本 | **训练批次冻结前**（默认 30 天，G4.1 定义） | 样本删除 + 该批聚合重算 | 已进入权重 → 委托 G4.1 "去贡献"（unlearning/聚合重算） |
| 审计摘要（非正文） | 按 G3.2 留存策略 | **不可删除**（审计链只增不改，R8.4） | — |

> **边界**：审计链只存"摘要+哈希+证据引用 id"（D4 §3.1），不含正文；删除传播删除的是**正文证据**，审计摘要保留（对齐 D4 §6 开放问题 5/6 的证据分层）。

## 6. 安全边界

- **凭证真实**：删除凭证由设备私钥签名；只有已远程证明（G2.1）的设备能提交（防恶意删除他人数据）。
- **删除最小集**：只删除 `entityRefs` 对应的云端副本；不可因删除请求扩大删除范围（防误删）。
- **证明防伪造**：删除证明带 Broker 签名；`receiptHashChainRef` 引用审计链，端侧可校验"删除确实发生"。
- **不可否认**：撤销/删除记录入审计链，不可修改删除（R11.14、R8.4）。
- **窗口内不可逆**：窗口内样本删除后不可恢复（对齐 R11.15 敏感数据物理清零——云侧对样本存储做安全擦除）。
- **审计与删除分离**：审计摘要不随正文删除（证据分层，D4 §3.1）。
- **SLA 强制**：删除任务 24h 内必须 COMPLETED 或 PARTIAL（可解释）；超时 → 升级告警（G5.1/G5.2 事件）。

## 7. 部署形态

- 删除传播服务独立部署（无状态 + 任务队列），任务状态存 PostgreSQL。
- 实体→副本索引存储（分布式 KV），删除后同步清索引条目。
- 联邦样本库删除由 G4.1 服务执行（删除接口 + 去贡献接口），G3.1 只编排。
- 删除证明生成在 HSM 签名（对齐密钥方案）。
- 接收端（Broker 等）通过事件订阅或 RPC 被调度删除；删除结果回写任务队列。

## 8. 与端侧联动

| 端侧 | 联动点 |
|---|---|
| `IAgentMemoryService.forget()` | `ForgetRequest.topic/entity` → 删除凭证实体；`confirmCloudDeletion=true` 触发云端删除 |
| `ForgetJob` | `cloudSyncPending` 状态：云端删除完成后置 false；`error` 记录删除失败原因 |
| `IAgentAuditService` | 端侧记录"用户发起忘记:客户A"（CAT_MEMORY_ACCESS，D4 场景 B）；云侧删除证明哈希可对账 |
| A5.1 记忆服务端 | 端侧实体图级删除（D4/R11.12）与云侧级联一一对应 |
| 隐私仪表盘 | 展示"云删除状态"（COMPLETED/retained 清单），链完整校验（D4 场景 C） |
| `CloudGateway` | 出网删除凭证通道（HTTPS + mTLS + 票据） |
| G2.2 | 设备丢失后"忘记并注销" → 吊销 + 删除传播联动 |

## 9. 验收口径

- [ ] 删除传播 ≤24 小时完成（R7.10/R11.13）；状态机 ACCEPTED→RUNNING→COMPLETED/PARTIAL/FAILED 完整
- [ ] Broker 缓存/上下文快照/窗口内联邦样本全部级联删除；实体索引同步清除
- [ ] 删除证明带 Broker 签名，端侧验签通过；receipt 引用审计链
- [ ] 窗口外样本返回 retained + mitigation（去贡献请求），不静默忽略
- [ ] 未签名凭证/未证明设备提交删除 → 拒绝
- [ ] 撤销/删除记录不可修改删除（R11.14）；审计摘要保留（正文删除不影响链）
- [ ] 敏感样本安全擦除（R11.15 云端对偶）
- [ ] H3.4 e2e：删除传播联动（forget → 云端删除 → 回执）通过
- [ ] 删除任务超时 → G5.1/G5.2 告警升级

## 10. 遗留项

1. **去贡献（unlearning）**：窗口外已进入模型权重的样本"去贡献"具体算法（G4.1 聚合重算 vs 近似 unlearning）需联合 G4.1 冻结。
2. **删除证明格式标准化**：receipt 的 JSON Schema 与端侧校验 SDK 待定稿（D13 §8 开放问题 6 关闭条件）。
3. **实体引用映射**：端侧实体引用（ent_graph/ent_vector）↔ 云端副本引用的映射规则需在 E3.3 评审后定稿。
4. **跨 Broker 供应商删除**：多供应商场景下删除传播需穿透到上游供应商（G1.1 遗留项 1 联动）。
5. **批量忘记**："忘记全部"（forget_all）的大规模删除性能与 24h SLA 联合验证。
