## 1. 权限最小化（Least Privilege）

### 1.1 系统服务权限

**红线规则**：

- ❌ **禁止**：所有 `com.genton.*` 服务使用 `dangerous` 权限
- ✅ **必须**：所有系统服务权限声明为 `signature|privileged`
- ✅ **必须**：每个服务接口有独立权限（不得共用通用权限）

**正确示例**：

```xml
<!-- overlay/frameworks/base/core/res/AndroidManifest.xml -->
<permission
    android:name="com.genton.permission.READ_UI_TREE"
    android:protectionLevel="signature|privileged"
    android:label="@string/perm_read_ui_tree"
    android:description="@string/perm_read_ui_tree_desc" />

<permission
    android:name="com.genton.permission.EXECUTE_ACTIONS"
    android:protectionLevel="signature|privileged"
    android:label="@string/perm_execute_actions"
    android:description="@string/perm_execute_actions_desc" />
```

**错误示例**：

```xml
<!-- ❌ 错误：使用 dangerous 权限 -->
<permission
    android:name="com.genton.permission.READ_SCREEN"
    android:protectionLevel="dangerous" />

<!-- ❌ 错误：多个服务共用通用权限 -->
<permission android:name="com.genton.permission.USE_AGENT" />
<!-- 所有服务都用这个权限 → 违反最小权限原则 -->
```

**检查方法**：

```bash
# 自动化检查
python tools/security_audit.py --checklist E1.1

# 手动检查
grep -r "android:protectionLevel" overlay/frameworks/base/core/res/AndroidManifest.xml | grep genton
```

### 1.2 能力粒度控制

**红线规则**：

- ✅ **必须**：每个动作映射到明确的 `capability`（不得使用通配符）
- ✅ **必须**：未注册的 capability 返回 `DENY`（不得返回 `UNKNOWN` 或 `ALLOW`）
- ✅ **必须**：敏感能力标记为 `high` 风险

**敏感能力清单**：

| 能力 | 风险等级 | 原因 |
|------|---------|------|
| `messages.send` | high | 发送短信可能产生费用/泄露信息 |
| `calls.place` | high | 拨打电话可能产生费用 |
| `share.content` | high | 分享内容到外部应用 |
| `calendar.delete` | high | 不可逆删除用户数据 |
| `account.access` | high | 访问账户凭据 |

**正确示例**：

```json
// overlay/vendor/genton/config/action_registry.json
{
  "actions": [
    {
      "name": "messages.send",
      "executorId": "telephony",
      "riskLevel": "high",
      "requiredCapability": "messages.send",
      "inputSource": ["user", "trusted_system"]
    }
  ]
}
```

**错误示例**：

```json
// ❌ 错误：未映射 capability
{
  "name": "messages.send",
  "executorId": "telephony"
  // 缺少 requiredCapability
}

// ❌ 错误：敏感动作未标记高风险
{
  "name": "messages.send",
  "riskLevel": "low"  // 应为 high
}
```

## 2. Deny 默认（Fail-Secure）

### 2.1 策略引擎

**红线规则**：

- ✅ **必须**：无匹配规则时，授权轴默认返回 `DENY`
- ✅ **必须**：无匹配规则时，路由轴默认返回 `P0_NATIVE`（可见）
- ✅ **必须**：策略编译失败时，系统拒绝启动（fail-stop）

**正确示例**：

```java
// PolicyEngine.java
public PolicyDecision evaluateIntent(IntentContext ctx) {
    // 阶段一：基线规则（不可覆盖）
    PolicyDecision baseline = evaluateBaseline(ctx);
    if (baseline.decision == Decision.DENY) {
        return baseline;  // 基线 DENY 直接返回
    }
    
    // 阶段二：自定义规则
    for (Rule rule : sortedRules) {
        if (rule.matches(ctx)) {
            return rule.decision;
        }
    }
    
    // ✅ 默认 DENY（无匹配）
    return PolicyDecision.DENY;
}
```

**错误示例**：

```java
// ❌ 错误：默认 ALLOW
if (rule.matches(ctx)) {
    return rule.decision;
}
return PolicyDecision.ALLOW;  // 危险！

// ❌ 错误：返回 UNKNOWN 让调用方自行判断
return PolicyDecision.UNKNOWN;
```

**单元测试**（H2.1）：

```java
@Test
public void testDefaultDeny() {
    PolicyEngine engine = new PolicyEngine(emptyRuleSet);
    PolicyDecision decision = engine.evaluateIntent(
        new IntentContext("unknown.capability", agentId)
    );
    assertEquals(Decision.DENY, decision.decision);
}
```

### 2.2 能力令牌

**红线规则**：

- ✅ **必须**：令牌签名失败时，调用被拒绝（不得降级到免验证）
- ✅ **必须**：令牌过期后立即失效（不得有宽限期）
- ✅ **必须**：撤销列表查询失败时，拒绝调用（fail-secure）

**正确示例**：

```java
// TokenValidator.java
public boolean validateToken(CapabilityToken token) {
    // 1. 签名验证
    if (!verifySignature(token)) {
        Log.w(TAG, "Token signature invalid");
        return false;  // ✅ 签名失败拒绝
    }
    
    // 2. 过期检查
    if (token.expiresAt < System.currentTimeMillis()) {
        return false;  // ✅ 过期立即拒绝
    }
    
    // 3. 撤销列表检查
    try {
        if (revokedTokens.contains(token.tokenId)) {
            return false;
        }
    } catch (Exception e) {
        // ✅ 查询失败 → fail-secure 拒绝
        Log.e(TAG, "Revocation check failed", e);
        return false;
    }
    
    return true;
}
```

**错误示例**：

```java
// ❌ 错误：签名失败时降级
if (!verifySignature(token)) {
    // 降级到 UID 校验（不安全）
    return checkUid(token.agentId);
}

// ❌ 错误：异常时返回通过
try {
    return !revokedTokens.contains(token.tokenId);
} catch (Exception e) {
    return true;  // 危险！应返回 false
}
```

## 3. Taint 纪律（Content Trust）

### 3.1 来源标注

**红线规则**：

- ✅ **必须**：所有感知 API 返回包含 `TrustLevel`
- ✅ **必须**：`APP_CONTENT` / `WEB_CONTENT` 打 taint 标记
- ✅ **必须**：动作参数来源与注册表 `inputSource` 不符时拒绝执行

**TrustLevel 定义**：

```java
// com.genton.perception.TrustLevel
public enum TrustLevel {
    TRUSTED_SYSTEM,   // 系统感知（UI 树/通知元数据）
    USER_INPUT,       // 用户显式输入（语音/文字）
    APP_CONTENT,      // App 内容（通知正文/页面文本）
    WEB_CONTENT       // Web 内容（浏览器页面）
}
```

**正确示例**：

```java
// IAgentUiTreeService 实现
public UiTreeSnapshot getUiTree(...) {
    UiTreeSnapshot snapshot = captureUiTree();
    
    // ✅ 标注来源
    for (UiNode node : snapshot.nodes) {
        if (node.packageName.equals("com.android.systemui")) {
            node.trustLevel = TrustLevel.TRUSTED_SYSTEM;
        } else {
            node.trustLevel = TrustLevel.APP_CONTENT;
        }
    }
    
    return snapshot;
}
```

**动作参数校验**：

```java
// IAgentActionService 实现
public ActionResult submitAction(ActionRequest request) {
    Action action = registry.getAction(request.actionName);
    
    // ✅ 校验 taint
    for (String key : request.taintedArgumentKeys) {
        if (!action.inputSource.contains("app") && 
            !action.inputSource.contains("web")) {
            return ActionResult.error("TAINT_DENIED", 
                "参数 " + key + " 来源不可信");
        }
    }
    
    // ... 继续执行
}
```

### 3.2 记忆投毒防护

**红线规则**：

- ✅ **必须**：记忆写入校验 `provenance`（来源）
- ✅ **必须**：低置信度实体（<0.6）不得进入 `packContext`
- ✅ **必须**：`APP_CONTENT` 不得直接提升为长期记忆（除非用户确认）

**正确示例**：

```java
// IAgentMemoryService 实现
public MemoryEntry write(MemoryDraft draft) {
    // ✅ 校验 provenance
    if (draft.provenance == null || draft.provenance.source == null) {
        throw new IllegalArgumentException("Missing provenance");
    }
    
    // ✅ APP_CONTENT 需用户确认
    if (draft.trustLevel == TrustLevel.APP_CONTENT && 
        draft.tier == MemoryTier.LONG_TERM &&
        !draft.userConfirmed) {
        throw new SecurityException("APP_CONTENT requires user confirmation for LONG_TERM");
    }
    
    // ... 写入
}
```

## 4. Secret 值安全路径（Secret Handling）

### 4.1 密码/凭据

**红线规则**：

- ❌ **禁止**：`secret=true` 字段值落入日志/审计/记忆
- ✅ **必须**：密码输入框标记为 `FLAG_SECURE`
- ✅ **必须**：凭据值只通过 Keystore/TEE 通道传递

**正确示例**：

```java
// 审计日志处理 secret 字段
public void recordActionExecuted(ActionRequest request) {
    JsonObject auditPayload = new JsonObject();
    
    for (Map.Entry<String, Object> param : request.parameters.entrySet()) {
        if (isSecretField(param.getKey())) {
            // ✅ 只记录存在性，不记录值
            auditPayload.put(param.getKey(), "<redacted>");
        } else {
            auditPayload.put(param.getKey(), param.getValue());
        }
    }
    
    auditLog.record("action_executed", auditPayload);
}
```

**UI 树掩码**：

```java
// UI 树采集时过滤密码字段
public UiNode captureNode(AccessibilityNodeInfo node) {
    UiNode uiNode = new UiNode();
    
    if (node.isPassword() || node.getInputType() == TYPE_TEXT_VARIATION_PASSWORD) {
        // ✅ 密码字段不返回明文
        uiNode.text = null;
        uiNode.hasValue = true;
        uiNode.isSecret = true;
    } else {
        uiNode.text = node.getText().toString();
    }
    
    return uiNode;
}
```

### 4.2 敏感输入

**红线规则**：

- ✅ **必须**：支付信息输入自动掩码
- ✅ **必须**：OTP 不得进入上下文索引
- ✅ **必须**：密码字段的 UI 树返回 `hasValue=true, text=null`

**敏感字段模式**：

```java
// 敏感字段检测器
private static final Pattern[] SENSITIVE_PATTERNS = {
    Pattern.compile("password", Pattern.CASE_INSENSITIVE),
    Pattern.compile("passcode", Pattern.CASE_INSENSITIVE),
    Pattern.compile("pin", Pattern.CASE_INSENSITIVE),
    Pattern.compile("cvv", Pattern.CASE_INSENSITIVE),
    Pattern.compile("card.*number", Pattern.CASE_INSENSITIVE),
    Pattern.compile("otp", Pattern.CASE_INSENSITIVE),
    Pattern.compile("验证码", Pattern.CASE_INSENSITIVE)
};

public boolean isSensitiveField(String fieldName) {
    for (Pattern p : SENSITIVE_PATTERNS) {
        if (p.matcher(fieldName).find()) {
            return true;
        }
    }
    return false;
}
```

## 5. 确认宿主独占（Confirmation Integrity）

### 5.1 SystemUI 独占

**红线规则**：

- ❌ **禁止**：Agent 自我确认（必须由 SystemUI 展示）
- ✅ **必须**：确认面板使用 `FLAG_SECURE` 全屏（防截图/录屏）
- ✅ **必须**：确认结果直回执行中介（不经过大脑 App）

**架构约束**：

```
正确流程：
  大脑 → 执行中介 → 策略引擎（需确认） → SystemUI 确认面板 → 用户操作 → 执行中介

错误流程：
  大脑 → 自建确认 Dialog → 用户操作 → 执行中介  ❌ 违规！
```

**正确示例**：

```java
// SystemUI 中的确认面板
public class AgentConfirmationDialog extends AlertDialog {
    public AgentConfirmationDialog(Context context, ConfirmationUiRequest request) {
        super(context);
        
        // ✅ 设置 FLAG_SECURE
        getWindow().setFlags(
            WindowManager.LayoutParams.FLAG_SECURE,
            WindowManager.LayoutParams.FLAG_SECURE
        );
        
        // 全屏显示（防止 tapjacking）
        getWindow().setType(WindowManager.LayoutParams.TYPE_SYSTEM_ALERT);
    }
    
    private void onUserConfirm() {
        // ✅ 直接调用 framework 服务（不回大脑）
        IAgentActionService service = getActionService();
        service.confirmAction(confirmId, true);
        dismiss();
    }
}
```

### 5.2 防伪造

**红线规则**：

- ✅ **必须**：`confirmId` 由策略引擎 HMAC 签发
- ✅ **必须**：Agent 提交伪造的 `confirmId` 被拒绝
- ✅ **必须**：确认超时后，动作状态为 `EXPIRED`（不得执行）

**confirmId 生成**：

```java
// IPolicyEngine 实现
public String generateConfirmId(ActionRequest request) {
    String payload = String.format(
        "%s|%s|%s|%d",
        request.actionName,
        request.agentId,
        request.sourceIntentId,
        System.currentTimeMillis()
    );
    
    // ✅ HMAC 签名（密钥在 TEE）
    byte[] signature = hmacSha256(confirmSecret, payload.getBytes());
    return Base64.encodeToString(signature, Base64.NO_WRAP);
}

public boolean verifyConfirmId(String confirmId, ActionRequest request) {
    String expected = generateConfirmId(request);
    // ✅ 恒定时间比较（防时序攻击）
    return MessageDigest.isEqual(
        confirmId.getBytes(),
        expected.getBytes()
    );
}
```

## 6. FLAG_SECURE 边界（Secure Content）

### 6.1 截图保护

**红线规则**：

- ❌ **禁止**：截取安全窗口（密码/支付/银行 App）
- ✅ **必须**：检测到 `FLAG_SECURE` 时，返回掩码帧或 `STATUS_SECURE_CONTENT`
- ✅ **必须**：掩码区域标记在 `secureRegions` 字段

**正确示例**：

```java
// IAgentScreenService 实现
public ScreenFrame captureScreen(String taskId) {
    // ✅ 检测 FLAG_SECURE 窗口
    List<WindowState> secureWindows = detectSecureWindows();
    
    if (!secureWindows.isEmpty() && !hasScreenCapturePermission(taskId)) {
        // ✅ 全屏安全 → 拒绝
        if (isFullScreen(secureWindows.get(0))) {
            return ScreenFrame.error("STATUS_SECURE_CONTENT");
        }
        
        // ✅ 部分安全 → 返回掩码帧
        Bitmap frame = captureWithMask(secureWindows);
        return ScreenFrame.success(frame, secureWindows);
    }
    
    return ScreenFrame.success(captureFullScreen(), Collections.emptyList());
}
```

**掩码实现**：

```java
private Bitmap captureWithMask(List<WindowState> secureWindows) {
    Bitmap frame = SurfaceControl.screenshot(...);
    Canvas canvas = new Canvas(frame);
    
    Paint maskPaint = new Paint();
    maskPaint.setColor(Color.BLACK);
    
    for (WindowState window : secureWindows) {
        Rect bounds = window.getBounds();
        // ✅ 绘制黑色遮罩
        canvas.drawRect(bounds, maskPaint);
    }
    
    return frame;
}
```

## 7. 审计完整性（Audit Integrity）

### 7.1 防篡改

**红线规则**：

- ✅ **必须**：审计事件形成 SHA-256 哈希链
- ✅ **必须**：哈希链周期性锚定到 TEE（或启动时 boot_id）
- ❌ **禁止**：审计日志 update/delete 操作（只允许 insert）

**哈希链实现**（参考 openphone）：

```java
// AuditLog.java
public void record(String eventType, JsonObject detail) {
    AuditEvent event = new AuditEvent();
    event.seq = nextSeq++;
    event.bootId = bootId;  // ✅ 启动会话标识
    event.timestampWallMs = System.currentTimeMillis();
    event.timestampElapsedMs = SystemClock.elapsedRealtime();
    event.eventType = eventType;
    event.detail = detail.toString();
    
    // ✅ 计算哈希链
    event.prevHash = lastHash;
    String payload = String.format(
        "%d|%s|%d|%s|%s",
        event.seq, event.bootId, event.timestampWallMs,
        event.prevHash, event.detail
    );
    event.hash = sha256(payload);
    
    // ✅ 只增不改
    events.add(event);
    lastHash = event.hash;
    
    // 持久化
    persistToFile();
}

// ✅ 启动时验证完整性
public boolean verifyIntegrity() {
    String computedHash = "0000...";  // 初始哈希
    
    for (AuditEvent event : events) {
        if (!event.prevHash.equals(computedHash)) {
            Log.e(TAG, "Hash chain broken at seq=" + event.seq);
            return false;
        }
        
        String payload = String.format(...);
        String expectedHash = sha256(payload);
        
        if (!event.hash.equals(expectedHash)) {
            Log.e(TAG, "Hash mismatch at seq=" + event.seq);
            return false;
        }
        
        computedHash = event.hash;
    }
    
    return true;
}
```

### 7.2 证据分离

**红线规则**：

- ✅ **必须**：审计链只存摘要+哈希+证据引用 ID
- ✅ **必须**：原始证据（截图/录音）按策略存冷存储
- ✅ **必须**：删除证据时，审计链记录保留（tombstone）

**架构**：

```
审计链（不可变）:
  {seq: 123, eventType: "screen_capture", evidenceId: "ev-456", hash: "..."}

证据存储（可删除）:
  /data/system/genton/evidence/ev-456.png

删除后：
  审计链不变，evidenceId 指向已删除证据（tombstone 标记）
```

**实现**：

```java
public void recordScreenCapture(String taskId, Bitmap screenshot) {
    // 1. 保存证据
    String evidenceId = UUID.randomUUID().toString();
    File evidenceFile = new File(evidenceDir, evidenceId + ".png");
    saveScreenshot(screenshot, evidenceFile);
    
    // 2. 审计链只记录引用
    JsonObject detail = new JsonObject();
    detail.put("taskId", taskId);
    detail.put("evidenceId", evidenceId);
    detail.put("evidenceType", "screenshot");
    // ✅ 不记录截图内容本身
    
    auditLog.record("screen_capture", detail);
}

public void deleteEvidence(String evidenceId) {
    File evidenceFile = new File(evidenceDir, evidenceId + ".png");
    evidenceFile.delete();
    
    // ✅ 审计链记录删除操作（不删除原记录）
    JsonObject detail = new JsonObject();
    detail.put("evidenceId", evidenceId);
    detail.put("deletedAt", System.currentTimeMillis());
    auditLog.record("evidence_deleted", detail);
}
```
