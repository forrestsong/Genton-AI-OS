### 任务目标

建立 MotionHub 姿态交互体系的硬件基线，确保 S7 功能在目标设备上可实现：
1. 与主要 SoC/OEM 签署 NDA
2. 确认传感器清单与能力位
3. 评估三级档位（亮屏前台/深睡事件/敏感全停）的可行性
4. 生成 ≥2 个目标机型的能力位确认报告

## 2. 硬件能力位清单（Sensor Capability Matrix）

### 2.1 核心传感器要求

| 传感器类型 | 必需级别 | 用途 | 关键参数 | 档位依赖 |
|-----------|---------|------|---------|---------|
| **加速度计 (Accelerometer)** | P0 必需 | 摇一摇就绪、翻面检测 | 量程 ±8g，采样率 ≥100Hz | 亮屏前台/深睡 |
| **陀螺仪 (Gyroscope)** | P1 增强 | 手势轨迹精细化 | 采样率 ≥100Hz | 亮屏前台 |
| **接近传感器 (Proximity)** | P0 必需 | 遮挡检测、通话状态 | 触发延迟 <50ms | 全档位 |
| **光线传感器 (Ambient Light)** | P1 增强 | 环境光上下文 | 量程 0.1–100k lux | 亮屏前台 |
| **重力传感器 (Gravity)** | P1 增强 | 翻面状态推理 | 融合型（软件合成） | 深睡 |
| **传感器枢纽 (Sensor Hub)** | P0 必需 | 低功耗深睡事件检测 | AON 岛支持、自定义手势引擎 | 深睡档位 |

## 5. 硬件能力位表 v0.1

### 5.1 能力位编码方案

每个机型分配 **32 位能力位掩码**（Capability Bitmask）：

```java
public class MotionHubCapabilities {
    // 传感器能力位 (bit 0-7)
    public static final int CAP_ACCELEROMETER       = 1 << 0;  // 加速度计
    public static final int CAP_GYROSCOPE           = 1 << 1;  // 陀螺仪
    public static final int CAP_PROXIMITY           = 1 << 2;  // 接近传感器
    public static final int CAP_AMBIENT_LIGHT       = 1 << 3;  // 光线传感器
    public static final int CAP_GRAVITY             = 1 << 4;  // 重力传感器
    
    // 高级能力位 (bit 8-15)
    public static final int CAP_SENSOR_HUB_AON      = 1 << 8;  // AON 岛支持
    public static final int CAP_CUSTOM_GESTURE_API  = 1 << 9;  // 自定义手势引擎
    public static final int CAP_HIGH_SAMPLE_RATE    = 1 << 10; // 高采样率 (>800Hz)
    public static final int CAP_LOW_POWER_MODE      = 1 << 11; // 微功耗模式
    
    // 隐私硬件位 (bit 16-23)
    public static final int CAP_CAMERA_SHUTTER_HW   = 1 << 16; // 相机遮挡传感器
    public static final int CAP_MIC_KILL_SWITCH     = 1 << 17; // 麦克风硬开关
    public static final int CAP_CAMERA_LED_ENFORCE  = 1 << 18; // 相机 LED 强制
    
    // 档位支持位 (bit 24-31)
    public static final int CAP_TIER_FOREGROUND     = 1 << 24; // 支持亮屏前台档位
    public static final int CAP_TIER_DEEP_SLEEP     = 1 << 25; // 支持深睡档位
    public static final int CAP_TIER_SENSITIVE_STOP = 1 << 26; // 支持敏感全停
}
```

## 6. 关键发现与风险

### 6.1 关键发现

1. **高端平台能力充足**: Snapdragon 8 Gen 2+ 和 Dimensity 9300 完全满足三级档位要求
2. **中端平台需降级**: 无 AON 岛的平台深睡功耗不可接受（50mW vs 0.5mW），必须禁用深睡手势
3. **隐私硬件缺失**: 大部分机型无相机遮挡传感器和麦克风硬开关，需软件策略补偿
4. **采样率差异**: 高端 1600Hz vs 中端 400Hz，手势识别精度有差异

### 6.2 风险与缓解

| 风险 | 影响 | 缓解措施 | 责任人 |
|------|------|---------|--------|
| **中端机型深睡功耗过高** | 用户投诉续航 | 降级方案：禁用深睡手势 | A12.2b |
| **相机遮挡传感器缺失** | 隐私风险 | 软件推理（光线+接近组合） | E5.4 |
| **自定义手势引擎差异** | 跨平台兼容性 | HAL 抽象层统一接口 | A12.1 |
| **OEM 固件更新延迟** | 功能不可用 | 回退到 Android 标准 API | A12.1 |
