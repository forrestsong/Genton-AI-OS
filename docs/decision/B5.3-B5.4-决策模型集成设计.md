## 1. 目标

把 **NeoHorse-Jev-4B**（prefill-only 结构化决策模型，Choice/Noul/Score 三类）落地为系统内**统一决策源**，按机型能力分为**旗舰版（端侧推理）与通用版（云端 API）双版本**：

- **B5.3**：决策模型服务（`IAgentDecisionService`）——**双后端**：旗舰版本地推理（模型包/加载/缓存/计量/审计）+ 通用版云端路由（`IAgentInferenceRouter` TIER_CLOUD → CloudBroker `/v1/decision`）。
- **B5.4**：决策适配器集——把三类决策映射到各业务点（意图/工具/分类/反骚扰/档位/预测），带独立阈值表与 fail-safe 降级；**后端无关**（业务方无感）。

对齐红线：**模型只出"带概率的建议"，授权/路由常量/deny 默认仍由策略引擎（A7）确定性裁决。**

## 2. 双版本部署原则（0.2 增补，来自产品决策）

| 维度 | 旗舰版（本地推理） | 通用版（云端 API） |
|---|---|---|
| 目标机型 | 第五代骁龙 8 至尊版 / 天玑 9500 / Exynos 2500 顶配旗舰 | 其余全部机型 |
| 决策模型权重 | 内置（签名包随系统镜像/OTA，~10GB 预算） | 不内置（0 本地占用） |
| 推理位置 | 端侧 NPU/CPU（vLLM/SGLang/原生 `neohorse_decision` runtime） | 云端决策服务（CloudBroker `/v1/decision`） |
| 路由 | `IAgentDecisionService` → 本地推理后端 | `IAgentDecisionService` → `IAgentInferenceRouter` TIER_CLOUD → CloudBroker |
| 延迟预算 | P95 ≤100ms（NPU）/ ≤150ms（CPU） | 端到端 P95 ≤300ms（含证明/网络；断线降级规则路径） |
| 隐私 | 决策不出设备 | 仅脱敏最小字段出端；金融/健康/账号类一律本地规则路径 |
| 计量 | token/energy 入 ACB（B5.2） | 云端 usage 签名回传对账（G1.2） |
| 机型判定 | `decision_local_capable: true`（旗舰 SoC 白名单） | `decision_local_capable: false` |
| 适配器（B5.4） | 同一适配器集，后端由能力位切换 | 同左 |

**后端切换**：`IAgentDecisionService` 在启动/机型变化时按 `device_capability_table_v1.json` 的 `decision_local_capable` 选择本地或云端后端；业务方（B2.1/B2.2/C4.x/A9.1/C5.1）只调用统一接口，不感知后端。

**降级链（双版本通用）**：本地模型不可用 → 云端（若允许）→ 规则/确定性路径 → 显式 P0/原生；云端不可达 → 规则/显式路径。任一决策点不因模型后端而阻塞。

## 2. IAgentDecisionService 接口契约（草案）

```aidl
// com.genton.decision (0.4 新增 AIDL 模块)
package com.genton.decision;

/**
 * 本地决策模型服务（B5.3）。
 * prefill-only：一次前向返回类型化决策 + 概率，不生成自由文本。
 * 调用方携带 capability 令牌；结果落审计链（模型版本+输入摘要+概率最小集）。
 */
interface IAgentDecisionService {
    /** Choice：候选选择，返回选中候选 + 全候选概率分布 */
    DecisionResult choose(in DecisionRequest request);

    /** Noul：是非判定，返回 P(true) */
    DecisionResult judge(in DecisionRequest request);

    /** Score：分级评分，返回等级分布 + 期望分 */
    DecisionResult score(in DecisionRequest request);
}

parcelable DecisionRequest {
    // 场景标识（用于阈值表/审计/计量）
    String scenario;            // e.g. "intent_classify" / "notification_category" / "callgate_spam"
    // 决策类型对应的输入（state 文本，或 imageRef 指向已掩码的帧）
    String state;
    String imageRef;            // 可选：S5-h 掩码帧引用（单图+文本联合输入）
    // Choice: 有序候选；Noul: 是否问题；Score: 有序等级
    String[] candidates;        // Choice/Score 的候选 key/等级描述
    String question;            // Noul 的是否问题 / 决策指令
    // 硬约束（供候选过滤/路由）：由策略引擎与推理路由注入
    String[] constraints;       // local_only / cloud_denied / offline_ok / low_energy
    // 计量与预算
    long budgetMicros;
}

parcelable DecisionResult {
    String scenario;
    // Choice: 选中候选 + 分布；Noul: P(true)；Score: 期望分 + 分布
    String selected;            // Choice 选中 / Score 期望等级（可小数）
    float confidence;           // Choice 命中概率 / Noul P(true) / Score 加权
    String[] probabilities;     // 全候选概率（与 request.candidates 对齐）
    int modelVersion;
    long latencyMicros;
    int statusCode;             // OK / MODEL_UNAVAILABLE / THRESHOLD_UNSET / BUDGET_EXCEEDED
    String fallbackReason;      // 低置信/降级原因（供 fail-safe 决策）
}
```

> 注：这是契约草案，精确 AIDL 原文由 B5.3 实现时对齐技术架构 §5.1 的 AIDL 生成流程落码。

## 3. B5.4 决策适配器映射表

| 适配器 | 决策类型 | 输入 state 示例 | 候选/问题/等级 | 阈值（独立验证） | 低置信 fail-safe | 消费方 |
|---|---|---|---|---|---|---|
| **intent_classify** | Choice | 用户消息（脱敏） | {open_app, send_msg, query_info, schedule, form_submit, ...} | 命中 ≥0.85 | 升级"复杂任务"或请求澄清 | B2.1 |
| **tool_select** | Choice | 目标 + 可用工具描述 | {dmi:<name>, macro:<name>, skill:<name>, exec:<type>} | 命中 ≥0.8 | 走解析降级链（DMI→macro→L2） | B2.2/§4.8 |
| **notification_category** | Choice | 通知摘要（掩码后） | {p0_native, p1_agent_summary, p2_agent_handle, advertising} | ≥0.75（广告类） | 显式 P0/P1，不静默误吞 | §4.11 S6-a |
| **callgate_spam** | Score | 来电上下文（脱敏） | [低风险, 中风险, 高风险] | 期望分 ≥1.5 → 反骚扰；慢路径回退原生 | 回退 RING_NATIVE | §4.11 S6-b |
| **tier_route** | Choice | 请求特征 + 约束位 | {TIER_LOCAL_TINY, TIER_LOCAL_LARGE, TIER_CLOUD} | 命中 ≥0.9（受 constraints 硬约束） | 默认 local_tiny / 规则路由 | A9.1 |
| **s1_predict** | Choice | 状态特征向量（脱敏） | 候选动作集 | 命中 ≥0.7 才预取（high 预创建/medium 预取） | 不预取（误预取 <2% 口径） | C5.1 |
| **learn_adopt** | Noul | learn. 候选 + 上下文 | 是否采纳 | P(true) ≥0.75 才建议 | 不产生 learn 候选 | C2.x |
| **policy_semantic_when** | Noul | DSL when 语义条件 | 是否成立 | 按策略规则场景设定 | 该条件不匹配（fail-safe deny 侧） | A7.1（可选扩展） |
| **result_selfcheck** | Score | 执行结果 vs 目标 | [未达标, 部分, 达标] | 期望分 <1 → 触发 B2.4 异常自检 | 结合确定性断言双通道 | B2.4 |
| **memo_naming** | Noul/Score | 地点/时间上下文 | 命名合理性 | 按 S7 场景 | 默认命名 `<地点>_<日期>_<时间>.m4a` | S7 备忘收声 |

> **阈值纪律**：每个适配器一条阈值记录 `{scenario, type, threshold, eval_set_ref, updated}`，存 `vendor/genton/config/decision_thresholds_v1.json`；不跨场景借用概率；独立集上验证（NLL/Brier/ECE 待补，见技术架构 §8.3 开放问题②）。

## 4. 部署形态（B5.3 双后端）

| 项 | 旗舰版（本地后端） | 通用版（云端后端） |
|---|---|---|
| 模型分发 | 模型包随系统镜像（签名包）或 §7 权重 OTA 分片/灰度（~10GB 预算） | 不内置；云端决策服务部署于 G1.1 CloudBroker `/v1/decision` 面 |
| 推理后端 | vLLM/SGLang/原生 `neohorse_decision` runtime（NPU 加速；CPU 降级 P95 ≤150ms） | CloudBroker **`/v1/decision`**（[G1.1b 决策接口扩展](../cloud/G1.1b-CloudBroker决策接口扩展.md)，走 mTLS+票据+最小字段） |
| 加载/缓存 | 按需加载 + 决策缓存（同 state+scenario 短时复用）；冷启预算入 ACB | 无本地加载；请求级计量 |
| 计量 | token/energy 走 B5.2 计量协议入 ACB 预算与审计 | 云端 usage 签名回传（G1.2）对账 ACB `AgentBudget` |
| 审计 | 决策结果（模型版本+输入摘要+概率）入 A5.2 审计链 | 同左 + requestId 端云关联（G5.1 汇入 A5.3 全链） |
| 降级链 | 本地不可用 → 云端（若允许）→ 规则/显式路径 | 云端不可达 → 规则/显式路径（断线本地重算） |
| 隐私 | 决策不出设备 | 仅脱敏最小字段出端；金融/健康/账号类本地规则路径禁止出端 |
