# G1.1b CloudBroker 云端决策接口扩展（/v1/decision）

> **关联任务**: G1.1（CloudBroker 网关）扩展、B5.3（决策模型服务通用版后端）、B5.4（决策适配器集）
> **版本**: v0.1　**日期**: 2026-10-05　**状态**: 设计稿（待实现）
> **上游**: [G1.1-CloudBroker网关设计.md](./G1.1-CloudBroker网关设计.md)；技术架构 §4.14（旗舰版/通用版双版本）；docs/decision/B5.3-B5.4-决策模型集成设计.md
> **契约对齐**: 端侧 `com.genton.decision.IAgentDecisionService`（choose/judge/score + DecisionRequest/DecisionResult）
> **前置**: E2.3（端云安全基线）、G2.1（设备远程证明）、G1.2（配额/记账）

## 1. 摘要

为支持**通用版（非旗舰机型）**设备在云端运行 NeoHorse-Jev-4B 决策模型，在 CloudBroker 上新增 **`POST /v1/decision`** 决策接口。该接口与端侧 `IAgentDecisionService` 的**三类决策契约**一一对应：

| 端侧 AIDL | 云端端点 | 决策类型 |
|---|---|---|
| `choose()` | `POST /v1/decision`（`type=choice`） | Choice：候选选择 + 全概率 |
| `judge()` | `POST /v1/decision`（`type=noul`） | Noul：是非判定 P(true) |
| `score()` | `POST /v1/decision`（`type=score`） | Score：分级评分 + 期望分 |

**通用版设备流程**：端侧 `DecisionService.cloudInfer()`（B5.3）→ `IAgentInferenceRouter` TIER_CLOUD → CloudBroker `POST /v1/decision` → 云端决策服务（NeoHorse-Jev-4B 推理）→ 返回 `DecisionResult`（含云端签名 usage）→ 端侧与确定性闸门复核后生效。

**与 G1.1 三个推理面的关系**：`/v1/decision` 是**决策专用面**（prefill-only、无自回归、低 token、强实时性），与文本生成 `/v1/responses` 分离——决策请求不产生自由文本，天然最小化出端字段与成本。

## 2. 职责与边界

| 职责 | 说明 |
|---|---|
| 决策模型推理 | 云端加载 NeoHorse-Jev-4B（vLLM/SGLang 部署），prefill-only 前向返回类型化决策 + 概率 |
| 契约映射 | 云端 `DecisionRequest` ↔ 推理输入（state/candidates/question）；`DecisionResult` ↔ 推理输出（selected/confidence/probabilities） |
| 鉴权与票据 | 复用 G1.1：mTLS 客户端证书 + 会话票据（G2.1/G2.2）；决策请求同样要求 `Bearer <ticket>` |
| 最小字段强制 | 决策请求只允许白名单字段（scenario/state(脱敏)/candidates/question/constraints/privacyMode/budget）；超字段 → `FIELD_VIOLATION` |
| 隐私分级 | 与 G1.1 一致：`privacyMode` 声明（plain/masked/summarized）；**敏感类（金融/健康/账号）端侧已拦截走本地规则路径，云端不接收**（端侧 B5.3 `sensitive` 约束） |
| usage 签名回传 | 每次决策回传 `usage`（token/成本），云端签名 → 端侧 ACB `AgentBudget` 对账（G1.2） |
| 处理即弃 | 决策正文不落盘、不进训练缓存；仅审计摘要 + 用量计数保留（G3.2） |
| 断线/降级语义 | 明确错误码 → 端侧降级规则路径；**不得以假成功回包** |

**边界**：云端决策只处理"已由端侧策略引擎/红线过滤后的决策请求"，云端不做授权裁决（授权轴仍在端侧 A7）；云端返回的概率仅作建议，端侧确定性闸门复核后才生效。

## 3. 接口契约

### 3.1 端点

```
POST /v1/decision
Content-Type: application/json
Authorization: Bearer <session_ticket>      // G2.1/G2.2 会话票据
X-Device-Key-Hash: sha256:9f2c...b1e0        // 设备键哈希（最小字段白名单）
X-Request-Id: req_01HZ...                    // 端云关联（G5.1 → A5.3）
```

传输层：TLS 1.3 + mTLS（复用 G1.1 §5 安全边界）。

### 3.2 请求体（云端 DecisionRequest）

```json
{
  "protocolVersion": "1",
  "type": "choice",                          // choice | noul | score
  "scenario": "intent_classify",             // 阈值表/审计/计量场景
  "state": "帮我订明天去北京的机票",            // 已脱敏/摘要文本（privacyMode 声明）
  "imageRef": null,                          // 可选：S5-h 掩码帧引用（单图+文本联合决策）
  "candidates": [
    {"key": "open_app", "desc": "打开应用"},
    {"key": "send_msg", "desc": "发送消息"},
    {"key": "query_info", "desc": "查询信息"},
    {"key": "schedule", "desc": "日程安排"},
    {"key": "form_submit", "desc": "表单提交"}
  ],
  "question": "用户是否要求退款？",            // noul 专用
  "constraints": ["offline_ok", "low_energy"], // 端侧硬约束（云端仅作候选过滤提示，授权在端侧）
  "privacy": { "mode": "masked", "fields": ["state"] },
  "budget": { "costCeilingMicros": 200, "maxTokens": 128, "currency": "USD" },
  "thresholdVersion": "v1.0.0"               // 端侧阈值表版本（供云端对账/审计）
}
```

**字段白名单**（云端强制）：`protocolVersion / type / scenario / state / imageRef / candidates / question / constraints / privacy / budget / thresholdVersion`；其余字段剥离，剥离后仍超 → 422 `FIELD_VIOLATION`。

### 3.3 响应体（云端 DecisionResult）

```json
{
  "requestId": "req_01HZ...",
  "scenario": "intent_classify",
  "type": "choice",
  "selected": "open_app",
  "confidence": 0.91,
  "probabilities": {
    "open_app": 0.91, "send_msg": 0.04, "query_info": 0.02,
    "schedule": 0.02, "form_submit": 0.01
  },
  "modelVersion": 1,
  "backend": "cloud",
  "latencyMicros": 42000,
  "usage": {
    "inputTokens": 96, "outputTokens": 8, "totalTokens": 104,
    "costMicros": 180,
    "signature": "<broker 私钥签名，端侧验签对账 G1.2>"
  },
  "status": { "code": 0, "reason": "" }       // 0=OK
}
```

### 3.4 错误响应（与端侧 DecisionResult.statusCode 映射）

| 云端错误码 | HTTP | 端侧 statusCode | 端侧降级行为 |
|---|---|---|---|
| `OK` | 200 | 0 | 正常 |
| `TICKET_MISSING/EXPIRED/REVOKED` | 401/403 | 4 (CLOUD_UNAVAILABLE) | 规则路径 |
| `ATTESTATION_FAILED` | 401 | 4 | 规则路径 |
| `BUDGET_EXCEEDED` | 429 | 3 (BUDGET_EXCEEDED) | 预算断流 |
| `FIELD_VIOLATION` | 422 | 4 | 规则路径 |
| `MODEL_UNAVAILABLE` | 503 | 4 | 规则路径（本地/云端均不可用） |
| `TIMEOUT` | 504 | 5 (TIMEOUT) | 规则路径 |
| `INTERNAL_ERROR` | 500 | 4 | 规则路径 |
| `CONTENT_POLICY` | 422 | 4 | 规则路径 + 审计 |

> 与 G1.1 §3.2 错误码表对齐：决策接口复用 `TICKET_* / ATTESTATION_FAILED / BUDGET_EXCEEDED / FIELD_VIOLATION / CONTENT_POLICY / UPSTREAM_UNAVAILABLE`，新增 `MODEL_UNAVAILABLE`（决策模型不可用）。

## 4. 决策模型推理后端（云端）

```
CloudBroker Broker Gateway
        │  (POST /v1/decision, 已鉴权+白名单)
        ▼
 DecisionService (云) —— 场景/阈值校验、usage 计量、签名
        │
        ▼
 NeoHorse-Jev-4B 决策运行时
   ├─ vLLM（决策后端适配，prefill-only）
   └─ SGLang（可选）
        │  prefill-only 前向 → 类型化决策 + 概率
```

- **部署**：GPU 集群（决策模型 ~9GB 权重，BF16），多副本无状态；按 G3.2 地域部署。
- **批量/缓存**：同 `scenario + state` 短时缓存（低风险场景），命中直返降低延迟/成本；敏感场景不缓存。
- **计量**：token/成本按 G1.2 租户 quota 记账，usage 签名回传端侧 ACB 对账。
- **观测**：决策结果（requestId/scenario/selected/confidence/status）汇入 G5.1 出网审计台 → A5.3 全链。

## 5. 安全边界（对齐 E2.3 / G1.1 §5）

| 层 | 机制 |
|---|---|
| 传输 | TLS 1.3 + mTLS（复用 G1.1） |
| 身份 | 会话票据（G2.1/G2.2）+ 设备键哈希 |
| 最小字段 | 决策请求白名单强制（§3.2） |
| 隐私 | `privacyMode` 声明 + 服务端抽检；**敏感类端侧已拦截**（sensitive 约束→本地规则路径），云端设计上不接收金融/健康/账号明文 |
| 预算 | `budget.costCeilingMicros` 硬上限（G1.2） |
| 数据处置 | 处理即弃；决策正文不落盘（G3.2） |
| 防重放 | 票据 nonce/时间戳 + 请求幂等（requestId） |

## 6. 与端侧联动

| 端侧 | 联动点 |
|---|---|
| `DecisionService.cloudInfer()`（B5.3） | 发起 `POST /v1/decision`；绑定 `IAgentInferenceRouter` TIER_CLOUD 路由 |
| `DecisionRequest`（端侧 AIDL） | 字段映射到云端请求体（scenario/state/candidates/question/constraints/budget） |
| `DecisionResult`（端侧 AIDL） | 云端响应映射回 statusCode/backend/usage；与确定性闸门复核后生效 |
| `decision_thresholds_v1.json`（B5.4） | `thresholdVersion` 与云端对账；阈值裁决在端侧（云端不代裁） |
| `EgressPlan`（preflightEgress） | 端侧出网前声明出端字段，与云端白名单一致（D13 同一 schema 权威） |

## 7. 验收口径

- [ ] H3.4 端云 e2e 覆盖 `/v1/decision`：通用版设备决策请求 → 云端返回 `DecisionResult` → 端侧复核生效
- [ ] choose/judge/score 三类型请求均正确返回（selected/confidence/probabilities）
- [ ] 无票据/过期/吊销请求被拒（401/403）；`FIELD_VIOLATION`（422）生效
- [ ] `budget.costCeilingMicros` 硬上限生效，超限返回 `BUDGET_EXCEEDED`（429）
- [ ] usage 带服务端签名，端侧可验签（防篡改计费对账 G1.2）
- [ ] 敏感类场景云端设计上不接收（端侧已拦截）
- [ ] 决策延迟 P95 ≤300ms（端到端通用版口径，见 B5.3）
- [ ] 所有失败路径返回明确错误码，无假成功回包

## 8. 遗留项

1. **云端决策模型部署**：NeoHorse-Jev-4B 云端 GPU 部署（vLLM/SGLang 适配）与容量规划（并发/吞吐），需 G5.2 SRE 支撑。
2. **模型版本与 OTA**：云端决策模型版本更新与端侧 `modelVersion` 对账（联动 G4.2 权重 OTA 与 C6.4 值集）。
3. **多区域/多供应商**：决策模型供应商抽象（同 G1.1 §9 遗留 1）。
4. **评测对账**：云端与旗舰版本地决策结果的准确率/一致性对账（同一评测集），确保双版本体验一致（B5.4 阈值表）。

---

*本设计把通用版云端决策接口从 G1.1 独立成清晰契约，对齐端侧 `IAgentDecisionService` 与 B5.3 通用版后端；实现纳入 A3 里程碑。*
