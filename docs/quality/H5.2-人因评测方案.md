# H5.2 人因评测方案

> 任务编号：H5.2（质量工程部 · 人因评测）
> 里程碑：A2 · 前置：H4.1 · 依赖草案：D9
> 状态：📋 评测方案（随里程碑执行）

## 1. 目的与范围

对 Agent 交互进行**人因评测**，覆盖三大维度（对齐 D9 §0 人因基线与
§5-b 反馈先行、D8.1 动效与可访问性设计）：

1. **100ms 可视反馈基线**：所有 Agent 行为发出后 100ms 内给出可视反馈；
2. **动效流畅主观评测**：过渡/占位动效的主观流畅度与客观帧率结合；
3. **无障碍走查**：TalkBack/字体缩放/对比度/触控目标走查。

## 2. 100ms 可视反馈基线

### 2.1 定义

> "无反馈"本身即构成慢（D9 §0 人因基线）。任何 Agent 动作
> （确认流、执行占位、任务卡状态切换）必须在**发出后 100ms 内**
> 呈现可视反馈（按钮回弹、光标、卡片"思考中→执行中"动效）。

### 2.2 评测对象清单

| 交互点 | 反馈形态 | 预算 |
|---|---|---|
| 表单提交 | 按钮回弹 + 卡片状态切换 | ≤100ms |
| 确认流发起 | 确认面板渐显 | ≤100ms |
| 宏/DMI 执行 | 任务卡"执行中"动效 | ≤100ms |
| CLI/语音命令 | 解析占位 + 首字光标 | ≤100ms |
| 姿态手势就绪 | 就绪提示（摇一摇） | ≤100ms（D9 §8 就绪类动作） |
| 日程预准备 | 准备状态占位卡 | ≤100ms |

### 2.3 评测方法

- **客观测量**：H5.1 SDK 埋点 `feedback_visible_*`（动作发出 → 反馈帧可见），
  每交互点 ≥30 样本，P95 ≤100ms；
- **主观抽查**：5 名评测员 × 20 个交互场景，标记"未感知到反馈"的事件；
- **门禁**：P95 ≤100ms 且主观未反馈率 <5%。

## 3. 动效流畅主观评测

### 3.1 动效清单（对齐 D8.1）

| 动效 | 触发 | 时长预算 |
|---|---|---|
| 任务卡状态切换 | 思考中→执行中→完成 | ≤250ms |
| 确认面板 | 渐显/渐隐 | ≤200ms |
| 表单内联渲染 | schema→控件呈现 | ≤150ms |
| 会话切换 | 热切换转场 | ≤100ms |
| 通知折叠/展开 | 摘要→详情 | ≤200ms |

### 3.2 评测方法

- **客观**：`dumpsys gfxinfo` 采集帧时间，janky（>16.7ms）占比 <5%，
  frozen（>700ms）占比 0；帧率分级遵循 D9 §6h（注入期 30fps 上限仅
  Agent 驱动段，离开即复原）；
- **主观量表**（5 点 Likert）：

| 维度 | 描述 | 分值 |
|---|---|---|
| 流畅度 | 无卡顿/掉帧感知 | 1–5 |
| 一致性 | 与系统动效语言一致 | 1–5 |
| 反馈清晰 | 状态变化可理解 | 1–5 |
| 干扰度 | 动效不打断任务 | 1–5 |

- **合格线**：流畅度/一致性 ≥4 分均值；任何评测员给 ≤2 分 → 记录缺陷。

### 3.3 敏感场景动效约束

- 输入聚焦/支付/安全窗口在屏 → 强制原生分辨率与帧率（D9 §6h 红线），
  禁用降级动效；
- 录音态/相机就绪态 → 无干扰动效（对齐 E4.1 合规观感）。

## 4. 无障碍走查

### 4.1 走查项

| 项 | 标准 | 方法 |
|---|---|---|
| TalkBack 朗读 | 所有可见元素可朗读，顺序合理 | TalkBack + 全键盘操作 |
| 内容描述 | 图标/按钮含 contentDescription | `uiautomator dump` 抽查 |
| 字体缩放 | 200% 无裁切/重叠 | 设置中缩放后走查关键页 |
| 对比度 | 文本/控件 ≥4.5:1（大文本 3:1） | 对比度采样工具 |
| 触控目标 | ≥48×48dp 可点区域 | 布局检查 |
| 动效减弱 | 尊重"移除动画"系统设置 | 设置切换验证 |
| 色彩非唯一信息 | 状态不依赖颜色单通道 | 灰度模式走查 |

### 4.2 执行框架

```bash
# 自动化走查（uiautomator + 无障碍服务桩）
python3 tools/validate_a11y.py --walkthrough GentonBrain,SystemUI
```

- 缺陷按 WCAG 2.1 AA 分级，P1（阻断级）不得跨里程碑遗留。
