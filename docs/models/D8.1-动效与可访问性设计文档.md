## 1. 设计目标

在 D1.1 双模式容器的基础上，实现符合 Android 无障碍规范的动效系统，满足：

1. **性能约束**：双模式切换动画 <150ms，满足 Material Design 规范
2. **文本放大支持**：遵循系统字体缩放设置（FONT_SCALE）
3. **无障碍服务兼容**：TalkBack、Switch Access 等辅助服务正常工作
4. **减少动画模式**：系统启用"减少动画"时禁用所有动效
5. **感知通道例外**：Agent 感知通道（屏幕读取）不受无障碍干扰

## 2. 核心架构

### 2.1 组件分层

```
┌─────────────────────────────────────────────────────────┐
│                    SystemUI 业务层                        │
│  ┌───────────────────────────────────────────────────┐  │
│  │ DualModeContainer                                 │  │
│  │ - switchMode(targetMode, animationDurationMs)     │  │
│  │ - switchToAssistantMode(duration)                 │  │
│  │ - switchToStandardMode(duration)                  │  │
│  └───────────────────┬───────────────────────────────┘  │
│                      │ 使用                              │
│                      ↓                                   │
│  ┌───────────────────────────────────────────────────┐  │
│  │ AnimationAccessibilityManager（D8.1 核心）        │  │
│  │ - getActualDuration(baseDuration) → 实际时长      │  │
│  │ - fadeIn/fadeOut(view, callback)                  │  │
│  │ - slideIn/slideOut(view, direction, callback)     │  │
│  │ - scale(view, fromScale, toScale, callback)       │  │
│  │ - applyTextScale(textView, baseTextSize)          │  │
│  │ - isReduceMotionEnabled() → boolean               │  │
│  └───────────────────┬───────────────────────────────┘  │
│                      │ 读取                              │
│                      ↓                                   │
│  ┌───────────────────────────────────────────────────┐  │
│  │ Android Settings Provider                         │  │
│  │ - Settings.Global.ANIMATOR_DURATION_SCALE         │  │
│  │ - Settings.System.FONT_SCALE                      │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

### 2.2 数据流

```
用户触发切换（悬浮球点击/侧边手势/QS Tile）
  ↓
ModeEntryManager.handleEntryTrigger()
  ↓
DualModeContainer.switchMode(targetMode, 150ms)
  ↓
AnimationAccessibilityManager.getActualDuration(150ms)
  ├─ 正常模式 → 返回 150ms
  ├─ 减少动画模式 → 返回 0ms（无动画）
  └─ 自定义缩放 → 返回 150ms * scale
  ↓
执行动画（fadeIn/fadeOut/slide/scale）
  ↓
动画完成回调 → 更新状态机 → 通知监听器
```

## 3. 动画规范

### 3.1 时长标准

根据 Material Design 和 D5 草案 §8 要求：

| 动画类型 | 时长（ms） | 说明 | WBS 要求 |
|---------|-----------|------|----------|
| **模式切换** | 150 | 双模式容器切换 | <150ms ✅ |
| **淡入淡出** | 120 | 通用 fade 动画 | - |
| **滑动进出** | 140 | 侧边栏/胶囊滑动 | - |
| **缩放动画** | 150 | 悬浮球展开/收起 | - |

**性能验收标准**：
- 所有动画必须在指定时长内完成
- 帧率 ≥ 60 fps（GPU 加速）
- 主线程不阻塞（异步动画）

### 3.2 插值器选择

```java
// 默认插值器：AccelerateDecelerateInterpolator
// 特点：开始和结束缓慢，中间加速，Material Design 标准
private final Interpolator mDefaultInterpolator = 
    new AccelerateDecelerateInterpolator();
```

其他可选插值器：
- `FastOutSlowInInterpolator`：快速启动，缓慢结束（推荐用于滑入）
- `LinearOutSlowInInterpolator`：线性启动，缓慢结束（推荐用于淡入）
- `FastOutLinearInInterpolator`：快速启动，线性结束（推荐用于滑出）

### 3.3 硬件加速

所有动画视图必须启用硬件加速：

```java
view.setLayerType(View.LAYER_TYPE_HARDWARE, null);
view.animate()
    .alpha(1f)
    .setDuration(duration)
    .withEndAction(() -> {
        // 动画完成后恢复软件层
        view.setLayerType(View.LAYER_TYPE_NONE, null);
    });
```

## 4. 无障碍兼容

### 4.1 减少动画模式

当用户启用"减少动画"（Settings > 辅助功能 > 减少动画）时：

```java
// 检测方法
float animatorDurationScale = Settings.Global.getFloat(
    context.getContentResolver(),
    Settings.Global.ANIMATOR_DURATION_SCALE,
    1.0f
);
boolean isReduceMotionEnabled = (animatorDurationScale == 0f);

// 应用策略
public long getActualDuration(long baseDuration) {
    if (mIsReduceMotionEnabled) {
        return 0; // 无动画，直接切换
    }
    return baseDuration;
}
```

**行为**：
- 所有动画时长强制为 0ms
- 直接设置最终状态，无过渡效果
- 状态回调立即触发

### 4.2 文本缩放支持

遵循系统字体缩放设置：

```java
// 读取缩放因子
float textScaleFactor = Settings.System.getFloat(
    context.getContentResolver(),
    Settings.System.FONT_SCALE,
    1.0f
);

// 应用到 TextView
public void applyTextScale(TextView textView, float baseTextSize) {
    textView.setTextSize(baseTextSize * mTextScaleFactor);
}
```

**覆盖范围**：
- 会话流气泡文本
- 任务卡片标题和描述
- 按钮文字
- 输入框提示文本
- 系统提示消息

**例外**：
- 悬浮球图标（固定尺寸）
- 指示器芯片（固定尺寸）
- 装饰性图标

### 4.3 TalkBack 兼容

为所有交互元素提供内容描述：

```java
// 悬浮球
floatingBubble.setContentDescription("AI 助理，双击切换到助理模式");

// 侧边手势面板
edgePanel.setContentDescription("侧边栏面板，从屏幕边缘滑入以唤出助理");

// QS Tile
tile.setContentDescription("AI 助理模式，当前处于标准模式，点击切换");

// 确认面板按钮
approveButton.setContentDescription("批准此操作");
denyButton.setContentDescription("拒绝此操作");
neverButton.setContentDescription("永不批准此类操作");
```

**焦点管理**：
- 模式切换后，焦点自动移动到助理输入框
- 确认面板弹出时，焦点锁定在按钮区域
- 胶囊出现时，TalkBack 播报胶囊内容

### 4.4 Switch Access 兼容

支持按键导航：

```java
// 可聚焦设置
view.setFocusable(true);
view.setFocusableInTouchMode(false);

// 焦点顺序
view.setNextFocusDownId(R.id.next_button);
view.setNextFocusUpId(R.id.prev_button);
```

**导航路径**：
1. 悬浮球 → 侧边手势触发区 → QS Tile
2. 助理模式：输入框 → 发送按钮 → 会话列表
3. 确认面板：上滑区域 → 批准 → 拒绝 → 永不

## 5. 感知通道例外

### 5.1 设计原则

> **D5 草案 §8 规定**：Agent 感知通道（屏幕读取）不受无障碍服务影响，仍走自定义 UI 树服务。

**实现策略**：
- 屏幕读取（ScreenReader）使用独立的 AccessibilityService
- 不依赖系统 TalkBack，避免冲突
- 自定义 UI 树遍历逻辑（不使用 AccessibilityNodeInfo）
- 独立的语音合成引擎（不使用系统 TTS）

### 5.2 隔离机制

```java
// Agent 专用 AccessibilityService（在 packages/apps/GentonBrain）
public class AgentAccessibilityService extends AccessibilityService {
    
    @Override
    public void onAccessibilityEvent(AccessibilityEvent event) {
        // 仅处理 Agent 授权的应用
        String packageName = event.getPackageName();
        if (!isAgentAuthorized(packageName)) {
            return;
        }
        
        // 自定义 UI 树遍历（不依赖系统无障碍）
        traverseCustomUiTree(event);
    }
    
    @Override
    protected void onServiceConnected() {
        AccessibilityServiceInfo info = new AccessibilityServiceInfo();
        
        // 仅监听特定包名（不影响系统无障碍）
        info.packageNames = getAuthorizedPackages();
        
        // 不请求系统级别的无障碍能力
        info.flags = AccessibilityServiceInfo.FLAG_RETRIEVE_INTERACTIVE_WINDOWS;
        
        setServiceInfo(info);
    }
}
```

**关键点**：
- Agent 感知服务不影响用户启用的 TalkBack
- 两套服务并行运行，互不干扰
- Agent 感知服务优先级更高（策略引擎控制）

## 8. 性能优化

### 8.1 动画优化策略

1. **硬件加速**：
   - 所有动画视图启用 `LAYER_TYPE_HARDWARE`
   - 动画完成后恢复 `LAYER_TYPE_NONE`

2. **异步执行**：
   - 动画在 UI 线程执行，不阻塞主线程
   - 使用 `Handler.postDelayed()` 避免嵌套回调

3. **内存优化**：
   - 动画对象池复用（避免频繁创建）
   - 及时释放 Animator 监听器

4. **提前预热**：
   - SystemUI 启动时预创建 AnimationAccessibilityManager 实例
   - 缓存常用插值器对象

### 8.2 功耗优化

1. **空闲时停止动画**：
   - 屏幕关闭时暂停所有动画
   - 应用后台时冻结动画状态

2. **降级策略**：
   - 低电量模式（<20%）：自动启用减少动画
   - 过热保护：禁用复杂动画，仅保留必要过渡

## 9. 开放问题

### 9.1 待确认问题

1. **文本缩放上限**：
   - 当前支持系统 FONT_SCALE（通常 0.85x ~ 2.0x）
   - 是否需要支持更大倍率（如 3.0x）？

2. **动画降级阈值**：
   - 何时触发低电量模式动画降级？
   - 是否需要用户可配置？

3. **感知通道权限**：
   - Agent 感知服务的授权粒度？
   - 用户如何撤销感知权限？

### 9.2 未来增强

1. **自适应动画速度**：
   - 根据设备性能动态调整动画时长

2. **个性化动效**：
   - 用户可选动画风格（经典/流畅/炫酷）
   - 自定义动画时长

3. **动画监控仪表盘**：
   - 统计动画执行次数和耗时
