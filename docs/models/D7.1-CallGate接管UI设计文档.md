## 1. 设计目标

在 A10.1 CallGate 服务基础上，实现 SystemUI 侧的通话接管 UI，满足：

1. **接管卡**：实时显示 CallGate 正在接管通话，状态清晰
2. **转写增量显示**：实时展示对方语音转文字（本地 ASR）
3. **摘要+建议回拨卡**：通话结束后展示摘要和智能建议
4. **查看详情**：跳转到审计时间线查看完整接管记录
5. **用户控制**：可随时中止接管，转为原生通话

## 2. 核心架构

### 2.1 组件分层

```
┌─────────────────────────────────────────────────────────┐
│              A10.1 CallGate 服务（system_server）        │
│  AgentCallGateService                                   │
│  - classifyIncoming() → CallVerdict                     │
│  - startHandleSession() → CallSessionHandle             │
└──────────────────────┬──────────────────────────────────┘
                       │ Binder IPC
                       │ IAgentCallGateListener 回调
                       ↓
┌─────────────────────────────────────────────────────────┐
│           SystemUI - CallGateUiController（D7.1）       │
│  ┌────────────────────────────────────────────────┐    │
│  │ 实现 IAgentCallGateListener.Stub              │    │
│  │ - onVerdict() → 显示接管卡                     │    │
│  │ - onTranscriptDelta() → 更新转写文本           │    │
│  │ - onSummaryReady() → 显示摘要卡                │    │
│  └────────────────────┬───────────────────────────┘    │
│                       │ 委托显示                        │
│                       ↓                                 │
│  ┌────────────────────────────────────────────────┐    │
│  │ UI 组件                                        │    │
│  │ - CallInterceptionCard（接管中卡片）           │    │
│  │ - TranscriptView（转写增量显示）               │    │
│  │ - CallSummaryCard（摘要+建议卡）               │    │
│  └────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

### 2.2 状态流转

```
来电 → CallGate 判定（≤50ms）
  ↓
路由决策：AGENT_HANDLE (L1/L2)
  ↓
SystemUI.onVerdict() → 显示接管卡
  ↓
会话状态：BRIDGING → GREETING → TRANSCRIBING
  ↓ 对方说话
SystemUI.onTranscriptDelta() → 增量更新转写文本
  ↓ 通话结束
SystemUI.onSummaryReady() → 显示摘要卡
  ↓ 用户点击
跳转审计详情 / 回拨建议 / 关闭卡片
```

## 3. UI 组件设计

### 3.1 接管卡（CallInterceptionCard）

**显示时机**：收到 `onVerdict(route=AGENT_HANDLE)` 后立即显示

**视觉设计**：
```
┌─────────────────────────────────────────┐
│  🤖 AI 助理正在接管来电                  │
│                                         │
│  来电：+86 138****5678                   │
│  时间：14:32                            │
│                                         │
│  状态：正在连接... / 正在问候 / 正在听取 │
│                                         │
│  [中止接管，手动接听]  [查看详情]        │
└─────────────────────────────────────────┘
```

**关键要素**：
- **来电号码**：脱敏显示（中间 4 位隐藏）
- **接管模式**：L1（留言）/ L2（对话）
- **会话状态**：bridging / greeting / transcribing / done
- **用户控制**：中止接管按钮（转原生通话）
- **查看详情**：跳转到审计时间线

**状态映射**：
| CallGate 状态 | UI 显示文案 | 图标 |
|--------------|------------|------|
| BRIDGING | 正在连接音频桥... | 🔄 |
| GREETING | 正在问候对方... | 👋 |
| TRANSCRIBING | 正在听取内容... | 👂 |
| DONE | 通话已结束 | ✅ |
| ERROR | 接管失败，已转原生 | ⚠️ |

### 3.2 转写增量显示（TranscriptView）

**显示时机**：接管卡展开状态下，收到 `onTranscriptDelta()` 时更新

**视觉设计**：
```
┌─────────────────────────────────────────┐
│  📝 实时转写                             │
│                                         │
│  [对方] 14:32:15                        │
│  你好，我是张三，想咨询一下...           │
│                                         │
│  [助理] 14:32:20                        │
│  您好，我是主人的 AI 助理...            │
│                                         │
│  [对方] 14:32:35                        │
│  那什么时候方便回复我？                  │
│  ━━━━━ 正在识别... ━━━━━               │
│                                         │
│  共 3 条对话，时长 45 秒                 │
└─────────────────────────────────────────┘
```

**关键要素**：
- **说话人标识**：[对方] / [助理]
- **时间戳**：每条对话显示时间
- **增量更新**：实时追加文本（isFinal=false 显示省略号）
- **滚动到底部**：新内容自动滚动
- **脱敏处理**：敏感信息（手机号/地址）打码

**性能优化**：
- 使用 RecyclerView 虚拟化渲染（支持长对话）
- 增量更新只刷新最后一项（避免全量刷新）
- 文本缓冲：100ms 内多次 delta 合并刷新

### 3.3 摘要+建议回拨卡（CallSummaryCard）

**显示时机**：收到 `onSummaryReady()` 后，替换接管卡显示

**视觉设计**：
```
┌─────────────────────────────────────────┐
│  📋 通话摘要                             │
│                                         │
│  来电：+86 138****5678                   │
│  时长：1 分 45 秒                        │
│  时间：今天 14:32                        │
│                                         │
│  摘要内容：                              │
│  对方咨询产品价格和交付时间，希望尽快   │
│  联系确认订单。留言表示本周五前回复。    │
│                                         │
│  🎯 建议操作：                           │
│  • [立即回拨] +86 138****5678            │
│  • [发送消息] "稍后回复您"               │
│  • [设置提醒] 周五 10:00 回拨            │
│                                         │
│  [查看完整转写]  [关闭]                  │
└─────────────────────────────────────────┘
```

**关键要素**：
- **摘要文本**：本地生成，不超过 200 字
- **建议操作**：回拨 / 发消息 / 设置提醒（3 选 1 或多个）
- **审计引用**：点击"查看完整转写"跳转详情
- **关闭卡片**：用户可主动关闭

**建议操作规则**：
- **立即回拨**：号码不在黑名单 → 调用系统拨号
- **发送消息**：号码存在通讯录 → 打开短信应用
- **设置提醒**：生成日程任务卡 → 提交到 B3.2 FormSubmitRouter

## 4. 数据流设计

### 4.1 监听器回调处理

```kotlin
class CallGateUiController : IAgentCallGateListener.Stub() {
    
    override fun onVerdict(descriptor: CallDescriptor, verdict: CallVerdict) {
        when (verdict.route) {
            CallRoute.AGENT_HANDLE -> {
                // 显示接管卡
                showInterceptionCard(descriptor, verdict)
            }
            CallRoute.RING_NATIVE -> {
                // 回退原生，不显示 UI
                Log.d(TAG, "Verdict: ring native, no UI")
            }
            CallRoute.RECORD_ONLY -> {
                // 仅记录，显示通知
                showRecordNotification(descriptor)
            }
        }
    }
    
    override fun onTranscriptDelta(session: CallSessionHandle, delta: TranscriptDelta) {
        // 增量更新转写文本
        transcriptView?.appendDelta(delta)
    }
    
    override fun onSummaryReady(session: CallSessionHandle, summary: CallSummary) {
        // 显示摘要卡
        showSummaryCard(session, summary)
    }
    
    override fun onError(session: CallSessionHandle, code: Int, message: String) {
        // 错误处理：转原生
        handleError(session, code, message)
    }
}
```

### 4.2 会话状态管理

```kotlin
data class CallGateSession(
    val sessionHandle: CallSessionHandle,
    val descriptor: CallDescriptor,
    val verdict: CallVerdict,
    val startTime: Long,
    var state: SessionState,
    val transcripts: MutableList<TranscriptDelta>,
    var summary: CallSummary?
)

enum class SessionState {
    BRIDGING,      // 音频桥接中
    GREETING,      // 问候对方
    TRANSCRIBING,  // 转写中
    DONE,          // 已结束
    ERROR          // 错误
}
```

## 5. 防误触与安全

### 5.1 用户控制

**中止接管按钮**：
- 位置：接管卡顶部右上角
- 确认：弹窗二次确认"确定转为手动接听？"
- 效果：调用 `IAgentCallGateService.endHandleSession()`，Telecom 转原生来电

**审计透明**：
- 所有接管操作记录到审计时间线
- 用户可查看策略规则依据
- 支持举报误判

### 5.2 隐私保护

**号码脱敏**：
- 接管卡：+86 138****5678
- 摘要卡：同上
- 详情页：完整号码（用户主动查看）

**转写脱敏**：
- 手机号：138****5678
- 身份证号：3201***********234
- 地址：北京市朝阳区***路 123 号

**音频不落地**：
- 音频流直接桥接到本地 ASR（TEE 边界）
- 不录音，不存储原始音频
- 转写文本可选存储（默认 7 天后删除）
