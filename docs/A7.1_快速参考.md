# A7.1 策略引擎快速参考

## 概览

策略引擎是 Agentic Native OS 的**确定性闸门**，意图与动作在落地前必须经它裁决。

**核心职责**:
- 意图级预检（规划前调用）
- 动作级令牌签发（含 Taint 检测）
- 用户确认回灌
- 令牌验证（三查：签名/scope/TTL）
- 策略热加载

**性能目标**: evaluateIntent P50 < 1ms

## 快速上手

### 1. 调用策略引擎

```java
// 获取服务
IPolicyEngine policyEngine = IPolicyEngine.Stub.asInterface(
    ServiceManager.getService("policy_engine")
);

// 意图级预检
IntentEvaluationRequest request = new IntentEvaluationRequest();
request.intentId = "intent_12345";
request.agentId = "agent_email_assistant";
request.requestedCapabilities = new String[]{
    "agent.read_contacts",
    "agent.send_email"
};

PolicyDecision decision = new PolicyDecision();
int status = policyEngine.evaluateIntent(request, decision);

if (status == IPolicyEngine.STATUS_OK && 
    decision.decision == IPolicyEngine.DEC_GRANT) {
    // 全部能力授权，继续规划
} else if (decision.decision == IPolicyEngine.DEC_REQUIRE_CONFIRMATION) {
    // 需要用户确认
    showConfirmationDialog(decision.confirmId, decision.reasons);
} else {
    // 拒绝
    Slog.w(TAG, "Intent denied: " + Arrays.toString(decision.reasons));
}
```

### 2. 请求能力令牌

```java
// 动作级令牌请求
CapabilityRequest capRequest = new CapabilityRequest();
capRequest.agentId = "agent_email_assistant";
capRequest.intentId = "intent_12345";  // 必须匹配 scope
capRequest.capability = "agent.send_email";
capRequest.actionId = "send.email";
capRequest.targetSummary = "发送邮件给 Alice";
capRequest.argTaints = new TaintMapEntry[]{
    new TaintMapEntry("recipient", TrustLevel.USER),
    new TaintMapEntry("body", TrustLevel.AGENT)
};

PolicyDecision decision = new PolicyDecision();
int status = policyEngine.requestCapability(capRequest, decision);

if (status == IPolicyEngine.STATUS_OK && 
    decision.decision == IPolicyEngine.DEC_GRANT) {
    // 令牌签发成功
    CapabilityToken token = decision.token;
    
    // 调用域服务执行动作
    emailService.sendEmail(recipient, body, token);
} else {
    // 拒绝或需确认
}
```

### 3. 用户确认回灌

```java
// SystemUI 用户确认面板
void onUserConfirmed(String confirmId, boolean allow) {
    int decision = allow ? 
        IPolicyEngine.USER_ALLOW_ONCE : 
        IPolicyEngine.USER_DENY;
    
    int status = policyEngine.reportUserDecision(confirmId, decision);
    
    if (status == IPolicyEngine.STATUS_OK) {
        // 补签令牌成功（通过回调返回）
    }
}
```

### 4. 令牌验证（域服务侧）

```java
// 域服务收到令牌后验证
boolean valid = policyEngine.validateToken(
    token,
    scopeIntentId,  // 当前执行上下文的 intentId
    capability
);

if (!valid) {
    throw new SecurityException("Invalid capability token");
}

// 执行动作
executeAction();
```

### 5. 令牌撤销

```java
// 撤销 Agent 的全部令牌
policyEngine.revokeTokens(agentId, null);

// 撤销指定 Intent 的令牌
policyEngine.revokeTokens(agentId, intentId);
```

## AIDL 接口

### IPolicyEngine 方法

| 方法 | 说明 | 返回值 |
|------|------|--------|
| `evaluateIntent()` | 意图级预检 | STATUS_OK/DENIED/CONFIRM_PENDING |
| `requestCapability()` | 动作级令牌请求 | STATUS_OK/DENIED/CONFIRM_PENDING |
| `reportUserDecision()` | 用户确认回灌 | STATUS_OK/INVALID_REQ |
| `validateToken()` | 令牌验证（三查） | true/false |
| `revokeTokens()` | 令牌撤销 | STATUS_OK |
| `listApplicableRules()` | 治理视图 | PolicyRuleView[] |
| `reloadPolicySet()` | 策略热加载 | STATUS_OK/INTERNAL_ERROR |
| `registerListener()` | 注册监听器 | STATUS_OK |
| `unregisterListener()` | 注销监听器 | STATUS_OK |
| `getStats()` | 统计信息 | PolicyStats |

### 状态码

| 常量 | 值 | 说明 |
|------|-----|------|
| `STATUS_OK` | 0 | 成功 |
| `STATUS_DENIED` | 1 | 拒绝 |
| `STATUS_UNKNOWN_CAP` | 2 | 能力未注册 |
| `STATUS_INVALID_REQ` | 3 | 无效请求 |
| `STATUS_TOKEN_INVALID` | 4 | 令牌失效 |
| `STATUS_CONFIRM_PENDING` | 5 | 需用户确认 |
| `STATUS_INTERNAL_ERROR` | -1 | 内部错误 |

### 裁决类型

| 常量 | 值 | 说明 |
|------|-----|------|
| `DEC_GRANT` | 0 | 授权 |
| `DEC_DENY` | 1 | 拒绝 |
| `DEC_REQUIRE_CONFIRMATION` | 2 | 需用户确认 |
| `DEC_REQUIRE_MITIGATION` | 3 | 需缓解（Taint 冲突） |

### 用户决策

| 常量 | 值 | 说明 |
|------|-----|------|
| `USER_ALLOW_ONCE` | 0 | 仅允许本次动作 |
| `USER_ALLOW_TASK` | 1 | 允许整个任务 |
| `USER_DENY` | 2 | 拒绝 |

## 裁决流程

### 意图级预检

```
evaluateIntent(request)
  ↓
遍历 requestedCapabilities
  ↓
逐个调用 evaluateCapability()
  ↓
收集裁决结果
  ↓
合并裁决（deny > confirmation > allow）
  ↓
任一 DENY → 整体 DENY
任一 CONFIRMATION → 整体 REQUIRE_CONFIRMATION
全部 GRANT → GRANT
```

### 动作级令牌请求

```
requestCapability(request)
  ↓
能力注册表检查
  ↓ (未注册 = DENY)
两阶段规则求值
  ↓
阶段 1: Baseline 规则匹配
  ├─ 精确匹配
  ├─ 通配符匹配
  └─ 命中 → 返回（不可覆盖）
  ↓ (未命中)
阶段 2: Custom 规则匹配
  ├─ 精确匹配
  ├─ 通配符匹配
  └─ 命中 → 返回
  ↓ (未命中)
阶段 3: Deny 默认
  └─ 返回 DEC_DENY
  ↓
[decision == DEC_GRANT]
  ↓
Taint 冲突检测
  ├─ 检查 argTaints vs rule.argSources
  └─ 冲突 → DEC_REQUIRE_MITIGATION
  ↓ (无冲突)
TokenManagementService.issueToken()
  ↓
返回 CapabilityToken
```

### Taint 冲突检测

```
checkTaintConflict(rule, argTaints)
  ↓
for each argTaint:
  ↓
  allowedTrust = rule.argSources.get(argKey)
  ↓
  if argTaint.trust > allowedTrust:
    ↓
    return "Taint conflict"
  ↓
return null (无冲突)
```

## 基线规则

当前硬编码 6 条基线规则：

| 规则 ID | 能力 | 效果 | 优先级 |
|---------|------|------|--------|
| `sys.action.baseline.payment-confirm` | `agent.payment_action` | REQUIRE_CONFIRMATION | 1000 |
| `sys.action.baseline.data-share-confirm` | `agent.share_data` | REQUIRE_CONFIRMATION | 1000 |
| `sys.action.baseline.app-install-confirm` | `agent.install_package` | REQUIRE_CONFIRMATION | 1000 |
| `sys.action.baseline.settings-modify-confirm` | `agent.modify_settings` | REQUIRE_CONFIRMATION | 1000 |
| `sys.action.baseline.low-risk-allow` | `agent.read_contacts` | GRANT | 100 |
| `sys.action.baseline.search-allow` | `agent.search_content` | GRANT | 100 |

**特性**:
- Baseline 规则不可被任何自定义规则覆盖
- 高风险能力（支付/分享/安装/设置）强制确认
- 低风险能力（读取/搜索）自动授权

## 策略热加载

### 加载新策略

```java
// 仅平台签名服务可调用
String signedBundle = readSignedPolicyBundle();
String[] newVersion = new String[1];

int status = policyEngine.reloadPolicySet(signedBundle, newVersion);

if (status == IPolicyEngine.STATUS_OK) {
    Slog.i(TAG, "Policy reloaded: " + newVersion[0]);
} else {
    Slog.e(TAG, "Policy reload failed");
}
```

### 监听策略变更

```java
IPolicyListener listener = new IPolicyListener.Stub() {
    @Override
    public void onPolicyBundleUpdated(String bundleVersion) {
        Slog.i(TAG, "Policy updated: " + bundleVersion);
        // 清空令牌缓存
        clearTokenCache();
    }
    
    @Override
    public void onTokensRevoked(String agentId, String intentId) {
        Slog.i(TAG, "Tokens revoked: agent=" + agentId + ", intent=" + intentId);
        // 移除缓存的令牌
        removeFromCache(agentId, intentId);
    }
};

policyEngine.registerListener(listener);
```

## 安全约束

### 1. Fail-Secure

**所有异常返回 DENY**：
```java
try {
    // 裁决逻辑
} catch (Exception e) {
    decision.decision = IPolicyEngine.DEC_DENY;
    return STATUS_INTERNAL_ERROR;
}
```

### 2. Deny 默认

**无匹配规则 = DENY**：
```java
// 阶段 3: 无匹配规则
decision.decision = IPolicyEngine.DEC_DENY;
decision.reasons = new String[]{"No matching rule found (deny by default)"};
```

### 3. Baseline 优先

**Baseline 规则不可覆盖**：
- 两阶段求值：baseline → custom
- Baseline 命中后直接返回
- Custom 规则不执行

### 4. 能力注册表强制

**未注册能力 = DENY**：
```java
if (!isCapabilityRegistered(capability)) {
    return STATUS_UNKNOWN_CAP;
}
```

### 5. Scope 检查

**令牌验证强制 scope 匹配**：
```java
boolean validateToken(token, scopeIntentId, capability) {
    if (!token.scopeIntentId.equals(scopeIntentId)) {
        return false;  // Scope 不匹配
    }
    // ...
}
```

## 数据结构

### IntentEvaluationRequest

```java
parcelable IntentEvaluationRequest {
    String intentId;                    // Intent 标识
    String agentId;                     // Agent 标识
    String goalSummary;                 // 脱敏目标
    int derivedFrom;                    // 来源（user/agent/event）
    String[] requestedCapabilities;     // 请求的能力列表
    boolean[] highSensitivityFlags;     // 高敏感度标记
    int[] constraintMask;               // 约束掩码
}
```

### CapabilityRequest

```java
parcelable CapabilityRequest {
    String agentId;
    String intentId;                // 必须匹配 scope
    String capability;              // 能力名
    String actionId;                // 动作 ID
    String targetSummary;           // 脱敏目标
    TaintMapEntry[] argTaints;      // 参数 taint
    int riskEstimate;               // 风险估计
}
```

### PolicyDecision

```java
parcelable PolicyDecision {
    int decision;                   // GRANT/DENY/REQUIRE_CONFIRMATION/MITIGATION
    String[] reasons;               // 规则 ID + 说明
    String confirmId;               // 确认 ID（需确认时）
    CapabilityToken token;          // 令牌（授权时）
    String[] requiredMitigations;   // 缓解措施（冲突时）
    String ruleVersion;             // 策略版本
}
```

### TaintMapEntry

```java
parcelable TaintMapEntry {
    String argKey;      // 参数键（如 "text"/"target"）
    int trust;          // 信任等级（0-3）
}
```

## 常见问题

### Q1: 如何添加自定义规则？

A: 编辑 DSL 文件并通过 `reloadPolicySet()` 热加载：
```dsl
rule user.custom.allow-photos {
  baseline: false
  domain: action
  subject: agent.photo_assistant
  
  when: {
    capability: "agent.read_photos"
  }
  
  effect: grant
  priority: 500
}
```

### Q2: Baseline 规则可以修改吗？

A: 不可以。Baseline 规则 (`baseline: true`) 不可被任何自定义规则覆盖，保证安全底线。

### Q3: 如何调试裁决结果？

A: 检查 `PolicyDecision.reasons`：
```java
if (decision.decision == IPolicyEngine.DEC_DENY) {
    for (String reason : decision.reasons) {
        Slog.d(TAG, "Deny reason: " + reason);
    }
}
```

### Q4: 性能不达标怎么办？

A: 检查统计信息：
```java
PolicyStats stats = policyEngine.getStats();
if (stats.evalP50Micros > 1000) {
    Slog.w(TAG, "P50 exceeds target: " + stats.evalP50Micros + "µs");
    // 优化规则数量或索引结构
}
```

### Q5: 令牌验证失败怎么办？

A: 检查失败原因：
```java
boolean valid = policyEngine.validateToken(token, scopeIntentId, capability);
if (!valid) {
    // 可能原因：
    // 1. 签名无效
    // 2. Scope 不匹配（scopeIntentId 错误）
    // 3. TTL 过期
    // 4. 令牌已撤销
}
```
