# G1.1 CloudBroker 网关设计

> **任务编号**：G1.1
> **任务名称**：CloudBroker 网关（OpenAI 兼容 /v1/responses、realtime(WS)、transcribe 反代与鉴权）
> **交付物**：Broker 服务
> **前置依赖**：E2.3（端云安全基线评审）、G2.1（设备远程证明服务端）
> **草案来源**：D13（轨道A-端云调度与推理路由接口草案.md）
> **里程碑**：A3（智能与端云）
> **状态**：设计稿（待实现）

---

## 1. 摘要

CloudBroker 是端云协同的**云端唯一推理入口**：对外提供 OpenAI 兼容的 `/v1/responses`（文本/工具流式推理）、`/v1/realtime`（WebSocket 低延迟会话）、`/v1/transcribe`（音频转写）三个面；对内只接收**已通过远程证明（G2.1）且持有有效会话票据**的设备请求，并把请求转发给上游模型供应商（自建或白名单第三方）后回传。

CloudBroker 本身**不落原始正文**（处理即弃），只保留审计摘要与用量计数；支持删除传播凭证（G3.1）与预算硬上限（G1.2）。它同时是**请求最小字段**的云端强制点：凡是字段超出 `deviceKeyHash / contextDelta / privacyMode / budget` 白名单的请求一律拒绝（`STATUS_FIELD_VIOLATION`）。

本设计稿以 D13 §4 云侧契约为权威，补齐服务端侧的完整规范，供后续实现直接编码。

## 2. 职责

| 职责 | 说明 |
|---|---|
| OpenAI 兼容反代 | 三个接口面：`/v1/responses`（HTTPS 流式/非流式）、`/v1/realtime`（WSS）、`/v1/transcribe`（HTTPS 音频）；对外 API 形态与 OpenAI 对齐，内部实现自研（对齐 openphone model-broker 形态） |
| **决策专用面（0.1 增补）** | **`/v1/decision`**：NeoHorse-Jev-4B prefill-only 决策（Choice/Noul/Score），供**通用版**（非旗舰机型）设备经云端 API 运行决策模型——契约与端侧 `IAgentDecisionService` 对齐，详见 [G1.1b-CloudBroker决策接口扩展.md](./G1.1b-CloudBroker决策接口扩展.md) |
| 鉴权与票据校验 | 每次请求必须携带会话票据（G2.1/G2.2 签发）；无票据/票据过期/票据吊销 → 401/403；mTLS 客户端证书作为第一层 |
| 双向证明锚点 | 服务端证书固定（平台根证书签发的服务端证书），设备端预置指纹；云端向设备证明自己是合法 Broker |
| 最小字段强制 | 请求体 schema 校验：只允许白名单字段，其余字段剥离或拒绝 |
| usage 签名回传 | 每次推理回传 `usage`（token/成本），由云端签名（防篡改计费，联动 G1.2 与端侧 ACB `AgentBudget`） |
| 处理即弃 | 推理请求正文不落盘、不进入训练缓存；仅审计摘要与用量计数保留（见 G3.2 留存策略） |
| 删除传播接收点 | 接收端侧删除凭证（G3.1 `DeleteCredential`），级联删除缓存/样本 |
| 断线语义 | 明确错误码（证明失败/超预算/内容策略/上游故障），**不得以假成功回包** |

## 3. 接口契约

### 3.1 会话建立（握手）

端点：`POST /v1/session`（HTTPS，TLS1.3 + mTLS）

请求（首包携带设备证明 quote，服务端校验后发放短时效会话票据）：

```json
{
  "protocolVersion": "1",
  "deviceKeyHash": "sha256:9f2c...b1e0",
  "attestation": {
    "type": "TEE",                 // software | TEE | hardware
    "quote": "<base64 attestation quote>",
    "signature": "<base64 设备私钥签名>",
    "nonce": "f0e1d2c3b4a59687",
    "timestampMs": 1737000000000
  },
  "clientCertChain": ["<mTLS 客户端证书链>"],
  "clientInfo": {
    "osVersion": "1.0.0",
    "inferenceRouterVersion": "1.2.0"
  }
}
```

响应：

```json
{
  "sessionId": "sess_01HZ...",
  "ticket": {
    "ticketId": "tkt_8f...",
    "expiresAtMs": 1737000300000,     // 短时效：默认 5 分钟（可刷新，见 G2.2）
    "scope": ["responses", "realtime", "transcribe"],
    "signature": "<broker 私钥签名>"
  },
  "serverAttestation": {
    "certFingerprint": "sha256:AA...",
    "brokerId": "broker-cn-north-1",
    "pinnedFingerprintListVersion": 7
  }
}
```

> 端侧 `CloudGateway` 在发起会话前调用 `IAgentInferenceRouter.attestDevice()` 取得 `AttestationReport`，将其映射到上文的 `attestation` 字段（字段名与端侧契约保持一致：`attestationType/quote/signature/timestampMs/nonce/deviceKeyHash/status`）。

### 3.2 /v1/responses（文本/工具流式推理）

端点：`POST /v1/responses`（HTTPS + mTLS + `Authorization: Bearer <ticket>`）

请求（最小字段，字段白名单见 §5）：

```json
{
  "model": "cloud-llm-v3",
  "input": [
    {
      "role": "user",
      "content": [
        { "type": "input_text", "text": "<已脱敏文本或摘要>" }
      ]
    }
  ],
  "stream": true,
  "max_output_tokens": 512,
  "context": {
    "type": "kv_session",
    "refId": "kv_9a...",
    "deltaFields": ["currentScreenSummary"]
  },
  "privacy": {
    "mode": "masked",                // 脱敏声明：plain | masked | summarized
    "fields": ["prompt", "context"]
  },
  "budget": {
    "costCeilingMicros": 5000,
    "maxTokens": 1024,
    "currency": "USD"
  }
}
```

响应（流式，SSE）：

```json
data: {"type": "response.output_item.done", "output_index": 0, "item": {"type": "message", "content": [{"type": "output_text", "text": "已为你安排..."}]}}
data: {"type": "response.usage", "usage": {"input_tokens": 320, "output_tokens": 96, "total_tokens": 416, "costMicros": 2300}}
data: {"type": "response.completed", "response": {"id": "resp_5f...", "status": "completed"}}
```

> `usage` 块由 Broker 以**服务端私钥签名**后下传（`signature` 字段），端侧用于 ACB `AgentBudget.costUsedMicros` 记账与审计对账（联动 G1.2）。

错误响应（明确错误码，不假成功）：

```json
{
  "error": {
    "code": "ATTESTATION_FAILED",
    "message": "设备证明无效或票据已吊销",
    "retryable": false,
    "statusCode": 401
  }
}
```

错误码枚举（与端侧 `STATUS_*` 对齐映射）：

| 云端错误码 | HTTP | 端侧映射 | 说明 |
|---|---|---|---|
| `TICKET_MISSING` / `TICKET_EXPIRED` / `TICKET_REVOKED` | 401/403 | `STATUS_DENIED` | 票据校验失败（G2.2 吊销实时生效 ≤1min） |
| `ATTESTATION_FAILED` | 401 | `STATUS_ATTESTATION_FAILED` | 证明校验失败（G2.1） |
| `BUDGET_EXCEEDED` | 429 | `STATUS_BUDGET_EXCEEDED` | 超预算硬上限（G1.2） |
| `FIELD_VIOLATION` | 422 | `STATUS_DENIED` | 请求字段超出最小白名单 |
| `CONTENT_POLICY` | 422 | `STATUS_DENIED` | 内容策略命中 |
| `UPSTREAM_UNAVAILABLE` | 503 | `STATUS_NO_ROUTE` | 上游模型不可用 → 端侧降级本地 |
| `INTERNAL_ERROR` | 500 | `STATUS_INTERNAL_ERROR` | 服务端内部错误 |

### 3.3 /v1/realtime（WebSocket 低延迟会话）

- 握手：`wss://broker/v1/realtime?session=<sessionId>`，首帧必须携带 `ticket`。
- 消息协议与 OpenAI Realtime 兼容子集：`session.update` / `input_audio_buffer.append` / `response.create` / `response.output_item.done` / `response.usage`。
- 音频数据在端侧已本地 ASR/脱敏（D13 §5 数据离开策略），Broker 不接收原始通话音频（红线 R11.5：通话音频本地处理不出端）；realtime 仅用于**已脱敏的文本/工具流**的低延迟通道与 `transcribe` 的音频流。
- 心跳：服务端每 15s 下发 `ping`，客户端 30s 无响应即断链并释放会话；断线后支持 `contextDelta` 续传（D13 §6）。

### 3.4 /v1/transcribe（音频转写）

端点：`POST /v1/transcribe`（HTTPS，multipart/form-data 或 JSON base64）

```json
{
  "model": "whisper-large-v3",
  "audio": { "format": "wav", "sampleRate": 16000, "durationMs": 8000, "data": "<base64 音频，已脱敏/降噪>" },
  "privacy": { "mode": "summarized" },          // 转写结果按声明脱敏
  "language": "zh"
}
```

响应：

```json
{
  "id": "tr_77a...",
  "text": "<转写文本，已摘要化或已剥离 PII>",
  "segments": [ { "startMs": 0, "endMs": 8000, "text": "<摘要>" } ],
  "usage": { "input_seconds": 8.0, "costMicros": 400 },
  "signature": "<broker 签名>"
}
```

## 5. 安全边界

| 层 | 机制 | 依据 |
|---|---|---|
| 传输 | TLS 1.3 only（禁用 <1.3）；证书固定服务端指纹（平台根签发），防中间人与恶意服务器 | D13 §4、红线 R9.6 |
| 身份 | mTLS 客户端证书（设备签发证书，见 G2.1）+ 会话票据双重校验 | D13 §4、R9.7/R9.8 |
| 证明 | 每次会话首包携带 quote；服务端 G2.1 校验后发放票据 | R9.8 |
| 最小字段 | 请求体 schema 白名单强制：`deviceKeyHash / contextDelta / privacyMode / budget` + 推理必要字段；超白名单字段剥离去重后仍超 → 422 | D13 §4、R9.3 |
| 隐私声明 | `privacyMode` 声明脱敏等级（plain/masked/summarized）；服务端抽检脱敏声明与内容一致性，违反即拒（联动 G1.3 中间件） | D13 §4 |
| 预算 | `budget.costCeilingMicros` 硬上限，超限即断流并回 `BUDGET_EXCEEDED`（联动 G1.2 租户 quota） | 红线 R9.4/R9.5 |
| 数据处置 | 处理即弃：正文不落盘、不进训练缓存；仅审计摘要+用量计数保留（G3.2 留存策略） | D13 §4 |
| 防重放 | 票据含 nonce/时间戳；服务端会话状态绑定 source IP 段与 mTLS 指纹 | — |
| 内容策略 | 上游内容安全策略命中 → `CONTENT_POLICY`，端侧可降级本地重算 | D13 §4 |

**不得以假成功回包**：任何失败路径必须返回明确错误码；端侧收到错误码后按 D13 §3 降级（本地重算或 `STATUS_NO_ROUTE`），绝不静默丢任务。

## 6. 部署形态

```
                     ┌──────────────── 云（G 部门） ────────────────┐
 设备 ──TLS1.3+mTLS──► │ 负载均衡(LB/TLS 终结, 证书固定校验)            │
                      │      │                                        │
                      │   ┌──▼───┐   ┌──────────┐   ┌─────────────┐  │
                      │   │Broker │──►│ 上游模型  │   │ G2.1/G2.2   │  │
                      │   │Gateway│   │ 供应商    │   │ 证明/票据服务 │  │
                      │   └──┬───┘   └──────────┘   └─────────────┘  │
                      │      │                                        │
                      │   ┌──▼────────────────────┐                   │
                      │   │ 审计摘要/用量（G5.1 审计台 │◄── G1.2 配额/记账   │
                      │   └───────────────────────┘                   │
                      └──────────────────────────────────────────────┘
```

- **多副本无状态**：Broker Gateway 无状态（会话状态放 Redis/内存外置），水平扩容；会话票据为自包含 JWT 风格（含签名），任意副本可校验。
- **就近/地域**：按 G3.2 地域策略部署（`broker-cn-north-1`、`broker-eu-west-1` 等），设备按地域白名单解析（联动端侧域名白名单）。
- **上游抽象**：自建或白名单第三方供应商通过统一 `UpstreamAdapter` 接入；切换供应商不影响设备侧契约（D13 §8 开放问题 4 落地）。
- **隔离**：Broker 与训练/数据管道网络隔离；只开放 443/8443 入站。

## 7. 与端侧联动

| 端侧 | 联动点 |
|---|---|
| `IAgentInferenceRouter.attestDevice()` | 会话握手时端侧生成 `AttestationReport` → 映射为会话请求 `attestation` 字段 |
| `IAgentInferenceRouter.preflightEgress()` | 端侧出网前生成 `EgressPlan`（fieldsToSend/fieldsMasked/localOnly），Broker 端字段白名单与之一致（两端同一 schema 权威：D13） |
| `CloudGateway`（A9.2 待实现） | 端侧出网组件：TLS1.3 + mTLS + 白名单域名解析 + 会话票据缓存/刷新 |
| `InferenceRequest.costCeilingMicros` | 与 `budget.costCeilingMicros` 一致；Broker usage 签名回传 → ACB `AgentBudget` 记账 |
| `IInferenceCallback.onRouteChosen(tier)` | 端侧回调告知 Agent"在云上跑"（TIER_CLOUD） |
| 断线降级 | Broker `UPSTREAM_UNAVAILABLE`/超时 → 端侧本地重算，不静默丢任务（D13 §6） |
| `ForgetRequest.confirmCloudDeletion` | 端侧记忆 forget 时发送删除凭证 → Broker 删除传播入口（G3.1） |

## 8. 验收口径

- [ ] H3.4 端云链路 e2e 通过：证明→Broker→回传、脱敏断言、断线降级、删除传播联动
- [ ] `/v1/responses`、`/v1/realtime`、`/v1/transcribe` 三接口 OpenAI 兼容子集联调通过
- [ ] 无票据/过期票据/吊销票据请求均被拒（HTTP 401/403），吊销生效 ≤1 分钟（R9.9）
- [ ] 超白名单字段请求返回 `FIELD_VIOLATION`（422）（R9.3）
- [ ] `costCeilingMicros` 硬上限生效，超限断流返回 `BUDGET_EXCEEDED`（R9.4/R9.5）
- [ ] usage 回传带服务端签名，端侧可验签（防篡改计费）
- [ ] 正文不落盘；审计只含摘要（G3.2 留存符合）
- [ ] 证明+握手开销 P95 ≤100ms（R9.10，含 G2.1 校验）
- [ ] 所有失败路径返回明确错误码，无假成功回包

## 9. 遗留项

1. **上游供应商抽象**：多供应商切换时的证明链差异与 SLA 归一（D13 §8 开放问题 4）——建议 v1 只支持厂商自建单供应商，v2 开放白名单第三方。
2. **realtime 协议子集边界**：OpenAI Realtime 功能面收敛（哪些事件保留/裁剪）需与 B 部门会话服务（B3.x）联合冻结。
3. **证书轮换**：Broker 服务端证书指纹轮换流程（对齐密钥方案 §6 轮换策略），需在 E2.3 评审后定稿。
4. **会话票据与 G2.2 吊销通道**：票据吊销的推送/拉取机制细节见 G2.2，Broker 侧订阅吊销事件流。
5. **内容策略本地化**：`CONTENT_POLICY` 的上游内容安全服务接入方式（自建 vs 供应商）待定。
