# A3.2 执行中介快速参考

> **版本**: 2.0.0（对齐 `com.genton.action` 唯一落地实现）
> **更新日期**: 2026-09-07
> **适用于**: AI Native OS A1 里程碑（D2 §3）

---

## 概述

**AgentActionService（com.android.server.genton）** 是 `com.genton.action.IAgentActionService`
的唯一实现，是副作用动作的**唯一入口**。每次动作强制走：

```
注册表校验 → 参数 schema 校验 → A4.2 策略引擎 requestCapability
  →（DEC_REQUIRE_CONFIRMATION → 确认宿主展示并等用户直回）
  → ActionExecutorDispatcher.dispatch（持令牌）
  → 审计落链 → 8 态状态机 → 终态回调解绑
```

红线：
1. 未知动作/未知能力/无 requiredCapability → 拒绝（fail-secure）
2. DENY / REQUIRE_MITIGATION 一律终态 FAILED，**不执行**（完整 mitigation 编排属 A3.4）
3. 确认决策由用户（SystemUI/确认宿主）**直回中介，不经大脑**（A11.2）
4. 终态回调后服务自动解绑（unlinkToDeath），不再有后续回调

## 核心接口（`com.genton.action`）

### IAgentActionService

```java
package com.genton.action;

int submitAction(in ActionRequest request, in IAgentActionCallback callback,
                 out String[] actionRequestId);
int cancelAction(in String actionRequestId);
ActionExecutionStatus getActionStatus(in String actionRequestId);
ActionInfo describeAction(in String actionName);
ActionInfo[] listActions();
```

### IAgentActionCallback（oneway，终态后服务自动解绑）

```java
interface IAgentActionCallback {
    oneway void onStatusChanged(in String actionRequestId, in ActionExecutionStatus status);
}
```

### Parcelable 结构

```java
parcelable ActionRequest {
    String actionName;              // 注册表动作名（A3.1 registry name）
    Bundle arguments;               // 参数（执行器以 JSON 消费）
    String[] taintedArgumentKeys;   // 参数来源打标（模型标 tainted 的键）
    String sourceIntentId;          // 触发意图 id（scope 锚定）
    String agentId;
    String reason;                  // 人类可读理由（确认 UI 展示）
}

parcelable ActionExecutionStatus {
    String actionRequestId;
    int state;                       // STATE_* 1..8
    long updatedAtRealtimeNanos;
    @nullable ActionResult result;   // 终态携带
}

parcelable ActionResult {
    int resultCode;   // RESULT_* 0..9
    String error;
    Bundle data;      // 执行器成功负载（resultJson）
    String auditEventId;
    String evidenceRef;
}

parcelable ActionInfo { /* actionId/name/description/actionType/executorType/
   executorConfig/assetId/parametersSchema/requiredPermissions/
   requiredCapabilities/category/tags/enabled/avgLatencyMs/successRate/registeredAt */ }
```

## 8 态状态机

| 态 | 常量 | 含义 |
|----|------|------|
| 1 | `STATE_QUEUED` | 已受理入队 |
| 2 | `STATE_POLICY_CHECK` | 策略闸门中（requestCapability） |
| 3 | `STATE_CONFIRMATION` | 等用户确认（高风险，60s 看门狗） |
| 4 | `STATE_EXECUTING` | 持令牌执行中（30s 执行看门狗） |
| 5 | `STATE_SUCCEEDED` | 终态：成功（result=RESULT_OK） |
| 6 | `STATE_FAILED` | 终态：策略拒绝/taint/执行错/超时 |
| 7 | `STATE_ABORTED` | 终态：cancel / 客户端进程死亡 |
| 8 | `STATE_EXPIRED` | 终态：确认超时（E1.1：超时不得执行） |

```
QUEUED(1) → POLICY_CHECK(2)
              ├─ GRANT(STATUS_OK+DEC_GRANT) ─→ EXECUTING(4) → SUCCEEDED(5)/FAILED(6)
              ├─ DEC_REQUIRE_CONFIRMATION ─→ CONFIRMATION(3)
              │      ├─ allow → 持补签令牌 EXECUTING(4)
              │      ├─ deny/token null → FAILED(6, RESULT_CONFIRMATION_DENIED)
              │      └─ 超时 → EXPIRED(8)
              ├─ DEC_REQUIRE_MITIGATION ─→ FAILED(6, RESULT_TAINT_DENIED)  // A3.4 编排
              └─ DEC_DENY / 未知能力 ─→ FAILED(6, RESULT_POLICY_DENIED)
```
非终态可经 `cancelAction` → ABORTED(7)；晚到的执行结果不再覆盖终态。

## 返回码（与 IAgentActionService 常量一致）

### submitAction（同步闸门）

| 常量 | 值 | 含义 |
|------|---|------|
| `SUBMIT_ACCEPTED` | 0 | 已受理进入异步执行（GRANT 直通） |
| `SUBMIT_UNKNOWN_ACTION` | 1 | 不在注册表/disabled |
| `SUBMIT_POLICY_DENIED` | 2 | 策略拒绝 |
| `SUBMIT_ARGUMENT_INVALID` | 3 | 参数 schema 校验失败 |
| `SUBMIT_TAINT_DENIED` | 4 | 参数来源含未授权 taint |
| `SUBMIT_CONFIRMATION_REQUIRED` | 5 | 已生成确认等待用户（状态=CONFIRMATION） |

### 终态结果码（ActionResult.resultCode）

`RESULT_OK=0 / POLICY_DENIED=1 / ARGUMENT_INVALID=2 / TAINT_DENIED=3 /
CONFIRMATION_DENIED=4 / EXECUTION_ERROR=5 / TIMEOUT=6 / CANCELLED=7 /
INTERNAL_ERROR=8 / NOT_FOUND=9`（`cancelAction` 返回 RESULT_OK / RESULT_NOT_FOUND）

## 使用示例

### 1. 授权路径提交

```java
ActionRequest req = new ActionRequest();
req.actionName = "ui.tap";
req.agentId = "agent_123";
req.sourceIntentId = "intent_456";
Bundle args = new Bundle();
args.putString("nodeId", "btn_send");
req.arguments = args;                 // taintedArgumentKeys = null（无模型来源数据）
req.reason = "点击发送按钮";

IAgentActionCallback cb = new IAgentActionCallback.Stub() {
    @Override public void onStatusChanged(String id, ActionExecutionStatus st) {
        if (st.state == IAgentActionService.STATE_SUCCEEDED) {
            // st.result.data.getString("resultJson")
        }
    }
};

String[] outId = new String[1];
int rc = actionService.submitAction(req, cb, outId);
// rc == SUBMIT_ACCEPTED → outId[0]
```

### 2. 确认路径（决策直回，不经大脑）

```java
// 提交高风险动作（如 notification.reply）
int rc = actionService.submitAction(req, cb, outId);   // rc == SUBMIT_CONFIRMATION_REQUIRED
// 状态回调 → STATE_CONFIRMATION；SystemUI 确认面板由 ConfirmationHostService 展示
// 用户决策 → ConfirmationHostService.onUserDecision → IPolicyEngine.reportUserDecision
//   （out CapabilityToken 补签）→ ConfirmDecisionListener 直回中介 → 继续执行
// 调用方无需处理确认回灌；等待回调进入 STATE_EXECUTING / 终态即可
```

### 3. 取消 / 查询

```java
actionService.cancelAction(requestId);             // 正等确认时同步撤策略挂起+关确认 UI
ActionExecutionStatus st = actionService.getActionStatus(requestId);
ActionInfo info = actionService.describeAction("ui.tap");
ActionInfo[] all = actionService.listActions();
```

## 关键实现语义

| 项 | 行为 |
|----|------|
| 注册表装配 | 启动读 `/vendor/genton/config/action_registry.json`（A3.1 registry：`name→actionId`、`executorId→executorType`、`requiredCapability→requiredCapabilities[0]`、`inputSchema→parametersSchema`）；缺失则内置 12 动作兜底 |
| 参数校验 | 解析 schema `required` 数组，缺键/解析异常 → SUBMIT_ARGUMENT_INVALID（fail-secure） |
| 策略闸门 | `CapabilityRequest{agentId,intentId=sourceIntentId,capability,actionId,targetSummary,argTaints(taintedArgumentKeys→TRUST_APP_CONTENT),riskEstimate}` |
| 令牌校验 | GRANT 持 `decision.token` 进执行；确认回灌令牌由 `PolicyEngineService.reportUserDecision` 经 out 回填字段 |
| 执行超时 | 30s → FAILED(RESULT_TIMEOUT)；确认超时 60s → EXPIRED(RESULT_TIMEOUT) |
| 终态保留 | 5min 后清理请求（供 getActionStatus 查询）；确认映射同步清理 |
| 客户端死亡 | `linkToDeath` 感知 → 撤确认 → ABORTED(RESULT_CANCELLED, client_died) |
| 回调解绑 | 终态推送后 `unlinkToDeath` + 清回调（契约：无后续回调） |
| 权限 | 全部 5 入口 `enforceCallingOrSelfPermission(MANAGE_AI_NATIVE_AGENTS)` |
| 审计 | AuditInstrumentation：submitted/policy_grant/policy_denied/taint_denied/confirmation_required/executing/succeeded/failed/expired/aborted + recordPolicyDecision(grant/deny/…) |
