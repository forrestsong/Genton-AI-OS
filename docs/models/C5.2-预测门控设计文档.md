## 1. 背景与目标

### 1.1 问题陈述

C5.1 实现了基础门控机制（置信度分档 + 敏感场景暂停 + 预算检查），但仍缺乏：

1. **审计热度反馈**：未利用历史成功/失败模式调整策略
2. **权限状态感知**：预测可能触发的权限请求被动触发，影响体验
3. **用户偏好记忆**：用户明确拒绝的场景仍可能重复预测
4. **动态调整**：门控策略固定，无法根据运行时数据自适应

### 1.2 设计目标

**C5.2 预测门控**在 C5.1 基础上增强：

| 能力 | C5.1 基线 | C5.2 增强 |
|---|---|---|
| **置信度门控** | 固定阈值（HIGH ≥0.9, MEDIUM ≥0.7） | 动态阈值，基于 App/场景历史命中率调整 |
| **敏感场景** | 硬编码规则（支付/输入） | + 用户明确拒绝场景记忆黑名单 |
| **权限检查** | 无 | 预判权限状态，未授权场景降级或跳过 |
| **审计反馈** | 仅记录日志 | 热度分析（高失败率 App 降低预测频率） |
| **统计透明** | 基础命中率/浪费率 | 分 App/场景/时段的细粒度统计入审计 |

### 1.3 核心约束

- **安全优先**：所有门控决策写入审计链，可追溯
- **用户主权**：记忆黑名单优先级最高，用户拒绝即永久生效
- **渐进增强**：C5.1 基础门控保持不变，C5.2 为可选增强层

## 3. 审计热度信号

### 3.1 热度指标定义

从审计服务 `IAgentAuditService` 中查询预测相关事件，提取：

| 指标 | 定义 | 计算方式 | 用途 |
|---|---|---|---|
| **App 成功率** | 该 App 预测命中率 | hits / (hits + misses) | 高成功率 App 提高置信度阈值 |
| **App 失败率** | 该 App 预测浪费率 | misses / total | 高失败率 App 降低预测频率 |
| **场景成功率** | 特定场景（时段+位置）命中率 | 按时段/位置分组统计 | 高成功场景放宽门控 |
| **动作平均延迟减少** | 预测命中后的延迟节省 | avg(timeSaved) | 高价值动作优先预测 |

### 3.4 热度驱动策略调整

```kotlin
class DynamicPolicyAdjuster(private val auditSignal: AuditSignalExtractor) {
    /**
     * 根据历史成功率动态调整置信度阈值
     */
    fun adjustThreshold(
        baseThreshold: Float,
        packageName: String,
        context: SceneContext
    ): Float {
        val appSuccessRate = auditSignal.getAppSuccessRate(packageName)
        val sceneSuccessRate = auditSignal.getSceneSuccessRate(context.hour, context.location)
        
        // 调整策略：
        // - App 成功率 >80%：降低阈值 0.05（更激进）
        // - App 成功率 <30%：提高阈值 0.1（更保守）
        // - 场景成功率 >70%：降低阈值 0.03
        
        var adjusted = baseThreshold
        
        when {
            appSuccessRate > 0.8f -> adjusted -= 0.05f
            appSuccessRate < 0.3f -> adjusted += 0.1f
        }
        
        if (sceneSuccessRate > 0.7f) {
            adjusted -= 0.03f
        }
        
        return adjusted.coerceIn(0.5f, 0.95f)  // 限制在 [0.5, 0.95] 范围
    }
}
```

## 4. 权限状态检查

### 4.1 权限检查场景

预测动作可能触发敏感权限请求，影响用户体验：

| 预测动作 | 可能触发权限 | 门控策略 |
|---|---|---|
| **预热 App** | 无权限要求 | 放行 |
| **预创建 Activity** | 可能触发定位/相机/麦克风等 | 检查权限状态，未授权则降级为仅预热 |
| **预取数据** | 可能触发存储/网络权限 | 检查权限，未授权则跳过 |
| **预订阅 UI** | AccessibilityService 权限 | 检查服务状态 |

### 4.2 敏感权限列表


### 4.3 权限检查器实现

```kotlin
class PermissionChecker(private val context: Context) {
    /**
     * 检查目标 App 的权限状态
     */
    fun checkAppPermissions(
        packageName: String,
        actionType: PrefetchActionType
    ): PermissionCheckResult {
        // 1. 获取 App 的已授权权限列表
        val packageManager = context.packageManager
        val packageInfo = try {
            packageManager.getPackageInfo(packageName, PackageManager.GET_PERMISSIONS)
        } catch (e: Exception) {
            return PermissionCheckResult.Unknown("Package not found")
        }
        
        val requestedPermissions = packageInfo.requestedPermissions ?: emptyArray()
        val grantedPermissions = requestedPermissions.filterIndexed { index, permission ->
            (packageInfo.requestedPermissionsFlags[index] and PackageInfo.REQUESTED_PERMISSION_GRANTED) != 0
        }.toSet()
        
        // 2. 根据动作类型判断是否触发敏感权限
        val requiredPermissions = when (actionType) {
            PrefetchActionType.PRECREATE_ACTIVITY -> {
                // 可能触发运行时权限
                requestedPermissions.filter { it in SensitivePermissions.RUNTIME_PERMISSIONS }
            }
            PrefetchActionType.PREFETCH_DATA -> {
                // 可能触发存储权限
                requestedPermissions.filter { it in SensitivePermissions.STORAGE_PERMISSIONS }
            }
            else -> emptyList()
        }
        
        val ungrantedPermissions = requiredPermissions.filter { it !in grantedPermissions }
        
        // 3. 返回检查结果
        return if (ungrantedPermissions.isEmpty()) {
            PermissionCheckResult.Granted
        } else {
            PermissionCheckResult.Denied(ungrantedPermissions)
        }
    }
}

sealed class PermissionCheckResult {
    object Granted : PermissionCheckResult()
    data class Denied(val missingPermissions: List<String>) : PermissionCheckResult()
    data class Unknown(val reason: String) : PermissionCheckResult()
}
```

### 4.4 权限驱动降级策略

```kotlin
fun applyPermissionPolicy(
    predictedAction: PredictedAction,
    permissionResult: PermissionCheckResult
): GateDecision {
    return when (permissionResult) {
        is PermissionCheckResult.Granted -> {
            GateDecision.allow(ExecutionStrategy.ALLOW_PRECREATE, "Permission granted")
        }
        is PermissionCheckResult.Denied -> {
            // 降级策略：预创建降级为仅预热
            if (predictedAction.actionType == PrefetchActionType.PRECREATE_ACTIVITY) {
                GateDecision.allow(
                    ExecutionStrategy.ALLOW_PREFETCH_ONLY,
                    "Permission denied: ${permissionResult.missingPermissions.joinToString()}, downgrade to prewarm"
                )
            } else {
                GateDecision.reject("Permission denied: ${permissionResult.missingPermissions.joinToString()}")
            }
        }
        is PermissionCheckResult.Unknown -> {
            GateDecision.reject("Permission check failed: ${permissionResult.reason}")
        }
    }
}
```

## 5. 记忆黑名单

### 5.1 黑名单场景

用户可以明确拒绝特定场景的预测行为：

| 场景 | 触发方式 | 黑名单粒度 |
|---|---|---|
| **特定 App 预测** | 用户关闭"预测打开微信"设置 | App 级别 |
| **特定时段预测** | 用户拒绝"晚上 10 点后预测社交 App" | 时段 + App 类型 |
| **特定场景预测** | 用户拒绝"在办公室预测游戏" | 位置 + App 类型 |

### 5.2 黑名单存储 Schema

### 5.3 黑名单检查器

```kotlin
class MemoryBlacklistChecker(private val memoryService: IAgentMemoryService) {
    /**
     * 检查预测是否在黑名单中
     */
    fun isBlacklisted(
        predictedAction: PredictedAction,
        context: SceneContext
    ): BlacklistCheckResult {
        // 1. 从记忆服务查询黑名单
        val query = MemoryQuery.Builder()
            .kind(IAgentMemoryService.KIND_SYSTEM)  // 系统记忆层
            .tag("prediction_blacklist")
            .build()
        
        val blacklistEntries = memoryService.query(query)
            .mapNotNull { parseBlacklistEntry(it) }
        
        // 2. 逐条检查匹配
        for (entry in blacklistEntries) {
            if (matches(entry.scope, predictedAction, context)) {
                return BlacklistCheckResult.Blocked(entry)
            }
        }
        
        return BlacklistCheckResult.Allowed
    }
    
    /**
     * 匹配黑名单规则
     */
    private fun matches(
        scope: BlacklistScope,
        action: PredictedAction,
        context: SceneContext
    ): Boolean {
        return when (scope) {
            is BlacklistScope.AppLevel -> {
                action.targetApp == scope.packageName
            }
            is BlacklistScope.TimeSlot -> {
                context.hour in scope.hourStart..scope.hourEnd &&
                (scope.appCategory == null || matchesCategory(action.targetApp, scope.appCategory))
            }
            is BlacklistScope.Location -> {
                context.location == scope.location &&
                (scope.appCategory == null || matchesCategory(action.targetApp, scope.appCategory))
            }
            is BlacklistScope.Composite -> {
                scope.conditions.all { matches(it, action, context) }
            }
        }
    }
}

sealed class BlacklistCheckResult {
    object Allowed : BlacklistCheckResult()
    data class Blocked(val entry: PredictionBlacklistEntry) : BlacklistCheckResult()
}
```

```kotlin
class PredictionBlacklistManager(private val memoryService: IAgentMemoryService) {
    /**
     * 添加黑名单条目
     */
    fun addBlacklist(scope: BlacklistScope, reason: String, ttl: Long? = null) {
        val entry = PredictionBlacklistEntry(
            id = UUID.randomUUID().toString(),
            scope = scope,
            reason = reason,
            createdAt = System.currentTimeMillis(),
            expiresAt = ttl?.let { System.currentTimeMillis() + it }
        )
        
        val draft = MemoryEntryDraft.Builder()
            .kind(IAgentMemoryService.KIND_SYSTEM)
            .content(serializeBlacklistEntry(entry))
            .tag("prediction_blacklist")
            .provenance(ProvenanceInfo.fromUserExplicit())
            .build()
        
        val result = MemoryEntry()
        memoryService.write(draft, result)
    }
    
    /**
     * 移除黑名单条目
     */
    fun removeBlacklist(entryId: String) {
        memoryService.deleteById(entryId)
    }
}
```

## 6. 增强门控决策融合

### 6.1 决策优先级

多源信号按优先级仲裁：

```
优先级 1（最高）：记忆黑名单 → 直接拒绝
优先级 2：敏感场景检测 → 直接拒绝
优先级 3：权限检查 → 降级或拒绝
优先级 4：动态置信度门控 → 基于热度调整阈值
优先级 5：预算检查 → 资源限制拒绝
```

### 6.2 融合决策器实现

```kotlin
class EnhancedGateControl(
    private val context: Context,
    private val baseGate: GateControl,                          // C5.1 基础门控
    private val auditSignal: AuditSignalExtractor,             // 审计热度
    private val permissionChecker: PermissionChecker,          // 权限检查
    private val blacklistChecker: MemoryBlacklistChecker,      // 黑名单检查
    private val policyAdjuster: DynamicPolicyAdjuster          // 动态策略
) {
    /**
     * 增强门控决策
     */
    fun shouldExecute(
        predictedAction: PredictedAction,
        contextFrame: ContextFrame
    ): EnhancedGateDecision {
        val signals = mutableListOf<GateSignal>()
        
        // 1. 【优先级 1】记忆黑名单检查
        val blacklistResult = blacklistChecker.isBlacklisted(
            predictedAction,
            SceneContext.from(contextFrame)
        )
        if (blacklistResult is BlacklistCheckResult.Blocked) {
            return EnhancedGateDecision.reject(
                reason = "User explicitly blocked: ${blacklistResult.entry.reason}",
                signals = signals,
                priority = 1
            )
        }
        signals.add(GateSignal.Blacklist(blacklistResult))
        
        // 2. 【优先级 2】基础敏感场景检测（C5.1）
        val baseDecision = baseGate.shouldExecute(predictedAction, contextFrame)
        if (!baseDecision.allowed && baseDecision.reason.contains("Sensitive")) {
            return EnhancedGateDecision.from(baseDecision, signals, priority = 2)
        }
        signals.add(GateSignal.BaseSensitive(baseDecision))
        
        // 3. 【优先级 3】权限检查
        val permissionResult = permissionChecker.checkAppPermissions(
            predictedAction.targetApp ?: "",
            predictedAction.actionType
        )
        signals.add(GateSignal.Permission(permissionResult))
        
        if (permissionResult is PermissionCheckResult.Denied) {
            // 降级策略
            if (predictedAction.actionType == PrefetchActionType.PRECREATE_ACTIVITY) {
                return EnhancedGateDecision.allow(
                    executionStrategy = ExecutionStrategy.ALLOW_PREFETCH_ONLY,
                    reason = "Permission denied, downgrade to prewarm",
                    signals = signals,
                    priority = 3
                )
            } else {
                return EnhancedGateDecision.reject(
                    reason = "Permission denied",
                    signals = signals,
                    priority = 3
                )
            }
        }
        
        // 4. 【优先级 4】动态置信度门控
        val sceneContext = SceneContext.from(contextFrame)
        val adjustedThreshold = policyAdjuster.adjustThreshold(
            baseThreshold = 0.7f,
            packageName = predictedAction.targetApp ?: "",
            context = sceneContext
        )
        signals.add(GateSignal.DynamicThreshold(adjustedThreshold))
        
        if (predictedAction.confidence < adjustedThreshold) {
            return EnhancedGateDecision.reject(
                reason = "Confidence ${predictedAction.confidence} below adjusted threshold $adjustedThreshold",
                signals = signals,
                priority = 4
            )
        }
        
        // 5. 【优先级 5】预算检查（C5.1）
        if (!baseDecision.allowed) {
            return EnhancedGateDecision.from(baseDecision, signals, priority = 5)
        }
        
        // 全部通过
        return EnhancedGateDecision.allow(
            executionStrategy = ExecutionStrategy.ALLOW_PRECREATE,
            reason = "All checks passed",
            signals = signals,
            priority = 99
        )
    }
}

/**
 * 增强门控决策
 */
data class EnhancedGateDecision(
    val allowed: Boolean,
    val executionStrategy: ExecutionStrategy?,
    val reason: String,
    val signals: List<GateSignal>,         // 各检查器信号
    val priority: Int                      // 决策优先级（1 最高）
) {
    companion object {
        fun allow(
            executionStrategy: ExecutionStrategy,
            reason: String,
            signals: List<GateSignal>,
            priority: Int
        ) = EnhancedGateDecision(true, executionStrategy, reason, signals, priority)
        
        fun reject(
            reason: String,
            signals: List<GateSignal>,
            priority: Int
        ) = EnhancedGateDecision(false, null, reason, signals, priority)
        
        fun from(
            baseDecision: GateDecision,
            signals: List<GateSignal>,
            priority: Int
        ) = EnhancedGateDecision(
            baseDecision.allowed,
            baseDecision.executionStrategy,
            baseDecision.reason,
            signals,
            priority
        )
    }
}

/**
 * 门控信号
 */
sealed class GateSignal {
    data class Blacklist(val result: BlacklistCheckResult) : GateSignal()
    data class BaseSensitive(val decision: GateDecision) : GateSignal()
```

## 7. 命中/浪费统计入审计

### 7.1 统计指标

| 指标 | 定义 | 聚合维度 | 用途 |
|---|---|---|---|
| **命中率** | hits / (hits + misses) | App / 场景 / 时段 | 评估预测准确性 |
| **浪费率** | recycled / total | App / 场景 | 评估资源效率 |
| **平均延迟减少** | avg(timeSaved) | App / 动作类型 | 评估价值 |
| **门控拒绝率** | rejected / total | 拒绝原因 | 评估门控策略 |

### 7.2 统计聚合器

```kotlin
class PredictionMetricsAggregator(
    private val auditService: IAgentAuditService
) {
    /**
     * 聚合预测统计（按 App）
     */
    fun aggregateByApp(packageName: String, days: Int = 7): AppMetrics {
        val query = AuditQuery.Builder()
            .eventType("prediction.*")
            .timeRange(System.currentTimeMillis() - days * 86400000L, System.currentTimeMillis())
            .filter("predictedApp", packageName)
            .build()
        
        val events = auditService.queryEvents(query)
        
        val total = events.count { it.type == "prediction.made" }
        val gatePass = events.count { it.type == "prediction.gate_pass" }
        val gateReject = events.count { it.type == "prediction.gate_reject" }
        val hits = events.count { it.type == "prediction.hit" }
        val misses = events.count { it.type == "prediction.miss" }
        val recycled = events.count { it.type == "prediction.recycled" }
        
        val timeSaved = events
            .filter { it.type == "prediction.hit" }
            .mapNotNull { it.payload["timeSavedMs"] as? Long }
            .average()
        
        return AppMetrics(
            packageName = packageName,
            totalPredictions = total,
            gatePassRate = if (total > 0) gatePass.toFloat() / total else 0f,
            gateRejectRate = if (total > 0) gateReject.toFloat() / total else 0f,
            hitRate = if (gatePass > 0) hits.toFloat() / gatePass else 0f,
            wasteRate = if (gatePass > 0) recycled.toFloat() / gatePass else 0f,
            avgTimeSavedMs = timeSaved.toLong()
        )
    }
    
    /**
     * 聚合门控拒绝原因分布
     */
    fun aggregateGateRejectReasons(days: Int = 7): Map<String, Int> {
        val query = AuditQuery.Builder()
            .eventType("prediction.gate_reject")
            .timeRange(System.currentTimeMillis() - days * 86400000L, System.currentTimeMillis())
            .build()
        
        val events = auditService.queryEvents(query)
        
        return events
            .groupBy { it.payload["gateReason"] as? String ?: "Unknown" }
            .mapValues { it.value.size }
    }
}

data class AppMetrics(
    val packageName: String,
    val totalPredictions: Int,
    val gatePassRate: Float,
    val gateRejectRate: Float,
    val hitRate: Float,
    val wasteRate: Float,
    val avgTimeSavedMs: Long
)
```

```kotlin
class PredictionAuditLogger(
    private val auditService: IAgentAuditService
) {
    fun logGateDecision(
        predictedAction: PredictedAction,
        decision: EnhancedGateDecision,
        context: ContextFrame
    ) {
        val event = AuditEvent.Builder()
            .type(if (decision.allowed) "prediction.gate_pass" else "prediction.gate_reject")
            .timestamp(System.currentTimeMillis())
            .payload(mapOf(
                "predictedApp" to predictedAction.targetApp,
                "predictedAction" to predictedAction.actionType.name,
                "confidence" to predictedAction.confidence,
                "gateDecision" to if (decision.allowed) "ALLOW" else "REJECT",
                "gateReason" to decision.reason,
                "gatePriority" to decision.priority,
                "signals" to serializeSignals(decision.signals),
                "context" to serializeContext(context)
            ))
            .build()
        
        auditService.logEvent(event)
    }
}
```
