# H4.3 S7 功耗差分建档方法

> 任务编号：H4.3（质量工程部 · S7 功耗差分建档）
> 里程碑：A5 · 前置：H4.2 · 依赖草案：D9 §8.4/§8.5b
> 状态：📋 方法文档（S7 开启 vs 关闭的功耗差分验收基准）

## 1. 目的与验收口径

对 **S7 姿态交互**（MotionHub 常驻低功耗监测 + 摇一摇/翻面识别）做
**开启 vs 关闭**的整机功耗差分，判定是否满足 A5 门禁：

| 指标 | 验收上限（对齐 D9 §8.4） | 测量口径 |
|---|---|---|
| 整机日均新增电量 | **<0.5%** | 开启 S7 vs 关闭 S7 的 24h 整机日耗电差分 |
| 待机新增功耗 | **<0.2%** | 息屏待机场景电流差分（占比） |
| 相机就绪空转 | **15–30s 上限** | 相机就绪后空转时长上限验证（防止常驻占用） |

> 差分口径 = **相对"关闭 S7"的整机新增功耗**（D9 §8.5b），非绝对值。

## 2. 测量环境（对齐 H4.1 §2.3）

- 机型：REF_Snapdragon_7Gen3（T2 深睡档，Sensor Hub/AON）为主测；
  CPDAY10（无 AON，T1 前台档）为对照；
- 电源：Monsoon 电源表 / 高精度电流计（采样率 ≥1kHz）；
- 温度：25±3℃，全程无充电（用电源表供电）；
- 网络：Wi-Fi 6E 连接、蜂窝驻留 5G NSA；
- 系统：同一 build，仅切换 S7 编译开关（`BOARD_MOTION_HUB_ENABLED`
  true/false），其余完全一致。

## 3. 差分测量方法

### 3.1 待机电流差分（standby delta）

```
步骤：
1. 关闭 S7（编译开关 false）→ 刷机 → 恢复出厂 → 静置 10min
2. 息屏待机 4h，记录平均电流 I_off（mA）与电量消耗 Q_off（mAh）
3. 开启 S7（编译开关 true）→ 刷机 → 恢复出厂 → 静置 10min
4. 息屏待机 4h，记录平均电流 I_on（mA）与电量消耗 Q_on（mAh）
5. 待机新增 = (Q_on - Q_off) / Q_off × 100%
```

- 待机新增占比 **<0.2%** 即达标；
- 注意排除：系统更新、后台任务抖动（取 3 轮中位数，弃首轮预热）。

### 3.2 场景电流差分（scenario delta）

覆盖场景（各 30min，亮度/网络固定）：

| 场景 | 说明 | 关注点 |
|---|---|---|
| 亮屏待机 | 200nit 桌面静止 | 前台档常驻监测增量 |
| 亮屏滚动 | 系统设置页滚动 | 传感器采样 + 渲染 |
| 相机就绪空转 | 打开相机后保持就绪 15–30s | **空转时长上限**（§4） |
| 通话 | 拨号接通静默 | 传感器/音频边界 |
| 通知风暴 | 高频通知 | 监测 + 策略判定 |

每个场景记录平均电流 `I_off / I_on`，计算绝对增量 `ΔI = I_on - I_off` 与
占整机比 `ΔI / I_off × 100%`。

### 3.3 整机日均新增电量（daily delta）

```
整机日均新增 = Σ(各场景 ΔI × 场景日均时长占比) / 整机日均耗电 × 100%
```

- 时长占比参考用户画像（息屏待机 16h / 亮屏 6h / 相机 0.5h / 其他 1.5h）；
- **<0.5%** 即达标（整机日均口径）。

## 4. 相机就绪空转 15–30s 上限验证

S7 摇一摇拍照链路：判定就绪 → 相机预热保持就绪状态。要求**就绪空转
时长上限 15–30s**（避免相机传感器/预览常驻耗电）：

```bash
# 测量脚本（真机，桩传感器回放）
adb shell am start -a com.genton.motionhub.SHAKE_READY
# 观测：就绪后空转超 30s 应自动退出就绪态并释放相机
adb shell dumpsys camera | grep -E "active|state"
adb shell dumpsys power | grep -E "WAKE|Doze"
```

验收：
- 就绪空转 **≤15s 主动降级（低功耗轮询）**、**≤30s 强制退出就绪态**；
- 超过 30s 未退出 → 记录超限缺陷（对齐 H4.2 §7 超限记录）。
