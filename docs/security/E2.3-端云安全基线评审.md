## 0. 结论摘要

出网与双向 TLS/远程证明基线评审结论为 **通过**，并冻结以下基线（作为 G 部门实现与 H3.4 验收的强制输入）：

1. **白名单域**：设备出网只允许 **HTTPS + 域名白名单**（厂商自建 CloudBroker 域 + 已登记合规第三方），任何出网请求必须命中白名单，命中失败即拒绝（`STATUS_DENIED`）。**本地只有一份白名单清单**（系统签名配置，禁止第三方修改）。
2. **最小字段**：出网字段白名单强制（`prompt→ContextRef.delta`、`deviceKeyHash` 不传设备 ID、`privacyMode` 声明、`budget`），违反即拒（R9.3）。
3. **双向 TLS + 远程证明**：mTLS 强制（R9.6）+ 每次会话首包 `AttestationReport` + 短时票据（TTL ≤ 30 分钟）+ 票据吊销 ≤ 1 分钟（R9.9）。
4. **证明开销上限**：attestation 全链路开销 **≤100ms（P95）**（R9.10），通过「票据机制 + 会话级一次证明 + 周期刷新」满足。
5. **预算硬上限**：出网受 ACB `AgentBudget` 硬上限约束（R9.4/R9.5），超支即断流，不得静默超支出网。

**强制落地项（3 项）**：
- F1：域名白名单必须为**系统签名配置 + 设备内不可改**（对齐 D13 §4「设备侧只认签名证书 + 白名单域名」）。
- F2：证明开销指标（attestation P95）纳入 A3 门禁验收（H3.4 e2e），不达标不得出 A3。
- F3：票据吊销必须走「设备端主动拉取 + 云端主动推送」双通道，吊销生效 ≤ 1 分钟（R9.9）。

## 2. 评审正文

### 2.1 白名单域基线

**评审结论：通过，落地需 F1**

- **清单形态**：`overlay/system/etc/genton/egress_whitelist.json`（系统签名配置），条目含：
  ```json
  {
    "version": 1,
    "updatedAt": "2026-09-09",
    "entries": [
      {
        "domain": "broker.genton.example.com",
        "protocol": "https|wss",
        "tlsVersion": ">=1.3",
        "certPinSha256": ["sha256/..."],
        "purpose": "cloud_inference"
      }
    ]
  }
  ```
- **强制约束**：
  - 白名单**禁止第三方 Agent 修改**（系统签名只读）；三方 Agent 出网同样走本白名单（D14 开放问题 1：三方模型端点也受 preflight 约束）。
  - 请求域名解析后必须命中白名单（IP 与 SNI 双重校验，防 DNS 重绑定）。
  - 新增域走「策略包 OTA / 配置更新」通道（系统签名），非应用内可改。
- **第三方 broker 接入**：D13 开放问题 4（厂商自建 vs 白名单第三方）——本评审裁决：**v1 仅允许厂商自建 CloudBroker**；第三方 broker 须满足同款 mTLS/attestation/白名单基线并评审后加入，A4 后评估。

### 2.2 最小字段基线

**评审结论：通过**

- **字段白名单（R9.3）**：出网请求字段集合固定为：
  - `deviceKeyHash`（不传设备 ID，防止设备指纹跨服务关联）；
  - `contextDelta`（增量，不用整包上下文）；
  - `privacyMode`（脱敏声明，服务端校验，违反即拒）；
  - `budget`（预算声明，服务端对账）；
  - 可选 `sessionRef`（会话引用，不传正文）。
- **preflight 强制**：`preflightEgress` 在每次 TIER_CLOUD 前返回 `EgressPlan`，审计 + 用户透明（D13 §2/§5）。字段不在白名单 → `STATUS_DENIED`。
- **本地优先**（D13 开放问题 2 裁决）：`local_only` 约束位 + 策略强制，**文档类/生物特征类默认本地**，不得靠 Agent 自觉——由策略引擎 `constraintMask` 位强制。
- **正文不落云**：`InferenceRequest.prompt` 由 `ContextRef`（packId/kvSession/delta）替代，只传引用 + 增量 + 脱敏摘要（D13 §3 隐私最小化）。

### 2.3 双向 TLS 与远程证明基线

**评审结论：通过**

- **mTLS**：设备端 mTLS 证书（由设备身份密钥签发，TEE 内管理，联动 E2.2 §2.4），服务端证书固定 + 域名白名单（防中间人/恶意服务器）。
- **远程证明流程**（对齐 D13 §4）：
  1. 会话首包携带 `AttestationReport`（含 Keymint 证书链 + challenge 防重放 + boot state）；
  2. 服务端（G2.1）验证证书链与 challenge，通过后发放**短时票据**（TTL ≤ 30 分钟，含设备身份 + 会话 scope + 权限声明）；
  3. 会话内后续请求携带票据（不再全量 attestation），周期刷新；
  4. 票据签发方签名（云侧签名），设备端可验证。
- **票据吊销（R9.9，F3）**：
  - 主动拉取：设备定期（≤ 30s）拉取吊销列表（增量）；
  - 主动推送：云端吊销事件经实时通道（WS/长连接）推送；
  - 生效目标：吊销后 ≤ 1 分钟内设备侧票据失效。
- **证明频率裁决**（D13 开放问题 1）：会话级一次 + 周期刷新（票据 TTL），**不做每次请求全量 attestation**——否则 100ms 开销红线不可达。

### 2.4 证明开销上限

**评审结论：通过（F2 强制验收）**

- **预算拆解**（每次会话首包，P95 合计 ≤100ms）：
  - attestation 本地生成（Keymint quote）：≤20ms；
  - TLS 握手（TLS1.3 0-RTT/resumption）：≤30ms；
  - 服务端验证 + 票据签发：≤20ms；
  - 网络 RTT：≤30ms。
- **缓存与复用**：TLS session resumption + 票据复用，降低后续请求开销。
- **验收方法（H3.4 e2e）**：模拟 1000 次会话建立，统计首包总延迟 P95 ≤ 100ms；不达标 → 优化（缩短票据 TTL 换更少全量证明，或预生成 attestation）。

### 2.5 出网预算与审计

**评审结论：通过**

- **预算硬上限（R9.4/R9.5）**：`costCeilingMicros` 与 ACB `AgentBudget` 联动，`usage_estimate` 实时累计，越过即 `STATUS_BUDGET_EXCEEDED` 断流（D13 §3）。
- **用量防篡改（D13 开放问题 3 裁决）**：`usage_estimate` 由 **CloudBroker 服务端签名**回传，本地不得自报（防 Agent 虚报/漏报）；本地按服务端签名值记账并对账。
- **出网审计**：每次 TIER_CLOUD 记录 `EgressPlan` 摘要（字段清单 + 脱敏状态 + 用量），不落正文；隐私仪表盘「云使用」可见字段清单与用量（D13 §3 透明）。

### 2.6 断线降级与失败语义

**评审结论：通过**

- 网络不可达/证明失败 → 降级本地；无本地则 `STATUS_NO_ROUTE`（**不得静默失败成空结果**，D13 §3）。
- 断线后续传：断点标记 + delta 续传；不可续则本地重算已完成子任务（D13 §6）。
- 证明失败：返回明确错误码 `STATUS_ATTESTATION_FAILED`，不假成功回包（D13 §4 失败语义）。

## 4. 验收口径

- [ ] 白名单清单存在且系统签名；非白名单域出网被拒（用例：访问 `evil.com` → `STATUS_DENIED`）。
- [ ] 出网字段白名单校验：携带非白名单字段 → `STATUS_DENIED`；`privacyMode` 违反 → 服务端拒。
- [ ] mTLS + attestation 握手成功；伪造 attestation → 拒。
- [ ] 票据吊销：吊销后 ≤1min 设备侧票据失效（请求被拒）。
- [ ] 证明开销 P95≤100ms（H3.4）。
- [ ] 预算硬上限：超预算请求被断流（`STATUS_BUDGET_EXCEEDED`）。
- [ ] 每次 TIER_CLOUD 有 `EgressPlan` 审计摘要。
