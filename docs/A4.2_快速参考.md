# A4.2 能力令牌链 - 快速参考

## 核心组件

### 1. AIDL 数据结构
- `CapabilityToken.aidl` - 令牌数据结构（签名/scope/TTL）
- `TokenRevocationInfo.aidl` - 撤销信息

### 2. Java 实现
- `TokenSigner.java` - 令牌签名器（SHA256withRSA）
- `TokenValidator.java` - 令牌验证器（三查）
- `TokenRevocationList.java` - 撤销列表管理
- `TokenManagementService.java` - 令牌管理服务

### 3. 测试工具
- `test_token_chain.py` - 功能测试（6/6 通过）

## 令牌链条闭环

```
大脑 → Runtime(acquireCapabilityToken) → PolicyEngine(签发)
    → 域服务(validateToken 三查) → 执行 → 审计
```

## 三查验证

1. **签名验证**（离线）：SHA256withRSA，防伪造
2. **Scope 校验**：scopeIntentId 强制匹配，防跨意图盗用
3. **TTL + 撤销**：过期检查 + 在线撤销列表

## TTL 策略

- **LOW/MEDIUM**：30 分钟（默认）
- **HIGH/CRITICAL**：5 分钟（短时）
- **最长硬上限**：1 小时

## 撤销场景

1. Agent 注销（terminateAgent）
2. 意图任务结束（revokeByIntent）
3. 用户一键停止授权
4. 策略热更新
5. 安全事件响应

## 性能指标

- 签发延迟 P50 < 2ms
- 验证延迟 P50 < 1ms
- 撤销延迟 P99 < 5ms

## 安全特性

- ✅ Fail-secure：任何失败 = DENY
- ✅ Scope 隔离：防跨意图复用
- ✅ 短时有效：任务结束即废
- ✅ 实时撤销：在线状态管理
- ✅ 策略版本追踪
