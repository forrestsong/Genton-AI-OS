## 1. 目的与口径

H 是验收唯一出口：里程碑达标以 H 实测为准。本文件定义**真机矩阵基线**，
明确机型清单、KPI 实测方法与宏回归执行框架，作为 A2 起所有性能/功耗/
宏回归验收的统一基准。

> 基线口径：所有 KPI 均为 **P95 分位**（对齐 D9 §0 体验目标表）；所有
> 宏回归成功率为**同机型 ≥99% / 跨机型 ≥95% / 跨版本 ≥85%**（对齐
> F1.1 §7.3 混合策略指标表）。

### 2.3 软硬件基线条件

- 系统版本：AI Native OS milestone build（`aosp_*` 变体）+ 厂商 kernel；
- 亮度/音量/网络固定：屏幕 200nit、Wi-Fi 6E、蜂窝 5G NSA、音量 50%；
- 温度基线：设备冷却至 25±3℃ 开始；超过 40℃ 停止测试并回填；
- 电池：≥80% 且充电中，禁用自适应/省电模式；
- 每个机型固定 3 台样机，取中位数机型结果。

## 3. KPI 实测方法（D9 §0 对齐）

### 3.1 指标定义与测量工具

| KPI | 定义（P95） | 测量方法 | 工具 |
|---|---|---|---|
| 命令→可见结果 | 命令提交 → 首个可见结果帧 | 埋点 `form.submit→render.visible`（H5.1 SDK） | `kpi_telemetry.py` + logcat |
| UI 树增量推送 / 快照 | 增量 ≤10ms / 快照 ≤50ms | `IAgentUiTreeService` 桩注入计时 | e2e 脚本 + systrace |
| 热/冷会话切换 | 热 ≤100ms / 冷 ≤300ms | 任务切换埋点（`session.switch.hot/cold`） | systrace + 埋点 |
| 高频操作（DMI/宏） | <100ms 命令→可见 | 宏回归框架计时 | `tools/genton-macro-test.py` |
| 本地唤醒→首响应 | <200ms | 唤醒埋点 | logcat |
| 姿态手势判定 | 摇一摇 ≤150ms / 翻面收声 ≤300ms | `test_e2e_motion.py` 真机版 | 真机 + IMU 回放 |
| 通知栈路由判定 | 判定 ≤20ms；P1 摘要 ≤2s | 路由埋点 | `kpi_telemetry.py` |
| CallGate 判定 | ≤50ms；L1 静默接管 ≤1s | 通话场景脚本 | e2e + 埋点 |
| 本体 query / packContext | ≤10ms / ≤100ms | 服务端计时埋点 | `kpi_telemetry.py` |
| 决策模型（B5.3） | 延迟 P95 ≤100ms | 决策服务埋点 | `kpi_telemetry.py` |
| 带 DMI/宏应用冷启动 | ≤800ms（含首帧） | 冷启动计时 | `am start` + `logcat` |

### 3.2 测量流程（每机型）

1. **准备**：刷机 → 恢复出厂 → 静置 10min → 安装基线 APK 集；
2. **预热**：每项 KPI 前执行 3 次预热，丢弃数据；
3. **采样**：每项 ≥30 个有效样本（宏回归 ≥50），记录 P50/P95/P99；
4. **回填**：写入 `reports/quality/<milestone>/matrix-<device>.json`
   （格式见 H4.2 建档模板）；
5. **门禁判定**：P95 超预算 → 记 `budget_overrun` 并联动缺陷单。

## 4. 宏回归执行框架

### 4.1 流程

```
校准样本库（F4.2，per-机型黄金集）
        │
        ▼
加载宏资产（A8.1 目录）→ 按机型匹配校准 profile
        │
        ▼
执行回归：同机型 ≥99% / 跨机型 ≥95% / 跨版本 ≥85%
        │
        ▼
失败 → 失败率检查（连续 3 次 / 失败率 ≥70% 且样本 ≥5）
        │
        ▼
自动停用回灌 A8.1（reason=auto_disabled_by_ci）
        │
        ▼
报告：report.json / html / junit.xml（ci/macro-ci-config.yaml 对齐）
```

### 4.2 执行命令

```bash
# 全机型宏回归（需设备矩阵在线）
python3 tools/genton-macro-test.py --matrix \
    --devices CPDAY10,REF_Snapdragon_7Gen3 --suite golden

# 单机型冒烟
python3 tools/genton-macro-test.py --device CPDAY10 --suite smoke

# 与 CI 门禁联动（H1.3 资产门之后）
./ci/asset-ci-gate.sh && python3 tools/genton-macro-test.py --matrix
```
