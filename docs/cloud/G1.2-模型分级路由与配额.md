# G1.2 模型分级路由与配额设计

> **任务编号**：G1.2
> **任务名称**：模型分级路由与配额（档位决策、租户 quota、预算记账联动、断线降级语义回传）
> **交付物**：路由配额服务
> **前置依赖**：G1.1（CloudBroker 网关）
> **草案来源**：D13（轨道A-端云调度与推理路由接口草案.md）
> **里程碑**：A3（智能与端云）
> **状态**：设计稿（待实现）

---

## 1. 摘要

模型分级路由的目标是**让每次推理都跑在"最省钱、最快、最隐私"的档位上**，并把成本控制从端侧延伸到云端。

- **端侧档位决策**（`IAgentInferenceRouter`）：`TIER_LOCAL_TINY / TIER_LOCAL_LARGE / TIER_CLOUD` 三档，档位选择由本地决策模型 Choice 判定（架构 §4.12/§4.14），约束位 `local_only / cloud_denied / offline_ok / low_energy` 作为硬约束。
- **云侧分级路由**（本文档 G1.2）：当请求进入云端后，由路由配额服务按**档位决策表**选择具体上游模型（如 cloud-llm-v3-lite / -pro / -turbo），并对**租户 quota**（账户级/设备级/会话级三层）执行硬限。
- **预算记账联动**：云端用量签名回传 → 端侧 ACB `AgentBudget` 记账；端侧 `costCeilingMicros` 硬上限与云端租户 quota 双端强制。
- **断线降级语义回传**：云端不可用/超预算/上游故障时回传明确语义（`STATUS_NO_ROUTE`/`STATUS_BUDGET_EXCEEDED`），端侧据此降级本地重算，**不静默丢任务**。

---

## 2. 职责

| 职责 | 说明 |
|---|---|
| 档位决策表下发 | 向设备下发云端模型档位决策表（可用模型、档位、价格系数、配额提示），设备 `getCapabilities()` 消费 |
| 云侧档位裁决 | 设备请求进入云端后，按 `InferenceRequest.suggestedTier` + 决策表选择具体上游模型（对齐端侧建议，但云端有最终裁决权） |
| 租户 quota | 三层配额：账户级（日/月 token 与成本）、设备级（每设备并发与速率）、会话级（单会话成本硬上限） |
| 预算记账联动 | 用量记账（token/成本）签名回传；与端侧 ACB `AgentBudget` 双向对账 |
| 断线降级语义 | 定义云端各失败语义并映射到端侧状态码，驱动端侧降级链 |
| 配额审计 | 每次配额裁决/超限落审计摘要（G5.1 汇入 A5.3 全链） |


### 3.3 断线降级语义回传（云 → 设备）

| 云端状态 | HTTP | 端侧映射 | 端侧降级动作 |
|---|---|---|---|
| `QUOTA_ACCOUNT_EXCEEDED` | 429 | `STATUS_BUDGET_EXCEEDED` | 降级 `TIER_LOCAL_LARGE`（若可）；否则返回用户"预算用尽，可明日再试" |
| `QUOTA_DEVICE_RATE_EXCEEDED` | 429 | `STATUS_BUDGET_EXCEEDED` | 退避重试（`Retry-After`），或降级本地 |
| `QUOTA_SESSION_EXCEEDED` | 429 | `STATUS_BUDGET_EXCEEDED` | 断流当前会话；端侧标记会话"云额度用尽" |
| `UPSTREAM_UNAVAILABLE` | 503 | `STATUS_NO_ROUTE` | 降级 `TIER_LOCAL_LARGE`/`TIER_LOCAL_TINY` 本地重算 |
| `ATTESTATION_FAILED` | 401 | `STATUS_ATTESTATION_FAILED` | 触发重新证明（G2.1），重试一次；失败则拒绝 |
| `NETWORK_TIMEOUT` | 408/504 | `STATUS_NO_ROUTE` | 断点标记 + delta 续传（D13 §6），不可续则本地重算 |
| `CONTENT_POLICY` | 422 | `STATUS_DENIED` | 本地重算或显式告知用户 |

## 4. 档位决策表（确定性表 + 策略输入）

### 4.1 端侧档位决策表（权威：D13 §3，云侧配置输入）

| 场景 | 决策 | 依据 |
|---|---|---|
| 意图分级=简单（模板化） | `TIER_LOCAL_TINY` / 直走宏 | S5-a 免大模型 |
| 隐私 = `local_only`（文档/金融/生物特征） | 拒绝 `TIER_CLOUD` → `STATUS_DENIED` | 约束位 + 策略 |
| 端侧 NPU 有余量且离线可用 | `TIER_LOCAL_LARGE` | 遥测 + 能力表（A12.2） |
| 需云且授权通过 | `TIER_CLOUD`：preflight → 出网 | 证明 + 白名单 + 预算 |
| 网络不可达/证明失败 | 降级本地；无本地则 `STATUS_NO_ROUTE` | 遥测 |
| 低电量/无充电 | 倾向 `TIER_LOCAL_TINY` + 批量合并云推理 | 节能（D13 §6） |

### 4.2 云侧档位决策表（本文档新增）

| 维度 | 值 | 选中模型 | 配额策略 |
|---|---|---|---|
| 意图复杂度 | simple | cloud-llm-v3-lite | 默认配额 |
| 意图复杂度 | medium | cloud-llm-v3-lite/pro | 默认配额 |
| 意图复杂度 | complex/reasoning | cloud-llm-v3-pro | 限流（并发 ≤1/设备） |
| 上下文长度 | >32k tokens | cloud-llm-v3-pro | 会话成本翻倍计数 |
| 模态 | vision 输入 | cloud-llm-v3-pro | 价格系数 ×2 |
| 时延要求 | <800ms P95 | cloud-llm-v3-lite（缓存命中优先） | 默认 |
| 用户订阅档位 | free | 仅 lite | 日配额减半 |
| 用户订阅档位 | pro | lite+pro | 全量配额 |

> **一致性**：云侧决策表必须与端侧 `InferenceCapabilities`（`getCapabilities()` 返回）一致；表版本号（`tableVersion`）不匹配时设备应重新拉取，避免两端档位认知漂移。

## 5. 租户 Quota 模型

### 5.1 三层配额

| 层 | 粒度 | 维度 | 默认值（示例） | 重置周期 |
|---|---|---|---|---|
| 账户级 | 账号（deviceKeyHash 归属账户） | 日 token / 月成本 / 日请求数 | 10M token / $50 / 1000 请求 | 日/月 |
| 设备级 | 单设备 | 并发 / 速率 | 2 并发 / 30 req/min | 分钟 |
| 会话级 | 单 sessionId | 成本硬上限 | $0.01（10000 micros） | 会话 |

### 5.2 配额强制流程

```
请求进入 Broker
  → 1. 账户级配额检查（日 token/月成本）
       超限 → QUOTA_ACCOUNT_EXCEEDED（429 + Retry-After）
  → 2. 设备级配额检查（并发/速率，Redis 计数）
       超限 → QUOTA_DEVICE_RATE_EXCEEDED（429 + Retry-After）
  → 3. 会话级检查（sessionCostCeilingMicros 累计）
       超限 → QUOTA_SESSION_EXCEEDED → 断流
  → 4. 放行 → 推理 → usage 签名回传 → 三层计数原子累加 → 审计
```

### 5.3 预算记账联动（端云对账）

- **端侧**：`InferenceRequest.costCeilingMicros`（请求硬上限）↔ ACB `AgentBudget.costUsedMicros`（D3）；超支断流 `STATUS_BUDGET_EXCEEDED`。
- **云侧**：租户 quota 独立强制；`usage.costMicros` 签名回传。
- **对账**：端侧按会话累计云用量，定期（如每日）上报本地记账摘要与云端账单核对；不一致标记审计告警（G5.1）。

```
端侧 ACB AgentBudget ◄── 扣减 ◄── 云端 usage 签名回传
      │
      └── 每日对账：本地 costUsedMicros vs 云端账单 → G5.1 审计
```

## 7. 安全边界

- **配额不可绕行**：三层配额检查在 Broker 内原子执行（Redis Lua 原子计数），设备无法通过伪造请求头绕过。
- **签名防篡改**：路由表、usage 均带服务端签名，端侧验签后才采信。
- **设备身份绑定**：配额计数以 `deviceKeyHash`（G2.1 证明过的）为键，非设备 ID，防设备指纹泄露。
- **降级不降安全**：降级到本地推理不绕过任何策略（本地同样走 preflight/审计/预算）。
- **DoS 防护**：设备级速率限制 + 全局令牌桶；`Retry-After` 语义化回退。
- **最小影响面**：配额服务与 Broker 解耦，配额服务故障时 Broker 按上次缓存决策表放行（fail-open 仅限配额，不含身份；身份失效仍拒绝）。

---

## 8. 部署形态

- 路由配额服务为**独立无状态服务**（Redis 集群存计数），与 Broker Gateway 同区域部署，水平扩容。
- 路由表下发走 CDN/边缘缓存（`tableVersion` 强一致校验）。
- 对账任务（每日）为独立 batch，输出对账报告到 G5.1 审计台。
- 上游模型供应商经 `UpstreamAdapter` 接入；配额服务不直接依赖供应商。

## 9. 与端侧联动

| 端侧 | 联动点 |
|---|---|
| `IAgentInferenceRouter.getCapabilities()` | 消费云侧路由表（模型/档位/配额）；返回 `InferenceCapabilities` |
| `IAgentInferenceRouter.infer()` | `suggestedTier` 传云；云端最终裁决；回调 `onRouteChosen` 回传实际档位 |
| `InferenceRequest.costCeilingMicros` | 与云端 `sessionCostCeilingMicros` 双端硬上限 |
| `InferenceChunk.usage_estimate` | 端侧实时累计用量，配合云端签名 usage 对账 |
| `AgentBudget`（D3 ACB） | 云端记账回传扣减；每日对账 |
| 断线降级 | 云端语义（表 3.3）→ 端侧降级链（本地重算 / `STATUS_NO_ROUTE`） |
| 本地决策模型（§4.14 Choice） | 档位选择本身由本地决策模型判定；云侧决策表只做云内模型选择 |

## 10. 验收口径

- [ ] 云侧档位决策表下发成功，端侧 `getCapabilities()` 消费一致（tableVersion 校验）
- [ ] 三层配额（账户/设备/会话）全部生效；超限返回语义化错误码 + Retry-After
- [ ] `costCeilingMicros` 双端硬上限生效（端侧 ACB 与云侧会话级）
- [ ] usage 签名回传，端侧验签成功；每日对账零差异（或差异可解释）
- [ ] 断线/超配额/上游故障全部回传明确语义，端侧降级本地重算且不丢任务
- [ ] 配额裁决与超限全部落审计（G5.1 → A5.3 全链）
- [ ] 配额服务故障时降级路径符合 fail-open（配额）/fail-closed（身份）设计
