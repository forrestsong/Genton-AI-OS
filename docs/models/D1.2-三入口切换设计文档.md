## 1. 设计目标

实现三种独立且共存的模式切换入口，满足：

1. **全局悬浮球**：普通模式下常驻可拖动气泡，单击切换/长按快速指令
2. **侧边栏手势**：屏幕边缘内滑唤出，快捷打开助理
3. **QS Tile**：状态栏下拉快捷设置磁贴，显式切换模式
4. **防误触**：与系统手势（返回/多任务/HOME）协调，避免冲突

---

## 2. 三入口对比

| 入口 | 触发方式 | 可用模式 | 主要场景 | 优先级 |
|-----|---------|---------|---------|--------|
| 悬浮球 | 单击气泡 | 仅 STANDARD_MODE | 快速回助理（单手操作） | 高 |
| 侧边手势 | 边缘内滑 | 双模式可用 | 单手唤出助理面板 | 中 |
| QS Tile | 下拉点击磁贴 | 双模式可用 | 显式模式切换（双手操作） | 低 |

**设计原则**：
- 悬浮球是**最高频入口**（普通模式下始终可见）
- 侧边手势是**辅助入口**（无需视觉提示，肌肉记忆）
- QS Tile 是**兜底入口**（显式、明确、不易误触）

## 3. 全局悬浮球设计

### 3.1 视觉设计

```
┌─────────────────── 屏幕 ───────────────────┐
│                                            │
│                                        ●  ← 悬浮球
│                                       56dp │
│                                            │
│           Launcher 内容                     │
│                                            │
│                                            │
└────────────────────────────────────────────┘
```

**规格**：
- 尺寸：56dp × 56dp（Material Design 标准 FAB 尺寸）
- 颜色：主题色（默认 #2196F3 蓝色）
- 形状：圆形，带阴影（elevation 8dp）
- 位置：默认右侧中间，用户可拖动到任意位置
- 状态指示：
  - 空闲：纯色圆形
  - 任务进行中：中心加载动画（圆环转动）
  - 需要确认：红点角标

### 3.2 交互行为

| 操作 | 行为 | 动画 |
|-----|------|------|
| 单击 | 切换到 ASSISTANT_MODE（全屏） | 悬浮球放大并淡入为 Assistant Surface |
| 长按（>500ms） | 弹出快速指令菜单 | 悬浮球周围展开菜单项（Dynamic Island 式） |
| 拖动 | 移动位置 | 跟随手指，释放后吸附到屏幕边缘 |
| 双击 | 打开助理设置（可选） | 无 |

**快速指令菜单**（长按触发）：
```
        [新建提醒]
            ↑
    [拍照识物] ← ● → [语音输入]
            ↓
        [查看任务]
```

### 3.3 吸附策略

**吸附规则**：
1. 拖动释放后，自动吸附到最近的屏幕边缘（左/右）
2. 垂直位置保持用户拖动的 Y 坐标
3. 吸附动画：弹性动画（spring animation），时长 ~200ms

**边界约束**：
- 顶部：状态栏下方 80dp（避免遮挡状态栏）
- 底部：导航栏上方 80dp（避免遮挡导航栏）
- 左右：屏幕边缘 16dp 内

**持久化**：
- 用户拖动位置保存到 SharedPreferences
- 下次启动恢复到上次位置

### 3.4 防误触策略

**与系统手势协调**：
1. **返回手势**（边缘内滑）：
   - 悬浮球吸附时留出 48dp 安全区（系统返回手势优先）
   - 悬浮球点击区域收缩为 40dp（中心区域），避免边缘误触

2. **多任务手势**（底部上滑）：
   - 悬浮球不吸附到底部中间区域（预留 200dp 宽度给多任务手势）

3. **下拉通知**：
   - 悬浮球不吸附到顶部中间区域（预留 200dp 宽度给下拉通知）

## 4. 侧边栏手势设计

### 4.1 触发区域

```
┌─── 屏幕 ──────────────────────────────────┐
│█                                          │ ← 左侧触发区（16dp 宽）
│█                                          │
│█         Launcher 内容                     │
│█                                          │
│█                                         █│ ← 右侧触发区（16dp 宽）
└──────────────────────────────────────────┘
```

**触发区域**：
- 宽度：16dp（屏幕边缘）
- 高度：全屏（排除状态栏和导航栏）
- 左右两侧都支持（用户习惯自选）

### 4.2 手势识别

**触发条件**：
1. 手指从边缘 16dp 内开始滑动
2. 向内滑动距离 >80dp（阈值）
3. 滑动速度 >1000 dp/s（防慢速误触）
4. 滑动角度：水平方向 ±30° 内（防止斜滑误触）

**状态机**：
```
IDLE → TOUCH_DOWN → SLIDING → TRIGGERED / CANCELLED
```

### 4.3 视觉反馈

**跟手效果**：
1. 手指滑动时，从边缘跟随手指位置绘制半透明面板
2. 滑动距离 <80dp：面板透明度 0 → 50%
3. 滑动距离 ≥80dp：面板透明度 50% → 100%（触发）
4. 松手触发：面板展开为助理面板

**动画**：
- 跟手动画：实时跟随（无延迟）
- 展开动画：spring 弹性动画，时长 ~300ms
- 取消动画：回弹到边缘，时长 ~200ms

### 4.4 行为模式

| 当前模式 | 手势触发后 | 说明 |
|---------|----------|------|
| STANDARD_MODE | 切换到 ASSISTANT_MODE（全屏） | 打开助理首页 |
| ASSISTANT_MODE | 打开侧边栏面板（半屏） | 显示常用任务胶囊，不切换模式 |

**侧边栏面板内容**（ASSISTANT_MODE 下）：
- 当前任务列表（3 个最新）
- 快速指令（4 个常用）
- 设置入口

## 5. QS Tile 快捷设置磁贴设计

### 5.1 磁贴外观

```
┌─────────────────┐
│   🤖 AI 助理    │ ← 图标 + 文字
│   ───────────   │
│   [ 已开启 ]    │ ← 状态文字
└─────────────────┘
```

**状态显示**：
- ASSISTANT_MODE：背景高亮，文字"已开启"
- STANDARD_MODE：背景灰色，文字"已关闭"
- TRANSITION：背景动画，文字"切换中..."

### 5.2 点击行为

| 当前模式 | 点击后 | 长按后 |
|---------|--------|--------|
| ASSISTANT_MODE | 切换到 STANDARD_MODE | 打开助理设置 |
| STANDARD_MODE | 切换到 ASSISTANT_MODE | 打开助理设置 |
| TRANSITION | 无操作（防止并发切换） | 无操作 |

**反馈**：
- 点击触觉反馈（haptic feedback）
- 磁贴状态立即更新（乐观更新）
- 切换失败时回滚状态并 Toast 提示

## 6. 架构设计

### 6.1 组件关系

```
┌────────────────── SystemUI ──────────────────┐
│                                               │
│  ┌─────────── ModeEntryManager ───────────┐  │
│  │                                         │  │
│  │  FloatingBubble ────┐                  │  │
│  │  EdgeGestureHandler ├─→ switchMode()   │  │
│  │  AssistantModeTile ─┘                  │  │
│  │                                         │  │
│  └─────────────────────────────────────────┘  │
│              ↓                                │
│  ┌─────── DualModeContainer ──────────────┐  │
│  │  switchMode(targetMode, durationMs)    │  │
│  └─────────────────────────────────────────┘  │
│                                               │
└───────────────────────────────────────────────┘
```

### 6.2 ModeEntryManager

```kotlin
/**
 * 模式入口管理器：统一管理三种切换入口
 * 
 * 职责：
 * - 协调三种入口的触发事件
 * - 统一调用 DualModeContainer.switchMode()
 * - 处理入口优先级冲突（防止同时触发）
 * - 记录切换来源（用于分析）
 */
class ModeEntryManager(
    private val context: Context,
    private val dualModeContainer: DualModeContainer
) {
    // 三种入口引用
    private var floatingBubble: FloatingBubble? = null
    private var edgeGestureHandler: EdgeGestureHandler? = null
    private var qsTile: AssistantModeTile? = null
    
    // 切换请求来源
    enum class EntrySource {
        FLOATING_BUBBLE,
        EDGE_GESTURE,
        QS_TILE,
        UNKNOWN
    }
    
    /**
     * 请求模式切换（统一入口）
     */
    fun requestModeSwitch(
        targetMode: SystemMode,
        source: EntrySource,
        animationDurationMs: Long = 150L
    ): Boolean
    
    /**
     * 获取当前模式（代理到 DualModeContainer）
     */
    fun getCurrentMode(): SystemMode
}
```

## 8. 防误触策略汇总

### 8.1 悬浮球防误触

| 场景 | 策略 |
|-----|------|
| 与返回手势冲突 | 悬浮球吸附时留出 48dp 安全区，点击区域收缩为 40dp |
| 与多任务手势冲突 | 不吸附到底部中间 200dp 区域 |
| 与下拉通知冲突 | 不吸附到顶部中间 200dp 区域 |
| 误点击 | 点击区域限定为 40dp 半径圆形（不包含阴影） |

### 8.2 侧边手势防误触

| 场景 | 策略 |
|-----|------|
| 与系统返回手势冲突 | 触发阈值 >80dp（系统返回 ~50dp） |
| 慢速滑动误触 | 速度阈值 >1000 dp/s |
| 斜滑误触 | 角度限制：水平方向 ±30° 内 |
| 多点触控 | 仅响应单点触控，多点触控取消识别 |

### 8.3 QS Tile 防误触

| 场景 | 策略 |
|-----|------|
| 连续快速点击 | 防抖 300ms（点击后 300ms 内不响应） |
| 切换中再次点击 | TRANSITION 状态禁止再次点击 |

## 10. 用户体验设计

### 10.1 首次使用引导

**引导流程**：
1. 首次切换到 STANDARD_MODE 时，显示悬浮球引导动画
2. 提示："点击这里可快速回到助理"
3. 3 秒后自动消失，或用户点击悬浮球即消失

### 10.2 个性化设置

**设置项**：
- 悬浮球开关（是否显示）
- 悬浮球默认位置（左侧/右侧）
- 悬浮球透明度（30% - 100%）
- 侧边手势开关（是否启用）
- 侧边手势触发位置（左侧/右侧/双侧）
- QS Tile 开关（是否显示在快捷设置中）

**设置入口**：
- 助理设置 → 切换入口 → 悬浮球/手势/磁贴设置
