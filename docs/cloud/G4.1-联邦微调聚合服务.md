# G4.1 联邦微调聚合服务设计

> **任务编号**：G4.1
> **任务名称**：联邦微调聚合服务（差分隐私、梯度聚合、不落原始数据、防中毒审计）
> **交付物**：联邦服务
> **前置依赖**：E4.2（AI 披露与跨境数据流合规）
> **草案来源**：D13（轨道A-端云调度与推理路由接口草案.md）、D9 S1（S1 RL 预测）、架构 §6（端云协同：模型进化）
> **里程碑**：A5（体验学习与加固）
> **状态**：设计稿（待实现）

---

## 1. 摘要

联邦微调聚合服务利用**分布在设备上的使用数据**（S1 操作意图预测、意图分类、摘要等端侧模型的使用信号）训练/微调端侧模型，**原始数据永不出设备**——设备只上传**梯度/贡献**，云端聚合后产出更新权重，经 G4.2 权重 OTA 管线签名分发回设备。

核心目标：

1. **差分隐私**：设备端梯度加 DP 噪声；云端聚合时再做裁剪/聚合（Local DP + 服务端 Secure Aggregation 可选），防止从梯度反推用户数据。
2. **梯度聚合**：FedAvg 变体（按设备贡献加权）；支持跨地域聚合（G3.2 地域合规）。
3. **不落原始数据**：云端只接收/存储梯度与聚合中间量，不落原始数据（E4.2 "联邦学习数据不出设备主张核验"）。
4. **防中毒审计**：检测恶意/异常设备贡献（梯度异常、Sybil、数据投毒），审计并剔除。

---

## 2. 职责

| 职责 | 说明 |
|---|---|
| 联邦任务编排 | 训练轮次（round）、设备选择、参数下发、梯度回收、聚合、评估 |
| 差分隐私 | 设备端 DP（噪声）+ 云端裁剪/聚合；隐私预算（ε）管理 |
| 梯度聚合 | FedAvg 变体聚合；按设备贡献加权；异常贡献过滤 |
| 不落原始数据 | 只接收梯度/贡献；原始数据零上传（合规核验） |
| 防中毒审计 | 梯度异常检测（范数/方向/统计）、Sybil 检测、设备信誉分；审计并剔除恶意贡献 |
| 权重产出 | 聚合权重 → 签名（OTA 密钥）→ 交 G4.2 灰度分发 |
| 删除联动 | 保留窗口内样本删除/去贡献（G3.1 联动） |

## 3. 接口契约

### 3.1 联邦任务宣告（云 → 设备）

端点：`POST /v1/federated/task`（管理面）或通过 OTA/推送下发任务描述

```json
{
  "taskId": "fed_01HZ...",
  "modelRef": "intent-classifier-v3",
  "baseModelVersion": "v3.2.0",
  "algorithm": "fedavg_dp",
  "rounds": 10,
  "deviceSelection": { "minCapability": "TEE", "minSamples": 50, "maxDevicesPerRound": 10000 },
  "differentialPrivacy": {
    "mechanism": "gaussian",
    "epsilonPerRound": 1.0,
    "deltaPerRound": 1e-5,
    "clipNorm": 1.0
  },
  "secureAggregation": true,
  "retentionWindowDays": 30,
  "signature": "<OTA/服务端签名>"
}
```

### 3.2 设备上传贡献（设备 → 云）

端点：`POST /v1/federated/contribution`（HTTPS + mTLS + 会话票据 + 证明）

```json
{
  "taskId": "fed_01HZ...",
  "round": 3,
  "deviceKeyHash": "sha256:9f2c...b1e0",
  "modelRef": "intent-classifier-v3",
  "contribution": {
    "type": "gradient",                 // gradient | metrics
    "encrypted": true,                  // 可选：secure aggregation 加密态
    "data": "<base64 梯度（已加 DP 噪声 / 已加密）>",
    "sampleCount": 87,
    "metadata": { "avgLoss": 0.42, "accuracy": 0.86 }
  },
  "dpNoiseInfo": { "mechanism": "gaussian", "epsilon": 1.0, "clipNorm": 1.0 },
  "deviceSignature": "<设备私钥签名>"
}
```

响应：

```json
{
  "taskId": "fed_01HZ...",
  "round": 3,
  "status": "ACCEPTED",                 // ACCEPTED | REJECTED_ANOMALY | REJECTED_QUOTA
  "contributionId": "con_5f...",
  "privacyBudgetUsed": { "epsilonAccumulated": 3.0, "budgetRemaining": 7.0 }
}
```

### 3.3 聚合状态查询

端点：`GET /v1/federated/task/{taskId}`

```json

  "taskId": "fed_01HZ...",
```

## 4. 防中毒审计

### 4.1 异常检测

| 检测项 | 方法 | 动作 |
|---|---|---|
| 梯度范数异常 | 贡献梯度范数 > clip 阈值 N 倍 | 剔除 + 设备信誉分下降 |
| 梯度方向异常 | 与全局更新方向余弦相似度过低 | 剔除 + 复核 |
| 样本量异常 | sampleCount 突变（远低于/高于均值） | 复核 + 剔除 |
| 指标异常 | avgLoss/accuracy 突升突降 | 复核 |
| Sybil 检测 | 同一账户/网络段多设备高度相似梯度 | 合并信誉 + 剔除 |
| 数据投毒 | 标签翻转/目标污染（定向攻击样本） | 隔离 + 重新训练受影响轮次 |

### 4.2 设备信誉分

```
设备信誉分 R ∈ [0,100]
  初始 100
  正常贡献：+0.1/轮（上限 100）
  异常贡献：-20/次（梯度异常）
  确认投毒：-50 并暂停参与 30 天
  重复投毒：永久禁入（联动 G2.2 吊销）

信誉分 < 60：仅接收其贡献但不计入聚合（观察模式）
信誉分 < 40：暂停参与（拒绝贡献接收）
```

### 4.3 审计

- 每轮聚合审计：设备选择/贡献接收/剔除/聚合参数/权重产出，全部入审计链（G5.1 → A5.3）。
- 异常/投毒事件触发告警（G5.1 异常检测 + G5.2 事故复盘输入）。
- 合规审计：证明"原始数据零上传"（E4.2 主张核验）——贡献 payload 仅梯度/指标，服务端 schema 校验 + 抽检。

## 5. 不落原始数据边界

```
设备本地（原始数据）         联邦客户端(端侧)              云端聚合服务
  ├─ 使用日志/S1 信号 ──► 本地特征工程 + 梯度计算 + DP 噪声
  │                          │ 仅上传：梯度/指标（非原始）      │
  │                          │──────────────────────────────►│
  │                          │                                │ 只存：梯度/聚合中间量
  │                          │                                │ 不存：原始数据/特征/文本
  │                          │◄── 聚合权重（签名）──────────────│
  └─ 原始数据永不出设备 ──┘
```

**强制项**：
- 上传 payload schema 只允许 `gradient/metrics` 类型；含文本/特征/原始样本 → 拒绝（`FIELD_VIOLATION`）。
- 服务端存储白名单：梯度（加密/DP 后）、聚合中间量、任务元数据；无原始数据类。
- 审计抽样核验上传内容类型分布（防绕过）。

## 7. 安全边界

- **差分隐私**：Local DP（设备端高斯噪声，ε 预算管理）；`secureAggregation: true` 时云端仅见聚合结果（加密态）。
- **贡献真实性**：设备签名 + 远程证明（G2.1）——只有已证明设备能上传。
- **防投毒**：异常检测 + 信誉分 + 剔除（§4）。
- **不落原始**：payload schema 强制 + 存储白名单（§5）。
- **地域合规**：聚合按地域分组（G3.2），数据不出境；跨境聚合需合规配置。
- **隐私预算**：每设备 ε 累计上限（耗尽即停），防长期跟踪。
- **删除联动**：窗口内样本删除 → 该贡献从聚合中间量移除或触发聚合重算（G3.1 去贡献）。
- **审计**：全流程审计；异常事件告警。

## 8. 部署形态

- 聚合服务独立部署：任务编排器 + 聚合计算集群（GPU 可选，梯度聚合 CPU 为主）+ 安全聚合协调器。
- 设备选择/信誉分存储（分布式 KV）；任务元数据（PostgreSQL）。
- 权重工件存对象存储（S3 风格），签名在 HSM（OTA 密钥，对齐密钥方案）。
- 评估服务（heldout 数据集在云侧，均为非用户数据）独立。
- 与 G3.1 删除传播、G4.2 OTA 管线、G5.1 审计台对接。

## 10. 验收口径

- [ ] 端到端联邦训练跑通：任务宣告→贡献→聚合→权重产出→签名交付 G4.2
- [ ] 差分隐私生效：ε 预算管理；梯度加噪可验证；防从梯度反推原始数据
- [ ] 原始数据零上传核验通过（payload schema 拒绝含文本/原始样本）
- [ ] 防中毒审计：异常梯度/样本量/Sybil/投毒检测生效；恶意设备剔除/降权/暂停
- [ ] 设备信誉分机制生效；重复投毒 → 联动 G2.2 吊销
- [ ] 窗口内样本删除 → 贡献移除/聚合重算（G3.1 联动）
- [ ] 聚合按地域分组，跨境合规生效（G3.2）
- [ ] 全流程审计入链（G5.1 → A5.3）；异常事件告警
- [ ] 产出权重带 OTA 签名，G4.2 可验签分发

## 11. 遗留项

1. **Secure Aggregation 实现**：加密态聚合的工程实现（阈值方案）与性能影响待实测。
2. **去贡献算法**：窗口外样本"去贡献"（聚合重算 vs 近似 unlearning）待冻结（G3.1 遗留项 1）。
3. **联邦任务调度频率**：与 S1 预测信号回流节奏（A4 真机数据）对齐的调度策略待定。
4. **ε 预算全局管理**：多任务共享设备隐私预算的全局账本待设计。
5. **模型评估集**：heldout 评估集的构建与地域分布（非用户数据）待定义。
